# V27: 흐린 원본에서도 생성한 지문선 표시

## 원인과 변경

V26은 모델·자세·경계가 함께 확인한 손끝을 지문선 관측이 불확실해도 합성한다.
그러나 기존 V19 재질의 생성 무늬 강도는 원본의 주파수 대역별 요약값을 따랐다.
흐린 손끝에서는 이 값도 작아서 실제 화소가 바뀌어도 뿌옇게 보였다.
적용 수·변경 화소 수만으로 외관을 검증하는 것은 부족했다.

`photo_generated_detail_v27.py`는 **예방적 손끝 합성 영역에만** 생성 재질의
대역별 강도 하한 `(1.5, 3, 3, 1.2)`를 준다. 원본 지문선·위상·방향을
복사하거나 보이지 않는 실제 지문을 복원하지 않는다. 생성 무늬는 기존 독립 시드를 쓴다.
V23의 경계·빛·주름 결합은 유지한다. 원본 지문 관측 결과와 경고도 유지한다.

- 원본 지문 관측을 통과한 기존 영역과 사람 검토 경로에는 하한을 적용하지 않는다.
- 검출/가시성/경계 임계값·가중치·4방향 의미 분할·원본 해상도는 바꾸지 않는다.
- 적용 밖과 미적용 영역의 RGB는 원본과 같아야 한다.
- 작은 손끝의 무늬는 전체 사진을 축소하면 보이지 않을 수 있으므로 같은 좌표의 확대도 비교한다.
- `generated_detail_policy`는 비공개 재질 보고서에 남기며, 기존 HTTP 계약과 Android 경고는 유지한다.

## 제공 V자 사진의 실제 전체 실행

고정 시드 `20261020`, 실제 COLFISPOOF·V6·MediaPipe·V23을 처음부터 실행했다.
이 사진은 첫 실패 이후 수정에 사용한 **개발 사진**이다. 독립 평가로 세지 않는다.

| 항목 | 확인 |
|---|---|
| 후보 / 적용 / 미적용 | 4 / 2 / 2. 후보 수는 손가락 수가 아님 |
| 실제 합성 위치 | 검지·중지 손끝 |
| 원본 지문선 관측 | 두 곳 모두 불확실. 예방적 합성 사유·경고 유지 |
| CPU 기준과 GPU FP32 전체 결과 | BODY/TIP, raw V6, 자세 소유 영역, 경계, 후보, 허용 영역, 적용 마스크의 화소 일치 |
| PNG / 응답 | 실제 서버 응답 계약 검사, 반환 PNG 재읽기, 적용 밖 RGB 보존 통과 |
| 외관 | 두 손끝의 같은 좌표 확대에서 수정 전보다 생성 무늬가 뚜렷해짐을 확인 |
| 일반 보호 효과·본인 지문 복원 | 입증하지 않음 |

기존에 원본 지문 관측을 통과했던 `CAP20261015-007`도 실제 CUDA 전체 경로로 재실행했다.
예방적 합성은 0개, 적용은 1개였고 기존 CPU 결과의 최종 RGB·적용/후보/경계·raw V6·BODY/TIP가
화소 단위로 같았다. 이 사례는 기존 개발 자료의 회귀이며 시간은 다른 검사와 겹쳐 성능 비교에서 제외했다.

원본 사진·확대·가중치·비공개 실행 JSON은 공개 Git에 넣지 않는다.
실행에 사용한 모든 AI 소스의 SHA256 묶음은
`ef6dbcbe9c20fd01a3108f8cd83232f14e268bbae0e38dfcbee11966b817908c`이다.
향후 코드나 테스트가 바뀌면 이 묶음을 최신 실행의 것으로 재사용하지 않는다.

## 시간 진단과 실행 변경

RTX 4060 Laptop GPU가 있는 PC였지만 원래 COLFISPOOF와 Torch는 CPU로 실행됐다.
COLFISPOOF 외부 그래프는 내부적으로 4608 크기의 입력을 네 방향으로 처리하며,
매 요청의 별도 프로세스에서 프레임워크·그래프를 다시 초기화한다.
저장/응답 PNG 처리도 전체 시간에 포함된다. 단순한 사진 합성 시간만은 아니다.

| 실행 | 측정값과 조건 |
|---|---|
| 기존 V26, CPU, 단독 함수 계측 | `run` 118.98초, import 포함 128.15초. 영역 준비 87.69초, 합성 18.18초. 중첩 계측값을 더하지 않음 |
| 기존 V26, CPU, 별도 프로세스 | 156.30초. 자동 검사와 겹쳐 엄밀한 비교 기준에서 제외 |
| 이번 V27, CUDA FP32, 실제 별도 프로세스 | 초기화·출력 저장 포함 **136.56초**, 응답 `processing_ms` **122,935**. 무거운 자동 검사와 동시 실행하지 않음 |

따라서 **동일 조건의 반복 평균이나 개선율은 제시하지 않는다. 120초 목표도 아직 미달**이다.
이번에는 독립적인 COLFISPOOF/MediaPipe 작업 시작과 Torch 초기화를 겹치게 했다.
실패/시간 초과 시 자신이 시작한 작업을 회수하고, Windows venv의 하위 Python도 종료한다.
이는 상주 추론 서버나 그래프 캐시 구현이 아니다. 초기화 비용은 여전히 남는다.

### 명시적인 GPU 선택

`demo/runtime.py`의 비공개 `photo` 설정에 `colfispoof_device: "cuda"`와
Windows의 `colfispoof_dll_dirs` 목록을 지정할 수 있다. 기본은 `"cpu"`다.
시스템 PATH나 드라이버를 바꾸지 않고 해당 자식 프로세스에만 DLL 경로를 전달한다.
GPU가 없거나 경로가 잘못되면 실패를 반환하며 CPU로 몰래 바꾸지 않는다.
기본 preflight의 경로 검사는 실제 GPU 추론 성공을 뜻하지 않는다.

이 PC에서는 TensorFlow 2.10 런타임과 별도 비공개 CUDA 11.8/cuDNN 8.9.5 DLL 묶음으로 시험했다.
처음 TF32 허용 실행은 CPU와 마스크가 달랐으므로 채택하지 않았다.
현재 경로는 TF32를 명시적으로 끈다. 제공 사진의 BODY/TIP와 전체 후속 마스크가
CPU와 같음을 확인했지만 임의 입력의 동등성을 보장하지 않는다.
학교 Ubuntu와 실물 Android는 별도 검증 대상이다.

## 공개 회귀

V27 검사는 실제 양자화 RGB의 생성 대역 에너지 증가, 지정하지 않은 성분의 기존 출력 일치,
적용 밖/입력 보존과 빈 선택 시 기존 보고서·출력 일치를 확인한다.
작업 회수 검사는 성공·실패·부모 예외·마감 시간 초과를 실제 작은 자식 프로세스로 확인한다.
GPU 설정·경로·명시적 장치 계약도 합성 단위 검사에 포함한다.
실제 모델의 외관 확인이나 보호 성능 평가는 이 합성 회귀 통과 수와 구분한다.
이번 코드 기준 자동 검사 86개·기존 AI 계약 115개·backend 계약 160개가 통과했다.
명령 범위와 남은 실물 검증은 [작업 기록](../../docs/worklogs/2026-10-20-이봉헌-generated-detail.md)에 남겼다.
