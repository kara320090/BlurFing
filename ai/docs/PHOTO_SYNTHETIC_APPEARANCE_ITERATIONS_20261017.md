# 합성 외관 개선 3회 — 2026-10-17

사용자 요청에 따라 V6를 기준으로 최대 3회 개선하고 각 버전을 같은 개발 사진 6장·16개 지정 영역·동일 seed로 검토한다. 검출·native 게이트·frozen 수학·기존 V1–V6는 유지한다. 손끝의 피부 명암·주름, 무늬의 굵기/반복성, 주변 피부와 경계 연결, 확대 시 가공 흔적을 본다. 구현자가 수행한 주관적 검토이며 독립 사용자 자연스러움 평가는 아니다. 기존 데이터에 대한 외관 개발이고 독립 holdout 평가는 아니다.

## 1차 V7 — 피부 명암과 넓은 주름

최대 12×40개 넓은 구역(원본 투영 기준 폭 56px·길이 24px 이상)의 RGB 중앙값으로 피부 명암장을 재구성한다. 이전의 최대 3개 횡방향 주름 곡선으로 제한하지 않아 비스듬한 넓은 주름·명암 변화를 표현할 수 있다. 원본 픽셀이나 원본 필터 영상은 섞지 않는다. 원본의 넓은 피부/주름 정보를 V6보다 더 유지하므로 개인정보가 전혀 없다고 주장하지 않는다.

알려진 합성 피부 주름 자료에서 명암 RMSE 1.1544→0.7363. 새 계약 검사 4개 통과. 실제 6장·16개 영역·4,703,163화소의 저장 RGB·원본 해시·범위 밖 RGB를 확인했다. 에너지 요약값을 고정하고 기존 색상/새 피부 구역의 교집합 안에서 원본 픽셀을 섞어도 합성 결과가 동일했다. 이는 숨겨진 raw 잔차 경로 검사이며 생체 보호 증명이 아니다.

6장·16개 영역 확대 검토: 넓은 명암/주름은 일부 개선됐으나, 매끈한 표면·굵고 규칙적인 무늬·관절 경계가 여전히 보였다. **엄격한 자연스러움 기준 미달**로 판단해 2차 개선을 진행한다.

## 2차 V8 — 가는 지문선과 얕은 반사

독립 합성선의 설계 밀도를 높이고, 넓은 명암 띠 대신 높이·방향성 기울기·얕은 밝은 반사를 조합한다. 긴 무작위 미세 흠집은 제거하고 독립적인 얕은 표면 요철로 바꿨다. 합성 간격은 기하/seed의 디자인 값이며 원본 pitch 추정값이 아니다.

관련 새 검사 2개를 포함한 반복 개선 검사 6개 통과. 합성 시험에서 주기 에너지 중심이 0.0874→0.1415 cycles/pixel로 올라가 가는 무늬가 실제 출력에 생성되는 것을 확인했다. 이 값은 자연스러움 점수가 아니다. 같은 실제 6장·16개 영역의 저장·원본/영역 밖 보존을 확인했다.

확대 검토: 굵은 규칙 무늬와 긴 흠집은 줄었으나, 피부가 매끈한 덮개처럼 보이고 일부 관절 경계가 두드러진다. 작은 불균일 피부 표현이 부족해 **엄격한 자연스러움 기준 미달**로 판단하고 3차 개선을 진행한다.

## 3차 V9 — 독립 피부 미세 구조

최대 640px 잠재 표면에서 독립적인 작은 요철·모공 모양·짧고 얕은 횡방향 주름·여러 크기의 피부색/반사 변화를 만든다. 원본에서 얻은 넓은 구역별 대역 에너지는 세기만 조절하고, 새 모공/미세 주름의 위치는 seed로 생성한다. 경계에서는 두 생성 표현을 연결하며 원본 RGB를 섞지 않는다. 모공이나 피부의 물리적 광학을 검증한 모델은 아니다.

3차 첫 시안도 원래 해상도에서 과도한 규칙성·매끈함이 보여 충분하다고 판정하지 않았다. 같은 3차 안에서 얕은 주름과 피부색/반사 변화의 표현을 보완했다. 첫 시안과 최종 시안은 별도 로컬 출력으로 보존한다.

V1–V9, RGB/EXIF/ICC, 파일/마스크 결합, 보존·자원 계약 등 관련 검사 **74개 통과**. 마지막 V9 표현 변경 후 영향 검사 **2개를 다시 통과**했으며 76개의 서로 다른 검사라고 합산하지 않는다. 잘못된 생성 표면의 NaN/shape를 uint8로 변환하기 전에 차단하는 검사를 추가했다. 기존 V1–V8의 정상 출력 의미는 유지한다.

기존 합성 실행기는 V6 선택을 유지한다. 별도 로컬 `outputs/BlurFing-Natural-V9-Test.cmd`가 `-SyntheticRenderer v9`로 이 실험을 선택한다. API 기본 renderer는 V1이며 자동으로 V9를 사용하지 않는다. 검출·native 거절 상태를 합성 성공으로 바꾸지 않는다.

최종 보완본도 같은 6장·16개 영역·4,703,163화소를 교체했다. 원본 해시·지정 범위 밖 RGB·PNG 재읽기를 확인했다. 6개 전체 사진, 16개 손끝 확대, 16개 원래 화소 크기 중심부 비교를 검토했다. V6보다 굵은 반복 무늬와 긴 흠집은 줄었지만, 여러 손끝의 매끈한 피부·반복성·첫 관절 절단 경계·외곽 오차는 여전히 보인다. **요청한 엄격한 자연스러움 수준에 아직 도달하지 않았다.** 구현 검사를 외관 승인으로 대체하지 않으며, V9는 비교용 실험으로 남긴다. 더 작은 대비 조정만으로 충분하다고 판단하지 않는다.

동일 위치 고주파 복사 진단은 318개 구간이 비교 가능했고 28개는 질감 근거가 부족했다. 최대 절대 상관 0.1500, 개발용 검토 기준 0.65 초과 0개였다. 직접 복사 징후 검사일 뿐 생체 보호·사진 전체 누락·재식별 불가능성 증명이 아니다. 원본 coarse 색/주름/에너지 정보는 계속 사용한다.

단계별 비교는 로컬 `outputs/two-photo-folders-20261016/synthetic-appearance-three-rounds-20261017/comparison.html`이다. V7/V8/V9 전환과 원래 화소 확대를 제공한다. 최종 V9 RGB는 `synthetic-replacement-v9-final/<case>/synthetic.png`, 첫 시안은 `synthetic-replacement-v9/`에 보존한다. 사진·개별 진단·실제 원본은 Git에 포함하지 않는다.

새 CMD 실행기에 실제 JPEG 경로를 전달해 검출→native 판정→V9→저장까지 실행했다. 1개 영역 620,040화소가 합성됐으며 저장 RGB·EXIF/ICC·원본 해시·범위 밖 보존·기존 비교와 동일 마스크를 확인했다. 파일 선택 UI는 재시험하지 않았다.

같은 고정 32개 ROI·동일 전처리로 실제 저장 RGB의 NBIS/SourceAFIS 작업을 완료했고 실행 오류는 없었다. 원본/결과 특징점 10개 이상이라는 개발 조건에서 V9 NBIS 전체 bbox 유효 1/16(점수 9), 내부 사각형 1/16(점수 0), SourceAFIS 양쪽 범위 모두 유효 0/16이었다. 자료가 부족하고 원본 self가 독립 촬영 참조가 아니므로 보호 성능 개선 결론을 내리지 않는다. 추출 실패·낮은 점수는 보호 성공으로 집계하지 않았고 매칭 결과를 보고 외관 파라미터를 바꾸지 않았다.
