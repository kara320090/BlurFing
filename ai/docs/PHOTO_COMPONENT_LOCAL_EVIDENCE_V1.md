# Component-local PHOTO evidence experiment

V7 groups disconnected learned prediction fragments by an observed semantic body owner. A new-photo diagnostic found that a large fingertip's pitch and aggregate extracted features could authorize disconnected false-positive skin/nail fragments under the same anatomically unverified owner. No mask-exterior leakage or EXIF mapping error was found. A successful owner-union functional gate was insufficient evidence for each changed fragment.

The explicit V8 experiment splits every owner-assigned permission into native connected components. All pixels, including tiny fragments and invalid/unowned predictions, remain represented; no component-size filtering or sample-specific condition is used. The existing 256-component engineering limit rejects excess work without allocating/deleting a selected subset.

Each component uses its associated observed body axis/width. Source pitch is measured using the intersection of the frozen preprocessing ROI and that component's seed-to-512 nearest-neighbor permission. The unchanged Raw/Bilateral/two-Gaussian numerical criteria are reused. An additional geometric guard requires the tensor window and actual rotated profile's bilinear sampling footprint to lie inside permission. Filtering and orientation preprocessing still have surrounding context; complete statistical/context independence is not claimed.

The renderer's second pitch measurement is bound to the same component, source frame, seed and permission under the existing shared reentrant lock. It must reproduce preflight evidence exactly; the alias is restored on every exit. Working and actual-native structure checks assess only that component's permission. Rejected components and every exterior retain original RGB.

```text
python ai/scripts/protect_photo_learned_v1.py --input PHOTO.jpg --model PRIVATE_COMPLETED_TRAINING --consumed-registry PRIVATE_REGISTRY.json --output FRESH_PRIVATE_OUTPUT --experimental-component-local-gate
```

This flag is mutually exclusive with historical V7's `--experimental-whole-region-gate`. No flag still selects historical V4. Unified/default GUI behavior, original frozen source files, renderer mathematics, trained weights and numeric confidence/feature criteria are unchanged. V8's evidence geometry and assessed component scope change; frozen-gate equivalence is false. It remains experimental.

Component separation cannot establish anatomical pad identity. Connected false positives, thin bridges, inaccurate bodies, missed pads and unavailable ridge evidence remain possible. These newly inspected images are now diagnostic development data, not an untouched final test. Without human masks there is no detector-accuracy or full-pad-coverage estimate, and functional checks are not privacy proof. See the [anonymous status JSON](../results/photo_component_local_evidence_status.json) for executed validation counts.
