# V23 교차 경계의 2차원 외관 모델

## 문제와 원리

V21/V22의 법선 프로파일은 접선 방향의 색을 평균한다. 피부·배경·관절
주름이 함께 있는 모서리에서는 서로 다른 구조가 섞여, 잘못 생성된
돌출이나 경계 이음새가 남는다. 원본 지문 영상으로 덮거나 보호 마스크를
줄이는 대신 별도의 낮은 차원 2차원 외관 모델을 추가했다.

`photo_junction_appearance_v23.py`는 마스크 외곽을 따라 최대 96개 국소
창을 사용한다. 각 창에서 13×13개 셀의 RGB 평균을 측정한다. 셀마다
3×3개 하위 표본을 사용하고 모델도 같은 적분 표본에서 비교한다.
4/5 셀로 적합하고 나머지 공간 셀에서 오차를 검사한다. 이 내부 셀 검사는
새 사진에 대한 독립 검증이 아니며 인접 셀의 의존성도 남는다.

모델은 방향·위치·흐림 폭이 있는 배경 경계, 피부의 완만한 이차 색 곡면,
필요할 때 이를 가로지르는 넓은 주름 하나로 구성한다. 원본에서 내보내는
정보는 최대 색 계수 30개와 기하 매개변수 6개다. 원본 픽셀/필터 영상/
고주파 지문 잔차를 출력으로 복사하지 않지만 원본의 통계에는 의존한다.
기존 생성 결과에서 추출한 제한된 질감을 결합한다. 생체정보 비연결성
또는 개인정보 보호의 증명으로 해석하지 않는다.

창 중앙에서는 추정한 배경까지 충분히 복원하고, 창 가장자리와 보호 영역
깊은 쪽으로 부드럽게 보정을 줄인다. 보정 깊이보다 안쪽, 마스크 밖,
보류된 영역은 그대로다. 원래 거절된 보호 영역을 새로 활성화하지 않는다.
판별이 어려운 창이나 큰 입력·구멍·문맥 부족에는 이전 결과를 유지한다.

## 개발 중 확인한 문제와 수정

1. 피부 곡면을 선형 음영으로만 표현하면 주름 모델이 큰 음영 변화를
   대신 설명하려 했다. 피부의 이차 색 곡면을 별도로 모델링했다.
2. 잔차의 주된 방향만으로 시작하면 주름 최적화가 잘못된 해에 머물 수
   있었다. 독립적인 교차 방향 초기값도 검사한다. 알려진 곡면/주름 합성
   사례에서 재현하고 수정했다.
3. 선형 모델의 기울기 계수 제한을 이차 모델에 그대로 적용하면, 계수가
   서로 상쇄해 실제 예측은 정상인 경우도 거절한다. 계수 크기 대신
   관측 영역에서의 실제 색 예측 범위를 검사하며 출력도 그 범위로 제한한다.
   이 경우를 별도 합성 회귀 테스트에 포함했다.
4. 유효 창의 중심부터 혼합 비율을 줄이면 잘못된 원래 경계가 반투명하게
   남는다. 검증된 창의 중앙 절반은 온전히 지지하고 바깥쪽에서만 줄인다.
5. 첫 파일럿에서 기존 잔존 질감 상관 경고가 증가하는 영역이 있었다.
   기존 진단 기준은 바꾸지 않고 새 경고 창이 생기면 그 성분의 V22
   결과를 유지한다. 원래 경고는 숨기지 않으며 경고 없음도 보호 증명이 아니다.

개별 사진명·GT·파일별 분기나 검출/가시성/피치/특징점 기준 변경은 없다.
기존 V19/V21/V22 및 frozen V4·스캐너 수학은 보존했다. 파일럿들은 이미
소비된 개발 자료이며, 이번 수정의 독립 성능 평가로 재분류하지 않는다.

## 실행

완료된 사람 검토 roster/state와 새 출력 폴더를 사용한다.

```powershell
python ai/scripts/photo_visibility_reviewed_apply_v1.py `
  --roster <private-roster.json> --state <private-state-folder> `
  --source-id <reviewed-source-id> --output <fresh-output-folder> `
  --appearance junction_v23
```

배치 CLI도 같은 선택을 지원한다. 옵션을 생략하면 V19다. V23은 사람
검토 기반의 실험 옵션으로, 자동 검출·자동 가시성 판단의 승격이 아니다.

## 검증 범위

새 8개를 포함한 55개 테스트가 통과했다. 알려진 교차 기하를 적합에
쓰지 않은 공간 위치에서 확인하고, 곡면의 큰 상쇄 계수, 반복선/평탄한
창 거절, 실제 교차 경계 복원, 결정성·회전 허용 오차·입력 보존·크기 제한,
보류 영역 보존과 새 상관 경고 시 이전 결과 유지, 통합 CLI 경로를 검사했다.
기존 V19/V20/V21/V22 회귀 테스트를 포함한다.

소비된 개발 사진 23장, 이미 합성된 44영역에 다시 적용했다. 30영역에서
외관 보정을 채택하고 14영역은 V22를 유지했다. 유지한 영역 중 1개는
새 잔존 질감 상관 경고 때문에 되돌렸다. 최종 경고 영역은 기존과 같은
1개이며 새 경고 영역은 없다. 이 수치는 보호 성공률이 아니다.

44영역의 확대 비교와 실제 저장 PNG의 대표 교차 경계를 직접 확인했다.
일부 관절 모서리의 뾰족한 돌출과 진한 경계는 줄었다. 전체적인 피부
질감 변화는 작고, 큰 주름 연결과 인공적인 매끈함은 남는다. 채택된 보정의
국소 패치 평균색 오차는 629개 중 146개에서 악화됐으며, 최대 RGB RMSE
증가는 약 2.08이다. 성분 전체의 평균 개선이 모든 국소 위치의 개선을
뜻하지 않으므로, 자연스러움이 완성됐다고 판단하지 않았다.

실제 V23 CLI 저장 RGB는 재생 실험과 일치했고, V22 CLI 재실행도 이전
반환 RGB와 동일했다. 원본/GT 60개, 기존 V19 반환 30개와 V20/V21/V22
반환 각 23개의 파일 해시를 확인했다. 사람 검토 상태, 적용 마스크,
마스크 밖·보류 영역·보정 깊이보다 안쪽 RGB 보존도 확인했다.

합성 테스트 통과는 실제 사진의 자연스러움·검출 정확도·일반 지문 보호를
승인하지 않는다. 피부의 인공적인 매끈함, 마스크 밖에 남은 지문,
관절 이음새, 미검출 손끝은 별도 문제다. 새 독립 촬영, 이번 버전 matcher,
Linux/Android 검증은 미실시다.
