# 합성 교체 V4 — 국소 피부 명암과 경계 색상

이 버전은 합성 교체 경로의 V4이며 기존 frozen PHOTO V4와 별개다. V3에서 남은 평평한 피부 명암과 관절·외곽의 색상 단차를 줄인다. 마스크를 축소하거나 원본 지문 픽셀을 섞어 경계를 감추지 않는다.

## 바뀐 처리

- 마스크 기하로 정한 최대 8×10개 구역의 RGB 중앙값과 RGB 가중 밝기 MAD를 사용한다. 밝기는 인코딩된 RGB에서 계산한 외관 통계이며 물리적인 노출·조명 측정값이 아니다.
- 전역 3차 다항식 대신 정규화한 thin-plate spline으로 국소 명암을 재구성한다. 계산 격자는 128×128로 제한하고 통계의 색상 범위를 넘는 외삽은 막는다. 지지가 부족한 작은 영역은 기존 다항식/중앙값 경로를 사용한다.
- V3의 독립 지문선·요철 생성기는 유지한다. 구역의 밝기 분포로 대비를 제한된 범위에서 조절하고 독립 난수로 만든 미세 입자를 추가한다. 원본의 고주파 잔차·지문 방향·위상을 사용하지 않는다.
- 마스크 안쪽의 좁은 경계 띠에서도 구역별 RGB 중앙값을 구한다. 마스크에서 계산한 법선 방향 4개로 구분하여 배경 쪽 색상이 관절 쪽으로 번지지 않게 한다. 같은 방향의 가까운 통계만 양의 가중치로 보간한다.
- 내부 명암장과 경계 색상장은 둘 다 통계에서 생성된 값이다. 이 두 생성 색상장 사이에 기하학적인 전이를 적용하며 원본 픽셀에 대한 alpha는 0이다. 허용 범위의 전체 픽셀을 교체하고 범위 밖 RGB는 보존한다.

초기 경계 실험의 전역 보간은 모서리의 밝은 배경색을 피부 쪽으로 퍼뜨렸다. 방향별 구분과 국소 양의 가중 보간으로 수정했다. 이전 실험 출력은 비공개 경로에 보존하며 최종 소스의 출력으로 혼동하지 않는다.

## 원본 정보와 검증 계약

V3보다 원본의 국소 명암·대비·경계 색상 정보를 더 유지한다. 최대 통계 수는 내부 320개와 경계 960개이며 실제 채워진 구역만 사용한다. 이는 원본 생체정보의 완전한 독립성을 증명하는 설계가 아니다.

순열 검사의 구역도 명시적으로 달라졌다. V4에서는 **같은 색상 구역 ∩ 경계 띠·법선 방향 또는 내부** 안에서 픽셀 위치를 뒤섞어도 결과가 같아야 한다. V3의 전체 색상 구역 순열 불변성을 그대로 주장하지 않는다. 이 검사는 해당 구역 안의 원본 지문선 위치를 직접 사용하지 않는다는 데이터 흐름 확인이며 일반적인 보호 성능 증명이 아니다.

원본 RGB·마스크·허용/거절 판정의 해시 결합, 기존에 승인된 native 픽셀, EXIF와 RGB ICC 저장 계약은 유지한다. PHOTO 품질 gate, 원본 pitch 판정, `natural_auto_04`, `boundaryblend_02`는 변경하지 않는다. 기존 거절을 기존 native 성공으로 재분류하지 않는다.

전역 할당 제한에 더해 영역 4 MiPixels, 영역 bbox 8 MiPixels, 영역 수 256개 제한을 둔다. 경계 보간 쿼리는 한 번에 65,536개 이하로 처리한다. 작은 영역의 지문 질감 생성 불가 상태는 계속 별도 기록한다.

## 실행

```text
python ai/scripts/replace_photo_synthetic_v1.py --input ORIGINAL --protection-run VERIFIED_NATIVE_RUN --output FRESH_OUTPUT --renderer v4
```

V1 기본값과 V2/V3 선택 경로는 보존한다. 이번 6장 비교는 기존의 검증된 경계와 native 결과를 재사용한다. 검출 성능 평가나 실행기의 전체 detector→native→합성 체인 재실행으로 보고하지 않는다.

## 평가 방법과 한계

합성 정답 명암에 넓은 사선 주름과 별도 미세 지문선을 넣은 테스트에서, 피부 명암 재구성 RGB RMSE가 기존 전역 함수의 4.6783에서 새 국소 함수의 1.5351로 감소했다. 이는 합성 정답의 색상 재구성 검사이며 실제 사진의 자연스러움 점수가 아니다.

실제 사진은 같은 개발용 6장·16개 경계와 seed를 고정한다. 마스크 안쪽 경계 3픽셀 띠를 기존 색상 구역으로 나누고 각 구역의 원본/결과 평균 RGB 차이를 화소 수로 가중한다. 이 값은 색상 단차를 살피는 보조 지표이며 지문 보호율·경계 정확도·자연스러움 점수가 아니다. 보호 영역을 줄여 지표를 개선하지 않는다.

NBIS·SourceAFIS는 V3와 같은 32개 ROI·동일 CLAHE 전처리로 원본/V3/V4/검은 가림을 비교한다. 32개 ROI는 독립 촬영 사진 32장이 아니다. 원본 특징점 부족, 점수 0, 추출 실패를 보호 성공으로 해석하지 않으며 점수에 맞춰 renderer나 seed를 재선택하지 않는다.

완전한 피부 주름 표현, 검출 경계의 정확성, 독립 사진에서의 자연스러움과 인식 저항성은 별도 검증 대상이다.

## 2026-10-17 개발 확인 결과

렌더러·입출력·회귀 검사 170개가 통과했다. 실제 6장·16개 지정 영역의 4,703,163화소를 교체했으며 질감 생성 불가 영역은 0개였다. 모든 사진에서 PNG 재읽기 RGB, 마스크 밖 RGB, 원본 파일 해시, 명시된 구역 내부 순열 불변성 검사를 통과했다. V4 CLI도 실제 파일 1건으로 실행했다.

동일 경계의 색상 차이 보조 지표는 6장 모두 감소했다. 각 사진의 V3→V4 값은 46.75→5.27, 17.22→3.57, 12.75→1.33, 7.53→1.13, 7.67→1.12, 8.53→2.34다. 전체 16개 확대 결과를 검토했으며 경계 단차는 줄었지만 균일한 요철과 큰 주름의 소실이 남는다. 자연스러움 검증 완료로 판정하지 않는다.

동일 CLAHE 전처리의 실제 저장 RGB 매칭 결과는 다음과 같다. 표의 측정 가능은 양쪽 특징점 10개 이상과 정상 점수 반환이라는 개발용 유효성 조건이며 보안 기준이 아니다. 점수 중앙값의 집계 대상을 명시했다.

| 엔진·ROI | 측정 가능한 V3/V4 쌍 | 원본 self 중앙값 | 원본→V3 중앙값 | 원본→V4 중앙값 |
| --- | ---: | ---: | ---: | ---: |
| NBIS 전체 bbox | 13/16 | 68 | 0 | 0 |
| NBIS 내부 사각형 | 1/16 | 100 | 3 | 3 |
| SourceAFIS 전체 bbox | 2/16 | 356.03 | 21.36 | 0.93 |
| SourceAFIS 내부 사각형 | 2/16 | 338.55 | 0 | 0 |

전체 bbox에는 변경되지 않은 외부 문맥이 포함된다. 내부 ROI는 대부분 원본부터 특징점이 부족하다. 원본 self는 독립 촬영 참조가 아니며 두 엔진은 서로 다른 척도다. 이 결과만으로 전체 지문 보호 성공이나 V4의 일반적인 보안 우위를 결론 내리지 않는다.

개별 전체 bbox 쌍의 V3 대비 V4 점수는 NBIS에서 3개 감소·6개 동일·4개 증가했고, SourceAFIS에서는 측정 가능한 2개 모두 감소했다. 중앙값이 낮다는 이유로 모든 사례가 개선됐다고 해석하지 않는다.

합성 전용 Windows 실행기를 V4로 연결했다. 별도의 실제 사진 1회 재실행에서 검출→경계 보정→native 거절→합성 V4→PNG 저장 전체 체인이 완료됐다. 1개 영역 570,030화소가 합성됐고 이전 비교의 허용 마스크와 같았다. 영역 밖 RGB·원본 파일·모델 해시를 다시 검증했다. 기존 native 결과는 거절로 유지되며 합성 성공과 구분한다. 파일 경로를 인자로 전달했으며 대화형 파일 선택창은 재시험하지 않았다.

이 과정에서 확인한 V6 학습 소스 해시 호환 오류는 [별도 수정 기록](V6_CHECKPOINT_VALIDATOR_COMPATIBILITY.md)에 설명한다. 수정 뒤 관련 통합·회귀 검사 70개가 통과했다. 이는 앞선 170개와 일부 중복되며 240개 고유 테스트라는 뜻이 아니다.
