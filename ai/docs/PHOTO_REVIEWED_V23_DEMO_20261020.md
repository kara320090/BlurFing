# V23 검토 기반 시제품 마감

후속 갱신: 아래 Android 연결 상태는 사람 검토 경로를 정리하던 시점의 기록입니다. 이후 [자동 V23](PHOTO_AUTOMATIC_V23_20261020.md)이 Android에 연결됐으며, 여기의 사람이 확정한 범위를 사용하는 실행기와는 구분합니다. 현재 발표 인수 범위는 [시연 절차](../../demo/README.md)를 따릅니다.

## 완료 범위

사람이 손끝 마스크와 지문선 가시성을 확인한 사진에서 인공 지문을 적용하고,
실제 저장 PNG를 재검사한 뒤 비교 화면을 생성하는 Windows 실행기를 추가했다.
이 실행기는 `junction_v23`을 명시적으로 선택한다. 기존 실행기·기본 V19·
V21/V22/V23 렌더러는 수정하지 않았다. 자동 검출 및 자동 가시성 판단의
제품 승격이 아니며 Android/서버에 V23을 새로 연결한 작업도 아니다.

`photo_reviewed_demo_v23.py`는 완료된 검토와 원본 해시를 검증하는 기존
batch 경로를 호출한다. 저장 RGB 해시, 적용 마스크 크기, 마스크 밖 RGB,
사람 검토 상태 및 실행 중 코드 변경을 다시 검사한다. 비교 화면은 저장
PNG에서 생성한다. 원본 ICC는 표시용으로 sRGB 변환하며 다운로드 파일의
원래 해상도/검증된 ICC·EXIF 계약은 유지한다. 오류 발생 시 `INCOMPLETE.txt`를
남기고 완료로 표시하지 않는다.

## 실행

검토가 끝난 사진 ID를 선택하거나 `-SourceId`로 전달한다. 새 사진은 기존
영역·가시성 검토 절차를 먼저 완료해야 하며, 이 실행기가 새 사진의 검토를
대신하지 않는다. `-SourceId`가 없으면 Windows 선택 창을 제공한다.

```powershell
& .\ai\platform\windows\start_reviewed_v23_demo.ps1 `
  -PythonPath <python.exe> `
  -RosterPath <private-roster.json> `
  -StatePath <completed-private-review-folder> `
  -OutputRoot <private-output-folder>
```

자동 점검에서는 `-SourceId <reviewed-id> -NoOpen`을 사용할 수 있다.
`-Seed <integer>`는 같은 입력의 재현용이며 기본은 새 난수 시드다.
시드나 매칭 점수를 탐색하여 유리한 결과를 고르는 기능은 없다.

출력은 `OutputRoot/날짜시각_고유번호/` 아래에 저장한다.

- `report.html`: 원본·실제 결과·적용 마스크와 PNG 링크.
- `results/<source-id>/returned.png`: 실제 반환 PNG.
- `results/<source-id>/result.private.json`: 적용/보류·버전·시드 기록.
- `verification.private.json`, `runtime-source.private.json`: 저장 및 코드 검증.

이 폴더는 개인 사진과 진단을 포함하므로 공개 저장소에 넣지 않는다.

## 실행·보존 검증

관련 58개 테스트가 통과했다. 실제 사진 1장의 4영역을 PowerShell 실행기로
처리했고 동일한 시드의 이전 V23 저장 RGB와 정확히 일치했다. 별도의
미관찰 사진은 Windows PowerShell 5.1 경로에서 0영역 적용, 원본 보존을
확인했다. 새 테스트에는 EXIF 방향, 저장 파일 손상 시 완료 차단,
명시적 사진 선택, 결과 링크 및 사람 검토 불변성을 포함한다.

브라우저 자동화 도구의 정책상 `file://` 접근이 차단되어 HTML 화면의
브라우저 렌더링 및 사진 선택 창의 직접 UI 검사는 미실시다. HTML의 이미지·
다운로드 경로, 저장 파일 재읽기, 생성된 비교 이미지와 실제 반환 미리보기는
확인했다. 실행기 테스트는 `-SourceId -NoOpen`으로 수행했다.

기존 개발 23장에는 사람 판정 57영역(보임 44, 불확실 7, 미관찰 6)이 있다.
보임 44개 마스크 및 대표 지문선 사각형 44개가 적용 범위에 포함됨을
확인했다. 불확실·미관찰 영역과 마스크 밖 RGB는 그대로다. 이는 이미 있는
사람 마스크와의 일치이며, 마스크 밖 누락된 지문에 대한 독립 검출 재현율이 아니다.

## 실제 매칭 검사

V23 실제 저장 PNG에서 기존과 동일한 전체 사각형/완전 내부 정사각형을
사용했다. 44영역의 두 시야로 총 88 ROI이며 독립 88개 샘플이 아니다.
기존 512px 비율 유지 정규화·고정 CLAHE·가정 DPI 500·양쪽 특징점 10개 이상
조건을 유지했다. 실제 물리 DPI는 모른다. 엔진당 이미지 176개, 비교 264쌍이다.

| 엔진 | 시야 | 원본→결과 측정 가능 | 측정 부족 | 중앙값 | 최대 |
|---|---|---:|---:|---:|---:|
| NBIS | 전체 사각형 | 41/44 | 3 | 10 | 127 |
| NBIS | 완전 내부 | 39/44 | 5 | 5 | 11 |
| SourceAFIS | 전체 사각형 | 36/44 | 8 | 0.918 | 64.189 |
| SourceAFIS | 완전 내부 | 26/44 | 18 | 0.408 | 11.107 |

원본 자기 매칭을 함께 기록했지만 별도 촬영의 동일인 참조를 대신하지 않는다.
매칭 점수는 일치 확률이 아니며 엔진 사이에 직접 비교할 수 없다. 임계값을
새로 정의하지 않았고 0점·특징점 부족을 보호 성공으로 집계하지 않았다.
동시에 측정 가능한 같은 영역만 V19와 비교했을 때 V23의 점수가 올라간
사례도 있다. V23의 외관 개선을 보호 성능 향상으로 해석하지 않는다.

전체 사각형은 보호 마스크 밖의 그대로 남은 픽셀을 포함한다. 모든 44영역에
대해 원본/결과 양쪽에서 그 바깥 부분만 흰색으로 만든 별도 진단을 시행했다.
주 검사 결과나 실제 반환 이미지는 변경하지 않았다. 대표 높은 점수는
NBIS 127→9, SourceAFIS 64.189→1.133으로 낮아졌다. 바깥 부분이 일부 높은
점수에 기여한다는 근거다. 그러나 이 진단은 실루엣·특징점 추출에도 영향을
주며 모든 매칭의 유일한 원인을 증명하지 않는다.

## 남은 한계와 마감 판단

잔존 질감 상관 경고는 44영역 중 1곳에 남는다. 확대 영상에서는 강한
피부/배경 외곽과 겹치며, 이를 원본 지문선의 잔존 또는 오경보로 확정하지
않았다. 경고 기준을 낮추거나 경고를 지우지 않았다.

현재 수준은 **사람 검토 기반 시제품**이다. 실행·저장·범위 계약과 개발
자료의 매칭 검사를 완료했으나 다음 항목은 미완료다.

- 새로운 촬영 그룹과 별도 동일인 참조에 대한 독립 검증.
- 마스크 밖 누락·과대 영역 및 자동 가시성 판단의 일반화.
- 경계·큰 주름 연결과 내부 피부의 인공적인 매끈함.
- V23의 Linux/Android/서버 통합 및 실제 기기 검증.
- 일반적인 지문 재식별 방지 또는 개인정보 보호 보장.

추가 외관 수치 조정은 이번 마감에 포함하지 않는다. 기존 자료 반복 관찰로
성능을 맞추지 않고 버전·경고·검사 조건을 고정해 발표한다.
