# 가시성 원본 반복 검사 V2/V3와 다음 자료 조건

이 문서의 V2/V3은 **가시성 관측 실험** 버전이며 V19 인공 지문 합성 버전과
무관하다. 기본 보호 적용 조건, frozen V4, scanner, V19는 변경하지 않았다.
이전 [누락 감사](PHOTO_VISIBILITY_GATE_AUDIT_V1_20261020.md)와 실험을 보존한다.

## 방법과 발견한 문제

`photo_visibility_repetition_probe_v2.py`는 32/64 픽셀 창의 주파수 봉우리에서
방향을 제안하고, 원본에서 얻은 두 개의 밝기 profile을 미분해 한 주기와
두 주기 뒤의 상관관계를 확인한다. 큰 주름의 저주파 에너지가 전체 에너지를
지배한다는 이유만으로 약한 반복 무늬를 거절하지 않는 별도 관측법이다.
대역 통과로 만든 무늬를 반복 증거로 삼지 않는다. 검사 창 전체와 실제
AREA 축소의 입력 범위가 마스크 안쪽이어야 한다.

그러나 정수 lag만 쓰면 3.5/4.5/5.5 픽셀 간격의 잡음 없는 합성 무늬도
실패했다. 첫 반복의 정수 오차를 두 배로 적용하면서 두 번째 반복 위치가
어긋나는 문제다. `photo_visibility_fractional_recurrence_v3.py`는 관측된
상관관계 봉우리를 포물선 보간해 소수점 위치를 추정한다. V3 관측기는 이
함수만 교체했고 V2의 비교 상수는 유지했다. 실제 지문 픽셀을 생성하거나
측정 실패 시 간격을 채워 넣는 기능은 없다.

V2와 V3 모두 분류기가 아니라 미교정 반복 신호 진단이다. 반복되는 피부 주름,
직물 등과 지문을 완전히 구분하지 못하며, 자동 가시성은 항상 `uncertain`,
`used_by_protection=false`, `renderer_binding_allowed=false`다. working pixel
간격을 물리적 DPI나 렌더러용 지문 간격으로 전달하지 않는다.

## 고정 비교

각 버전은 합성 대조를 통과한 뒤 코드·상수 해시를 고정했다. 동일한 30장·67개
영역을 개발 23장 → 소비된 GT7 순서로 실행했다. GT7 결과를 보고 상수를 조정하지
않았다. 라벨과 이전 실험 결과를 이미 확인했으므로 독립/블라인드 검증이 아니다.
원본·마스크 60개 파일과 decoded RGB 연결을 확인했고 사람 주석은 변경하지 않았다.

| 사람 판정 | 영역 | 기존 | 선형 조명 제거 | 주파수 V1 | 원본 반복 V2 | 소수점 반복 V3 |
|---|---:|---:|---:|---:|---:|---:|
| 보임 | 53 | 24 | 27 | 24 | 18 | 25 |
| 관찰되지 않음 | 6 | 0 | 0 | 0 | 0 | 0 |
| 불확실 | 8 | 0 | 0 | 0 | 0 | 0 |

V3은 V2 대비 7개를 회복했다. 기존 관측기 대비 9개를 추가 관측했지만 8개를
놓쳤다. 개발 23장의 보임 44개에서는 기존 17, 선형 조명 제거 19, V2 10,
V3 17이다. 전체 25/53이라는 숫자의 순증가 1개는 개발 자료에서의 우수성을
보여주지 않으며 **기본 판정기로 승격하지 않는다**. 이전 조명 실험의 27/53도
아직 운영 판정이 아니다. 방법별 좋은 결과만 사후 합쳐 검증 성능으로 보고하지 않는다.

수치는 신호 관측 수이며 분류 정확도, 자동 보호 적용률, 보호 성공률이 아니다.
음성 6개에서 0이라는 결과만으로 일반 오탐률을 확정할 수 없다. 관측 실패도
지문이 보이지 않는다는 뜻이 아니다. 비교의 해부학적 ROI는 사람 마스크이므로
자동 손끝 검출을 포함한 end-to-end 성능이 아니다.

## 자료 준비 점검과 필요한 사용자 작업

2026-10-20 사용자가 당장은 추가 자료 준비가 어렵다고 답해 새 촬영·독립 검증은
보류했다. 아래 내용은 이후 자료가 가능할 때의 조건이며 지금 재라벨링을 요구하지 않는다.

`photo_visibility_data_readiness_v1.py`는 검토 완료·사람 라벨·원본 해시 연결,
중복 파일/decoded RGB, 촬영 그룹별 클래스 분포를 검사한다. 메타데이터 검사이며
픽셀의 무결성 재검증은 위 비교 실행기가 담당한다. 불확실을 음성으로 바꾸지
않고 GT7은 학습 가능 자료에서 제외한다. 이 검사가 통과해도 사람 독립성이나
충분한 통계적 표본 수를 보장하지 않는다.

개발 23장에는 보임 44개, 관찰되지 않음 6개, 불확실 7개가 있다. 음성 6개는
두 사진·한 촬영 그룹에만 속한다. 그 그룹을 빼면 학습 음성이 0개이고,
나머지 그룹을 검증으로 빼면 검증 음성이 0개다. 패치나 손가락을 무작위로
나누어 이 문제를 숨기면 같은 촬영의 정보가 양쪽에 섞인다.

학습/조정/평가 세 역할에 양·음성이 있는 촬영 그룹을 따로 둘 수 있도록,
최소 두 번의 **새 촬영 회차**에 선명함·관찰되지 않음·판단 어려움 조건을
섞은 원본과 사람 검토가 필요하다. 회차당 6~10장, 합계 12~20장은 시작용
권장량일 뿐 정확도 보증 표본 수가 아니다. 흐림/반사를 자동으로 음성으로
라벨링하지 않는다. 같은 회차·사람의 파생 사진은 분리하지 않으며, 사람 독립
성능을 주장하려면 인물 그룹까지 분리해야 한다. 모델/설정 선택이 끝날 때까지
평가용 그룹을 사용하지 않는다. 기존 30장 라벨링을 다시 할 필요는 없다.

새 자료 수령 후 순서: 원본/EXIF/중복 점검 → 회차·인물 정보 확인 → 별도 검토
화면 → 사람 라벨 확인 → 그룹 분리와 사전 평가 규칙 고정 → 학습/조정 →
보관된 평가 그룹 실행. 기존 30장을 새 holdout으로 재분류하지 않는다.

## 검증

기존 회귀와 새 실험·자료 준비 검사 합계 66개 테스트 통과. 약한 무늬와 큰
주름, 3.3~12픽셀 소수점 주기, 회전·조명, 평면·단일 경계·단일/희소 주름,
무작위 잡음, 마스크 외 무늬의 축소, 입력 보존·결정성, 클래스 누락·중복·
미검토 라벨·GT7 제외를 확인했다. 대표 추가 관측·퇴행·미관측 사례의 원본
패치도 시각 확인했다. 개인 비교 이미지와 상세 JSON은 공개 저장소 밖에 보관한다.

```powershell
python -m unittest -v test_photo_visibility_gate_audit_v1 test_photo_visibility_spectral_probe_v1 test_photo_visibility_repetition_probe_v2 test_photo_visibility_repetition_probe_v3 test_photo_visibility_data_readiness_v1 test_photo_visibility_v1 test_photo_pad_annotation_v1 test_ridge_axial_orientation test_photo_candidate_ridge_diagnostic_v1
```

`ai/scripts`에서 실행한다. 데이터 준비 검사는 아래처럼 새 출력 파일을 지정한다.

```powershell
python ai/scripts/photo_visibility_data_readiness_v1.py --roster <private-roster.json> --labels <validated-human-labels.json> --output <new-private-readiness.json>
```
