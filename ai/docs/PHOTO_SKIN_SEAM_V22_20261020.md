# V22 경계 음영 재유입 제한 및 피부 이음새 보정

## 판단

기존 개발 23장·사람이 보임으로 확인해 이미 합성한 44영역에 적용했다.
44개 확대 비교를 시각 검토했으나 V21 대비 전체 차이는 작다. 일부 진한
경계 띠와 피부색 연결은 완화됐지만 관절 모서리의 뾰족함·다각형 이음새와
매끈한 질감은 남는다. 큰 자연스러움 개선이나 제품 수준 완성을 주장하지
않는다. 기본 V19와 V21 선택 경로를 보존하고 V22는 명시적 실험 옵션이다.

44영역의 RGB가 변경됐다는 수치는 보호 성공률도 외관 개선률도 아니다.
실루엣 단계는 43개 성분, 별도 피부 재질 단계는 29개 성분에 보정을 채택했다.
GT7 및 독립 holdout은 이번 외관 개발에 사용하지 않았다.

## 원인과 변경

V21은 기존 생성 영상에서 뽑은 고주파 성분을 피부색 모델에 다시 더한다.
이 성분에 이전 마스크 경계의 잘못된 음영이 들어 있으면, 색 보정 후에도
진한 띠가 다시 생길 수 있다. 알려진 경계에 인위적인 어두운 띠를 추가한
합성 재현으로 이 경로를 확인했다. V22에서는 생성 영상의 내부 띠에서
측정한 채널별 잔차 1/99 백분위 범위로 경계 잔차를 제한한다. 원본 영상의
지문 잔차를 가져오는 방식이 아니다. 내부 표본이 부족하면 기존 질감을 유지한다.
`photo_silhouette_appearance_v21.py`의 기본 동작은 바꾸지 않고 새 모드로 분리했다.

피부 안쪽의 허용 마스크 경계는 피부·배경 경계와 다르다. 별도
`photo_skin_seam_v22.py`에서 접선 평균 RGB를 완만한 이차 색 변화 또는
넓은 어두운 주름 하나와 선형 음영으로 근사한다. 단일 물체 경계로 맞는
표본과 그 이웃은 제외한다. 연속된 3개 이상의 지지 표본이 필요하며,
기존 생성 영상에 제한된 저차 색 차이만 더하고 안쪽으로 0까지 줄인다.
실제 양자화된 결과의 평균 색 오차가 줄지 않으면 이전 결과를 유지한다.

이차 모델만 사용한 첫 파일럿의 효과가 작아 넓은 주름 모델을 별도로
검증했다. 좁은 주름을 넓은 모델의 최소 폭에 억지로 맞추지 않도록
경계값 적합은 거절한다. 합성 사례의 좁은 주름과 반복 지문선은 거절된다.
실제 사진에서 원본 지문 정보가 절대로 전달되지 않는다는 증명은 아니다.

## 보존 계약과 한계

- 보호 허용 마스크를 확대·축소하지 않는다. 거절/보류 영역을 활성화하지 않는다.
- 마스크 밖과 보류 영역 RGB, 보정 깊이보다 안쪽의 기존 생성 RGB를 보존한다.
- 원본 픽셀 알파 혼합·원본 필터 영상 복사 없이 원본의 접선 평균 통계를
  색 계수 9개와 최대 주름 매개변수 2개에 사용한다. 원본 의존성은 존재한다.
- 경계의 생성 질감은 제한·보정되므로 경계 지문 위상의 완전 불변을 주장하지 않는다.
- 구멍, 문맥 부족, 큰 영역 등 지원하지 않는 경우 이전 결과를 유지한다.
  좌표는 원본 해상도이며 크기 제한을 위해 강제 축소하지 않는다.
- 검출·가시성·피치·특징점 임계값과 frozen V4·스캐너·V19 수학은 변경하지 않았다.
- 평균 색 오차 검사는 자연스러움 또는 개인정보 보호 지표가 아니다.
  실루엣 단계의 1,816개 국소 표본 중 643개, 재질 단계의 257개 중 39개는
  오차가 증가했다. 최대 RGB RMSE 증가는 각각 약 3.04와 0.37이다.
  모든 위치의 개선으로 해석하지 않는다.

## 검증

- 새 7개를 포함한 **47개 테스트 통과**. 합성 경계 음영 재유입, 완만한 색
  연결, 넓은 주름 복원, 좁은 주름/반복선 거절, 결정성·회전 허용 오차,
  입력 보존·지원 크기·보류 영역·실제 통합 경로와 V19/V20/V21 회귀를 검사했다.
- 실제 CLI에서 같은 seed로 V19 생성부터 V22·PNG 저장까지 실행했다.
  저장 RGB가 개발 재생 결과와 정확히 일치했고 적용 마스크도 동일했다.
- 기존 V21 옵션을 실제 CLI로 다시 실행해 이전 V21 저장 RGB와 정확한 일치를 확인했다.
  이는 검사한 사진/환경의 호환성이며 전체 플랫폼 동등성 증명은 아니다.
- 원본/GT 60개 파일, V19 반환 30개, V20 23개, V21 23개 해시를 재확인했다.
  사람 검토 상태 및 실행 중 소스 해시 고정, 새 23개 PNG 저장/재읽기도 확인했다.
- 잔존 질감 진단 경고는 2개에서 1개로 감소했고 새 경고 영역은 없었다.
  이 수치는 보호 증명이 아니다. V22 matcher, 새 독립 사진, Linux/Android
  검증은 수행하지 않았다. 이전 버전 matcher 결과를 V22 결과로 재사용하지 않는다.

## 실행과 다음 과제

사람 검토가 완료된 기존 roster/state와 새 출력 폴더를 사용한다.

```powershell
python ai/scripts/photo_visibility_reviewed_apply_v1.py `
  --roster <private-roster.json> --state <private-state-folder> `
  --source-id <reviewed-source-id> --output <fresh-output-folder> `
  --appearance material_v22
```

배치 도구도 `--appearance material_v22`를 지원하며 옵션 생략 시 V19다.
사람의 보임 판단을 자동 판정으로 바꾸지 않는다. 이전 코드/결과는 보존했다.

다음 과제는 피부·배경·관절이 동시에 만나는 구간이다. 현재의 1차원 법선
프로파일과 평활한 색 모델만으로는 이 교차점을 충분히 설명하지 못한다.
보호 마스크를 줄여 외관 오류를 숨기지 말고, 별도의 2차원 재질/경계 모델을
합성 정답으로 검증한 후 기존 개발 자료와 비교해야 한다. 독립 성능 승격에는
새 촬영 자료가 여전히 필요하다.
