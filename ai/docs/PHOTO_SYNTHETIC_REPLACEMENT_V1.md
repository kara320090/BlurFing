# 합성 지문형 무늬로 지정 영역 교체 — 실험 V1

사용자가 지정한 검은 가림 범위를 원본과 무관한 인공 지문형 무늬로 교체하는 별도 경로다. 기존 `natural_auto_04`, `boundaryblend_02`, V12 gate는 수정하지 않는다. 기존 변환 거절을 기존 변환 성공으로 다시 분류하지 않는다.

## 처리 계약

- `replace_photo_synthetic_v1.py`는 기존 PHOTO 실행의 원본 식별값, 허용/적용/가림 마스크, 연결 영역별 해시, 실제 반환 RGB와 판정을 검증한다. 실제 사진의 검은 RGB 값을 보고 마스크를 추측하지 않는다.
- 실제 native 변환이 적용된 영역은 그 결과를 보존하고, 정상 품질 거절 후 검게 가린 영역만 합성 무늬로 교체한다. 기존 runtime error를 품질 거절로 바꾸지 않는다.
- 각 연결 영역의 마스크 좌표와 별도 난수로 무늬·간격·명암을 생성한다. 원본에서는 영역별 RGB 중앙값 세 개만 사용한다. 원본 지문선 간격, 방향, 특징점, 공간적 질감은 사용하지 않는다.
- 합성 간격은 마스크 폭에서 선택한 렌더링 파라미터이며 측정된 지문 간격이 아니다. 이 무늬가 생물학적으로 타당하거나 지문 인식기에 유효한 지문이라는 주장은 하지 않는다.
- 경계까지 불투명하게 교체한다. 원본을 섞는 feather/alpha blend는 없다. 영역 밖 RGB와 원본 파일은 보존한다. EXIF 방향·유효 RGB ICC는 기존 PNG 저장 계약을 따른다.
- 기본값은 매 실행 독립 난수다. 재현 검증용으로 `--seed`를 지정할 수 있으며 사용된 seed를 비공개 결과 JSON에 기록한다. seed는 암호키나 보호 성능의 근거가 아니다.
- 기존 전역 할당 제한과 연결 영역당 4 MiPixels·최대 256개 제한을 검사한다. 제한 초과 시 임의 축소나 미처리 성공을 반환하지 않는다.

## 실행

```text
python ai/scripts/replace_photo_synthetic_v1.py --input ORIGINAL --protection-run VERIFIED_NATIVE_RUN --output FRESH_OUTPUT
```

`synthetic.png`, `replacement_mask.png`, `result.private.json`을 별도 폴더에 저장한다. 이전 원본/native/black 결과는 덮어쓰지 않는다. 기존 검증 실행을 재사용하며 detector/native 알고리즘을 다시 실행했다고 보고하지 않는다.

## 검증과 한계

합성 입력 테스트는 영역 내 원본 픽셀 위치를 임의로 뒤섞어도 동일 seed에서 교체 결과가 경계까지 완전히 같은지 검사한다. 따라서 이 렌더러가 원본 지문의 공간적 패턴을 사용하지 않음을 확인할 수 있다. 마스크와 대표 색상은 원본으로부터 온 정보다.

실제 6장 개발 사진의 기존 경계에 적용하며, PNG 재읽기·영역 밖 픽셀·원본 해시·실제 원본 픽셀 순열 검사를 수행한다. 합성 교체 성공은 지정 마스크의 교체 완료를 의미하며, 검출 누락·경계 정확도·사진 전체 보호나 생체 인식 저항성의 검증 완료를 의미하지 않는다. 자연스러움과 피부색 경계 이음새도 별도 개선 대상이다.

2026-10-16 실행 결과: 6장 16개 영역의 합성 교체 및 위 검증을 모두 통과했다. 기존 native 변환 적용은 0개, 거절은 16개로 유지된다. 총 149개 단위·계약·회귀 테스트 통과, 실제 CLI 1회와 실행기 PowerShell 구문 검사를 완료했다. 새 실행기의 전체 detector→native→합성 체인을 추가 재실행한 것은 아니다. 여섯 장 모두 확대 확인했으며 동심원 무늬·평평한 명암과 관절 경계가 인공적으로 보이는 한계가 있다.
