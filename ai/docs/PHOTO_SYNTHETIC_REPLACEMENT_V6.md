# 합성 교체 V6 — 경계 색상 연결과 사진별 질감

V5의 지문 무늬·큰 주름 생성에 두 가지 외관 변경을 추가한 명시적 선택 경로다. 기존 V1 기본값, V2–V5, frozen native 변환·검출·pitch·feature gate, 적용 마스크는 변경하지 않았다.

## 변경

- 경계 안쪽의 기존 구역별 RGB 중앙값을 연속적인 법선 방향 가중치로 보간한다. V5의 이웃/방향 구간 선택에서 발생하는 전환을 줄이고, 생성한 경계 색상과 생성한 내부 색상을 smoothstep으로 연결한다. 원본 RGB를 alpha로 섞지 않는다.
- 최대 512px 분석 래스터, 최대 6×8개 넓은 구역에서 등방성 두 주파수 대역의 강건한 에너지 요약값을 구한다. 이 스칼라값으로 독립 합성선의 강도와 부드러움을 조절한다. 원본 영상의 필터 결과·지문 방향·위상·특징점은 합성 무늬로 전달하지 않는다. 초점이나 물리적 지문 간격을 정확히 측정하는 모델은 아니다.
- 큰 주름 후보는 V5와 같은 방법으로 재구성한다. 선명한 합성선이 약한 질감의 사진에서도 과도하게 드러나는 현상을 줄이되, 무늬가 아예 없어지지 않도록 합성 대비 하한을 둔다.

V6는 원본 공간 배열에 의존하는 질감 에너지 요약을 추가한다. 따라서 V5의 구역 내 픽셀 순열 불변성을 그대로 주장하지 않는다. 새 에너지 요약을 고정한 상태에서 기존 색상·주름 요약을 보존하며 원본 픽셀을 섞는 검사로, 합성 단계에 숨겨진 원본 잔차 경로가 없는지 확인한다. 이 검사는 생체정보 제거의 증명이 아니다.

## 유지 계약

원본 해시·캐시 마스크·native 결과 결합, fresh output, EXIF/ICC·PNG 재읽기, 영역 밖 RGB·이미 승인된 native 픽셀 보존을 유지한다. 후보 전체를 생성 RGB로 교체하며, 기존 native 거절을 native 성공으로 바꾸지 않는다. 기존 전역 안전 제한과 영역 4 MiPixels·bbox 8 MiPixels·256개 제한을 유지한다.

```text
python ai/scripts/replace_photo_synthetic_v1.py --input ORIGINAL --protection-run VERIFIED_NATIVE_RUN --output FRESH_OUTPUT --renderer v6
```

## 개발 확인 — 2026-10-17

관련 단위·입출력·회귀 검사 **66개 통과**. V6 새 7개와 잔존 복사 진단 2개를 포함하며 과거 테스트 수를 누적하지 않았다. 정답 명암을 아는 합성 경계에서 평균 RGB 절대 오차가 2.361→1.129로 감소했다. 흐린 합성 입력에서는 독립 합성 무늬 강도가 낮아지는 것을 확인했다. 결정성·평행 이동·배경 독립성·작은 영역·구멍·잘못된 입력·자원 제한·native 승인 픽셀·원본 결합·EXIF/ICC를 검사했다.

기존 개발 사진 **6장·16개 영역·4,703,163화소**를 동일 seed·동일 마스크로 재처리했다. 모든 원본 해시와 영역 밖 RGB·저장 RGB가 보존됐다. 미처리 후보·질감 생성 불가 영역은 0개다. 이는 전체 사진의 지문 검출 누락이 0이라는 뜻이 아니다.

기존 고정 경계 구역에서 측정한 RGB 평균 불일치는 6장 중 3장 감소, 3장 증가했다. 전 사진의 경계 색상 정확도가 좋아졌다고 주장하지 않는다. 전체 사진 6장과 손끝 16개 확대 비교에서 과도한 선명도와 경계의 단절이 완화됐으나, 매끈한 피부 표현·작은 외곽 오차·첫 관절의 잘린 경계·약한 주름 소실은 남는다. 해부학적 경계를 확정할 인간 정답 마스크는 이 6장에 없으며, 외관만으로 정확한 과대/과소 범위를 수치화하지 않는다.

## 잔존 복사 진단의 범위

`photo_synthetic_residual_audit_v1.py`는 지정 마스크 내부의 같은 위치에서 원본/결과 고주파 상관을 검사한다. 원본을 그대로 두는 결함은 합성 시험에서 표시하고, 독립 무늬나 원본부터 무늬가 없는 경우를 구분한다. 절대 상관 0.65는 미보정 개발용 검토 기준이며 보호 승인 기준이 아니다. 경고가 없어도 검출 누락·이동/회전된 원본 무늬·재식별 가능성을 배제하지 않는다. 마스크 밖 보존된 피부와 첫 관절보다 몸쪽 피부는 별도 범위이며, 이 진단이 사진 전체를 보호한다고 판정하지 않는다.

실제 16개 영역의 346개 구간 중 318개가 비교 가능했고, 28개는 질감 근거가 부족했다. 검토 표시 0개, 최대 절대 상관 0.2365였다. 이는 이 진단에서 원본 직접 복사 징후가 기준을 넘지 않았다는 관찰이다. 원본에서 만든 넓은 색상·주름·에너지 요약값의 정보량이나 식별 가능성을 검증한 수치는 아니다.

## 실제 매칭과 실행기

V5와 같은 고정 32개 ROI(16개 영역 × 전체 bbox/내부 사각형), 전처리, seed로 실제 저장 RGB를 비교했다. 두 엔진의 실행 오류는 없었다. 점수나 특징점 수에 맞춰 seed·파라미터를 바꾸지 않았다.

| 엔진·ROI | V5 유효/16 | V5 점수 중앙값 | V6 유효/16 | V6 점수 중앙값 |
| --- | ---: | ---: | ---: | ---: |
| NBIS 전체 bbox | 12 | 0 | 3 | 0 |
| NBIS 내부 사각형 | 1 | 0 | 0 | 자료 부족 |
| SourceAFIS 전체 bbox | 0 | 자료 부족 | 0 | 자료 부족 |
| SourceAFIS 내부 사각형 | 0 | 자료 부족 | 0 | 자료 부족 |

유효 조건은 원본/결과 모두 특징점 10개 이상·정상 점수 반환이라는 개발용 기준이다. 원본부터 특징점이 부족한 경우가 많고 V6의 합성 무늬도 약해져 유효 비교 수가 줄었다. 유효 표본 구성이 다르므로 이 표를 보호 성능 개선으로 해석하지 않는다. 원본 self는 같은 손가락의 독립 촬영 참조가 아니며, 점수 0·특징점 부족·추출 실패는 보호 성공 집계에서 제외한다.

합성 전용 Windows 실행기를 V6로 연결하고 실제 JPEG 한 장을 경로 인자로 전달했다. 검출→경계 보정→기존 native 거절→V6 합성→PNG 저장까지 실행했으며 620,040화소 교체, 원본 해시·범위 밖 RGB·EXIF/ICC·기존 비교 마스크 일치를 확인했다. 파일 선택 UI는 재시험하지 않았다. 이후 안내 문구에서 기존 native 중간 결과와 최종 합성 결과를 구분했고 PowerShell 구문 검사를 통과했다.
