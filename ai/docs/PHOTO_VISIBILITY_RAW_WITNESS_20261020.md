# 지문 가시성: 연속 구간과 원본 봉우리 증거

기존 [V5/V6 점검](PHOTO_VISIBILITY_SUPPORT_SPATIAL_20261020.md)의 오탐 1개·
누락 10개를 조사했다. **V9 실험에서 오탐 0개·누락 6개**, 기존 보임 관측
손실 0개를 확인했다. 다만 사람 불확실 1개가 새로 관측됐다. V9는 개선
후보이며 V5 기본 진단·실제 실행기·자동 보호 조건을 교체하지 않는다.
여기서 버전 번호는 가시성 진단이다. frozen 보호 V4·합성 V19와 다르다.

## 발견한 문제

- 기존 `peak_train`은 검사선 전체 봉우리의 간격 변동과 모든 중간 골을
  요구했다. 선명한 반복 구간 옆에 주름이 끼면 전체가 탈락할 수 있다.
- 이름과 달리 봉우리·골은 원본 밝기 자체가 아니라 Gaussian 배경 제거
  잔차에서 검출됐다. 잔차의 오르내림만으로 원본에서 같은 반복을 사람이
  볼 수 있다고 결론 낼 수 없다. 잡음 대비가 높아도 이 문제가 남는다.
- 합성 단조 증가 신호 `30 + s*x + 0.8*sin(2*pi*x/4)`에서
  `s = 1.05*2*pi*0.8/4`, 길이 56이면 잔차 방식이 반복을 통과시켜도
  원본에는 실제 봉우리·골이 없다. V9는 이를 거절한다.
- 남은 6개 모두 사람 대표 사각형 안에 유효한 검사 중심이 20~50개 있었다.
  단순한 좌표 누락은 아니다. 방향 증거와 원본 반복 조건이 부족하고,
  최대 연결 창 수가 0~2개여서 4개 조건에 미달한다.

## 보존한 실험 버전

| 버전 | 변경 | 판단 |
|---|---|---|
| V7 | 두 검사선 간격을 창의 1/4로 확대, 주파수 bin 오차 범위 내 위치 정렬, 전체 ring 방향 거절 제거 | 기존 보임 7개 손실. 채택하지 않음 |
| V8 | 기존 V5 조건에서 가장 긴 연속 유효 봉우리 구간을 선택. 중간 봉우리를 건너뛰지 않으며 최소 4개·중간 골·간격 기준 유지 | 보임 3개 복구, 오탐은 남음, 불확실 1개 증가 |
| V9 | V8 구간 선택을 유지하되 약한 평활만 한 **배경 제거 전 원본 밝기**에서 봉우리·골 확인 | 보임 4개 복구, 기존 오탐 제거, 불확실 1개 증가. 개선 후보로 보존 |
| V10 | V9의 원본 증거는 유지하고 전체 ring 방향 거절만 제거 | V9보다 보임 1개 추가, 오탐 재발 및 불확실 2개 추가. 채택하지 않음 |

V9는 배경 제거를 전부 없애는 방식이 아니다. 잔차는 주파수 제안, 대비
규모와 검사선 상관에 사용하고, 봉우리·골의 존재 증명에는 원본을 사용한다.
두 검사선의 선택 구간은 겹쳐야 한다. 검사선은 같은 영상에서 얻으므로
독립 생체 증거가 아니다. 검사 창의 연결은 기존과 같은 8-neighbour 규칙이다.

V9의 주파수 대역, 가설 수, 봉우리 수, prominence 상수, 간격 변동,
간격 일치, 상관, 연결 창 기준은 V5의 값을 유지했다. 특정 파일·사람·
사각형에 대한 예외는 없고 여러 방법의 결과를 사후 합치지 않았다.

## 측정 결과

개발 23장: 사람 보임 44개 중 V5 34, V7 27, V8 37, V9 38, V10 39개 관측.
V9/V10은 기존 V5 보임 관측을 모두 유지했다. 음성 불일치는 V5/V7/V8/V10
각 1개, V9 0개였다. 개발 불확실 관측은 각각 0/1/1/1/3개다.

전체 30장·67영역에는 이미 소비된 GT7의 기록 재실행도 포함된다.

| 사람 판정 | 영역 | V5 | V7 | V8 | V9 | V10 |
|---|---:|---:|---:|---:|---:|---:|
| 보임 | 53 | 43 | 36 | 46 | 47 | 48 |
| 관찰되지 않음 | 6 | 1 | 1 | 1 | 0 | 1 |
| 불확실 | 8 | 0 | 2 | 1 | 1 | 3 |

표의 숫자는 후보 신호 관측 수다. 가시성 정확도·보호 성공률·독립 성능이
아니다. 사람 사각형은 결과의 위치 검토에만 사용했다. 새 보임 관측 4개에서
사람 사각형과 겹치는 자동 검사 창을 원본으로 확인했으며, 약한 질감과
주름이 섞인 사례도 포함된다. AI 검토로 사람 정답을 바꾸지 않았다.

각 실험의 코드·상수를 실행 전에 해시로 고정하고 개발 영역을 먼저,
GT7을 마지막에 확인했다. 새 방법은 이전 개발 결과의 분석에서 도출했으며
자료를 이미 보았으므로 블라인드 평가가 아니다. GT7을 이용한 조정은 하지 않았다.

V7/V8/V9는 각각 67영역·102해상도 단계를 실제 검사했다. V10은 불필요한
반복을 줄이기 위해 V9 양성 48영역에서 연결된 4개 창을 다시 검사했다.
원본·mask·보간·창 위치를 확인한 이 증거는 동일한 최종 양성 판정에 충분하다.
나머지 19영역은 모든 예정 해상도를 검사했다. V10의 모든 창을 다시
계산하거나 다른 버전과 공정한 속도 비교를 했다고 주장하지 않는다.

## 채택 조건과 한계

실험 전에 보임 관측 증가, 기존 보임 손실 없음, 음성·불확실 관측 증가
없음을 선호 조건으로 기록했다. V9도 불확실 1개 증가 때문에 이 조건을
완전히 충족하지 못했다. 결과를 보고 조건을 바꾸지 않고 **기본 V5 유지,
V9 실험 후보 보존**으로 결정했다. 사람이 불확실로 표시한 것을 정답 음성이나
오탐 확정으로 취급하지도 않는다.

원본 봉우리 조건은 강한 음영 아래 실제 지문도 놓칠 수 있다. 주기적인
일반 피부 무늬·직물 등을 지문과 완전히 구별하는 의미 모델도 아니다.
음성 6개는 2사진·1촬영 그룹에 치우쳐 있어 0/6을 일반 오탐률 0%로
해석할 수 없다. 독립 촬영·교정 검증이 없으므로 자동 보호 연결은 보류한다.
추가 촬영이 불가능하다는 현재 사용자 조건을 유지하며 기존 라벨링을 요구하지 않는다.

모든 새 출력은 `automatic_visibility=uncertain`, `used_by_protection=false`,
`renderer_binding_allowed=false`다. 실패를 지문 없음으로 해석하지 않는다.
실제 실행기·보호 renderer·scanner·원본·사람 라벨은 변경하지 않았다.

## 검증

새 단위 테스트 19개와 관련 기존 회귀 8개, **27개 통과**. 곡선·회전·약한
선·교차 주름, 38개 잡음/비주기 대조, 실제 연속 구간, 최소 반복 수,
단조 증가 신호의 잔차 오인, 결정성, 마스크 밖 픽셀 차단, 축소·입력 계약을 검사했다.
V9의 첫 8픽셀 주기 합성 fixture는 잔차 통과를 재현하지 못해 테스트가
실패했다. 해석적으로 단조 증가하면서 실제 재현되는 4픽셀 주기 fixture로
바로잡았으며 알고리즘 상수는 변경하지 않았다.

실행한 관련 회귀: `test_photo_visibility_peak_train_probe_v4`,
`test_photo_visibility_support_v1`. 새 테스트는 V7/V8/V9/V10 각각의 모듈이다.
이전 전체 79개를 이번에 모두 다시 실행한 것은 아니다. Windows Python 3.11.9,
NumPy 2.2.6, OpenCV 5.0.0, SciPy 1.15.3 환경의 결과다. Linux·GUI·matcher·
독립 자료·최종 RGB 보호 성능 검증을 새로 수행하지 않았다.

비공개 결과는 `outputs/visibility-raw-witness-20261020/report.html`과
각 버전별 protocol/result/hash 기록에 보관한다. 공개 저장소에는 사진·마스크·
개인 진단 JSON·리뷰 이미지·모델 가중치를 포함하지 않는다.
