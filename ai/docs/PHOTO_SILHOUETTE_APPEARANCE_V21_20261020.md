# V21 보호 마스크와 피부 외관 경계 분리

## 결과

기존 개발 사진 23장·사람이 보임으로 확인한 44영역의 저장 V19 반환에
별도 V21 외관 보정을 적용했다. 43영역은 보정 채택, 1영역은 V19 유지다.
이는 보호 성공률이 아니다. 44영역 모두 이미 V19 합성이 적용된 상태다.
GT7·독립 holdout을 이번 외관 개발에 사용하지 않았다.

44개 비교를 모두 시각 검토했다. 여러 사례에서 피부·배경 사이의 흰
테두리와 마스크 꼭짓점 주변의 색 단절이 눈에 띄게 줄었다. 일부 진한
경계 띠, 관절 부근의 이음새, 다각형의 흔적과 매끈한 질감은 남는다.
전체 자연스러움이나 일반 보호 성능을 승인하지 않았으며 기본 V19를
교체하지 않았다. CLI의 명시적 선택 경로로만 연결했다.

## 원리와 보존 계약

기존 보호 허용 마스크를 실제 피부 외곽으로 취급하면, 피부 밖까지
그려진 부분에는 피부색이 생기고 안쪽으로 잘린 부분에는 테두리가 남는다.
V21은 허용 마스크를 그대로 유지하며 별도의 외관 경계를 추정한다.

`photo_silhouette_appearance_v21.py`는 마스크 외곽을 따라 최대 192개
표본 위치를 정한다. 각 위치에서 접선 방향 평균 RGB의 법선 프로파일을
단일 흐린 색상 계단과 선형 음영으로 맞춘다. 내보내는 정보는 경계 위치·
흐림 폭 2개와 색 계수 9개뿐이다. 원본의 필터링 영상, 지문 위상 또는
원본 픽셀 알파를 출력에 전달하지 않는다. 경계 밖 원본도 이 거친 통계에
사용하므로 원본 의존성이 없다고 주장하지 않는다.

색 대비·단일 경계 설명력·폭 조건을 통과하고 인접 3개 이상의 표본이
지지하는 구간만 재구성한다. 이 조건은 개발 사진 재생 전에 합성 사례로
정했으며 검출·피치·특징점·가시성 기준을 변경한 것이 아니다. 추정한
피부·배경 색에 기존 생성 결과에서만 추출한 질감을 결합하고, 안쪽에서는
기존 생성 결과로 연결한다. 원본과의 알파 혼합은 없다.

허용 영역 축소·확대는 없고, 허용 영역 밖과 보류 영역의 RGB는 원본과
동일하다. 보정 깊이보다 안쪽의 생성 지문 RGB도 V19와 동일하다.
단일 경계가 불분명하거나 구멍·지원 크기 초과·문맥 부족이 있으면 해당
영역의 V19 결과를 유지한다. 여러 연결 성분은 별도로 처리한다.
거절된 보호 영역을 외관 보정이 새로 활성화하지 않는다.

## 검증

- 합성 곡선 복원, 주름·완만한 음영·반복선 거부, 회전 좌표,
  결정성·입력 보존·메모리 제한·구멍·보류 영역과 통합 계약 포함
  **40개 테스트 통과**. 기존 V19 9개와 V20 4개 회귀 포함.
- 실제 CLI에서 현재 검토 사진의 V19 생성부터 V21·PNG 저장까지 재실행.
  같은 seed로 재생한 비교 실험과 저장 RGB가 완전히 일치하고 적용 마스크도 같다.
- 원본/GT 파일 60개, 기존 V19 반환 30개, V20 반환 23개 해시 보존.
  새 반환 23개는 저장·재읽기 검증 및 소스·사람 검토 상태 고정 확인.
- 기존 잔존 질감 경고 3개 → 2개. 새로운 경고 영역은 없지만 경고를
  삭제하거나 특징점/매칭 성공으로 해석하지 않았다. V21 matcher 재검사는 미실시.
- 전체 경계 프로파일 평균 색 오차 검사는 개선됐다. 그러나 채택된
  1,816개 국소 표본 중 651개는 오차가 증가했다. 이들의 RGB RMSE 증가
  중앙값은 약 0.66, 최대 약 3.05다. 평균 개선을 모든 위치의 개선으로
  주장하지 않는다. 이 검사는 피부 정답·자연스러움·보호 성능 검사가 아니다.

개발 중 잘못 지정한 테스트 모듈명, 파일럿 집계 기대값 오류, 다중 성분을
단일 성분 함수에 직접 넘긴 평가 도구 오류를 수정했다. 최종 검사는 실제
사용되는 다중 성분 어댑터로 완료했으며 이전 실패 기록도 보존했다.
회전 시 OpenCV 외곽의 시작점에 따른 표본 위치 차이는 마스크 기하를
기준으로 표본 시작점을 잡도록 수정했다. 완전한 회전/플랫폼 비트 동등성은
주장하지 않는다. Linux·Android 및 새 촬영 독립 검증은 미실시다.

## 실행

기존 사람 검토가 완료된 roster/state와 새 출력 폴더를 사용한다.

```powershell
python ai/scripts/photo_visibility_reviewed_apply_v1.py `
  --roster <private-roster.json> --state <private-state-folder> `
  --source-id <reviewed-source-id> --output <fresh-output-folder> `
  --appearance silhouette_v21
```

`photo_visibility_reviewed_batch_v1.py`도 같은 `--appearance silhouette_v21`
선택을 지원한다. 생략하면 기본 V19다. 사람 검토를 자동 판정으로 대체하지
않는다. 원본, 기존 결과, frozen V4·스캐너 및 V19 수학은 보존했다.

다음 개선 과제는 피부 안쪽의 관절 이음새와 음영/재질 연결이다. 물체
외곽용 단일 경계 모델을 관절에 억지로 적용하지 않는다. 별도 국소 검증과
독립 사진이 필요하며, 마스크 밖에 남은 피부/지문은 이번 보정이 해결하지 않는다.
