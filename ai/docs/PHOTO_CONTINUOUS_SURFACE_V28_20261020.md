# V28: 반점·광택을 줄인 연속 지문선 재질

## 문제와 원인

사용자는 원래 지문 복원 대신 독립적인 지문을 자연스럽게 합성하려는 의도를 재확인했고,
V27 처리본의 무늬가 기괴하다고 평가했다. V27의 강도 하한은 지문선뿐 아니라
V19 재질의 생성 모공·희소한 선 끊김·미세면 반사와 추가 잔주름도 함께 강조했다.
작은 손끝에서 최소 4화소 간격과 이런 표현이 겹쳐 흰 점·비늘 같은 표면이 두드러졌다.
무늬가 보인다는 것과 자연스럽게 보인다는 것을 구분해야 한다.

## 변경

`photo_continuous_surface_v28.py`는 예방적 합성 영역의 재질만 바꾼다.

- 같은 독립 시드의 arch/loop/whorl 방향장으로 연속적인 지문선 단면을 만든다.
- 작은 손끝에서도 전체 설계 공간을 사용하고, 손끝 가로 폭에 따른 약 30~38선의 합성 밀도를 목표로 한다.
  실제 지문 간격이나 mm 크기를 측정한 값은 아니다. 설계 간격의 상하한도 적용한다.
- 손끝 곡면 좌표에 투영하고, 작은 표면은 최대 3배로 계산한 뒤 생성 신호만 카메라 화소 크기로 샘플링한다.
- 생성 모공, 임의 선 절단, 추가 잔주름, 강한 specular 반사를 사용하지 않는다.
  낮은 대비의 확산 명암을 사용하고 반사 하이라이트를 제한한다.
- 기존 피부의 큰 색 변화·넓은 주름 요약과 V23 경계 결합은 유지한다.
- 적용 허가·검출·경계·원본 지문 관측·HTTP 경고는 바꾸지 않는다.
  적용 밖과 미적용 영역은 원본 RGB 그대로다.
- 새 재질로 지정하지 않은 성분과 빈 선택은 기존 V19 결과·보고서를 유지한다.

V19에는 요청 범위의 선택적 재질 콜백만 추가했다. 기본 실행은 기존과 같다.
V27 모듈은 당시 결과 재현을 위해 보존하지만, 현재 예방적 합성에는 V28을 쓴다.
전송 엔진은 계속 `synthetic_v23`, 선택 정책은 계속 V26이며 비공개 renderer 보고서에 V28 재질을 기록한다.

## 확인 범위

제공 사진은 이미 수정에 사용한 개발 자료다. 시드 `20261020`을 유지했다.
먼저 기존 검출 후보로 재질만 시험하고, 이어 실제 모델의 검출부터 최종 PNG/전송까지 다시 실행했다.
두 실행을 혼동하거나 재질 시험을 전체 추론·속도 측정으로 제시하지 않는다.

전체 실행에서 후보 4개 중 검지·중지 2개 영역이 적용됐고 2개는 미적용이었다.
BODY/TIP·raw V6·자세 소유 영역·경계·후보/허용/적용 마스크는 이전 V27과 화소 단위로 같았다.
PNG/전송 RGB·적용 밖 보존을 검증했고, 재질 시험과 전체 실행의 반환 RGB도 일치했다.
이번 AI 소스 묶음 SHA256은 `2c85cf25116226da815b80aa61672f10181c775fb70170a45bd23ec391220059`다.
90개 pytest와 기존 검토 렌더러/성능 계약 20개 unittest가 통과했다.
전체 실행 약 132.51초는 회귀와 겹쳤으므로 이전 시간과 비교하거나 속도 목표 달성 근거로 쓰지 않는다.

수정 전·후는 같은 손끝 좌표를 같은 크기로 비교한다. 원래 지문을 복원한 결과가 아니며,
형태의 자연스러움에 대한 최종 판단은 비교 이미지로 검토해야 한다.
`natural_appearance_validated`와 일반 보호 효과 플래그는 계속 false다.

공개 검사는 지정 성분만 변경, 다른 성분의 기존 RGB 일치, 원본·적용 밖 보존,
같은 시드의 재현과 다른 시드의 변화, 실제 양자화 출력의 대비·과도한 밝기 제한을 확인한다.
이 수치는 자연스러움 점수가 아니다. 실제 전체 실행·정확한 통과 수·남은 범위는
[작업 기록](../../docs/worklogs/2026-10-20-이봉헌-continuous-surface.md)을 따른다.
