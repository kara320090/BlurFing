# 가시성 누락의 국소 감사와 원본 반복 관측 V4

후속 점검에서 V2/V3/V4의 AREA 마스크 보간 수치 오류를 확인했다. 당시 결과와
코드는 보존한다. 이후 진단에는 [V5 수정과 V6 비교](PHOTO_VISIBILITY_SUPPORT_SPATIAL_20261020.md)를
확인해야 하며 아래 수치를 오류 수정 후의 알고리즘 순위로 해석하지 않는다.

가시성 진단 실험 버전이다. 보호 렌더러 frozen V4와 별개이며 V19 합성, scanner,
기존 실행기·보호 조건을 변경하지 않았다. 이전 V1~V3 결과는 그대로 보존한다.

## 원인을 확인한 방법

이전 선형 조명 제거 진단이 놓친 사람 `visible` 26영역의 원본을 문맥과 1:1
픽셀로 검토했다. 30장·67영역 모두 원본·마스크·decoded RGB 결합을 확인하고
해시로 묶인 비공개 ROI 캐시를 생성했다. 사람 표시 사각형은 감사·표시에만
사용했다. 새 V4 관측기의 입력은 원본 회색조와 해부학적 마스크뿐이다.

`photo_visibility_local_audit_v1.py`는 native 32픽셀 창에서 기존 선형 조명 제거
조건을 재현하고 대비·방향 일관성·주파수 에너지 집중도·방향 분산·포화를 기록한다.
사람 표시 안의 창과 전체 ROI의 창을 구분하며 측정값을 흐림/반사 정답으로
자동 변환하지 않는다.

- 26개 중 12개의 사람 표시 구간에서 모든 검사 창의 대비가 기존 기준 8 미만이었다.
  실제 무늬가 없어서라기보다 약한 세부 신호를 고정 대비 기준이 거절할 수 있다.
- 전체 ROI에서 에너지 집중도 조건 하나만 가상 제거하면 26개 모두 4창 이상을
  확보했다. 이는 원인 분리용 반사실 검사이며 기준 삭제의 타당성이나 지문 검출
  성공을 뜻하지 않는다. 사람 표시 구간의 대비 결과와 동일 창 집합도 아니다.
- 반사로 보이는 하이라이트, 부드러운 무늬, 큰 주름과 거친 질감이 함께 관찰됐다.
  초점·흔들림·축소·압축의 물리적 원인은 단일 사진만으로 확정하지 않았다.
  표시 구간의 포화 비율은 모두 1% 미만이지만 포화 없는 반사도 가능하다.
- 26개 모두 사람 표시 안에 원본 검사 창이 있었다. 누락 전체를 경계 오류로만
  설명할 수 없다. 사람 마스크를 사용했으므로 자동 검출 경계 성능은 평가하지 않았다.

AI의 시각 관찰은 별도 비공개 기록이다. 기존 사람 라벨은 수정하지 않았다.

## 새 관측 방식

`photo_visibility_peak_train_probe_v4.py`는 다음 별도 가설을 시험한다.

1. 32/64픽셀 창에서 Gaussian 평활 성분을 분석용으로 빼 느린 조명의 영향을 줄인다.
2. 기존 주파수 범위 .065~.30에서 최대 3개의 방향·간격 가설을 얻는다.
3. 원본에서 서로 떨어진 두 밝기 profile을 읽고 각 profile에서 최소 4개의
   봉우리와 그 사이 골을 확인한다. 간격의 작은 변화는 허용한다.
4. 두 profile의 간격·신호 일치와 이웃 창의 관측을 함께 확인한다.

분석용 조명 제거는 사진 복원이나 지문 생성이 아니다. 관측용 주기는 working pixel
단위이며 렌더러나 물리 DPI로 전달하지 않는다. 두 profile은 같은 영상의 증거로,
통계적으로 독립적이지 않다. 여러 창·해상도도 독립 표본으로 세지 않는다.

원본/마스크를 변경하지 않고 전체 창 및 AREA 축소 입력 범위가 마스크 안에
있을 때만 검사한다. 입력·할당 검증을 재사용한다. 모든 결과는 다음을 유지한다.

```text
automatic_visibility=uncertain
calibrated_visibility_probability=null
used_by_protection=false
renderer_binding_allowed=false
absence_inferred_from_failure=false
```

이것은 반복 신호 관측기다. 주름·반복 피부 질감·직물 등과 지문을 구별하는
검증된 분류기가 아니다. 새 실험 상수는 합성 대조 후 고정했으며 기존 생산
알고리즘의 대비·pitch·feature 임계값은 변경하지 않았다.

## 고정 비교 결과

개발 23장을 먼저 실행하고, 고정한 코드로 소비된 GT7 기록을 마지막에 재실행했다.
코드·상수·캐시 해시와 사람 주석 불변성을 확인했다. GT7 결과에 맞춘 수정은 없다.
이미 본 라벨·이전 결과·원본을 사용했으므로 독립 또는 블라인드 검증이 아니다.

| 범위 / 사람 판정 | 영역 수 | 기존 | 선형 조명 제거 | V3 | V4 |
|---|---:|---:|---:|---:|---:|
| 개발 / 보임 | 44 | 17 | 19 | 17 | 34 |
| 개발 / 관찰되지 않음 | 6 | 0 | 0 | 0 | 1 |
| 개발 / 불확실 | 7 | 0 | 0 | 0 | 0 |
| 전체 / 보임 | 53 | 24 | 27 | 25 | 43 |
| 전체 / 관찰되지 않음 | 6 | 0 | 0 | 0 | 1 |
| 전체 / 불확실 | 8 | 0 | 0 | 0 | 0 |

선형 조명 제거 대비 개발에서 15개, 전체에서 16개 추가 관측했고 기존 관측
손실은 0개다. V3 대비 전체 추가 18개·손실 0개다. 이전 결과와 사후 OR 결합한
숫자가 아니라 V4 단독 결과다. 아직 사람 보임 10영역은 미관측이다.

사람 음성 1개에서 약한 세로 질감이 반복 증거로 통과했다. 원본은 하이라이트와
부드러운 질감이 보이며, 같은 구조가 진짜 지문인지 확정할 수 없어 사람 판정을
변경하지 않았다. 자동 가시성으로 해석하면 오탐에 해당하는 불일치다. 여러
간격 가설을 허용하면 약한 신호 관측과 비지문 질감 수용이 함께 늘 수 있다.

**진단 실험으로 보존하되 자동 보호/제외 조건으로 승격하지 않는다.** 표는 신호
관측 수이며 일반 분류 정확도·자동 보호 적용률·보호 성공률이 아니다. 음성
6영역은 한 촬영 그룹의 두 사진뿐이다. 현재 추가 자료가 불가능하므로 독립
검증·그룹별 학습/교정은 보류하며 기존 라벨링을 다시 요구하지 않는다.

## 검증과 남은 한계

국소 감사 2개·V4 4개와 기존 회귀 66개, 합계 **72개 테스트 통과**.
V4 대조에는 낮은 대비·회전·소수점 간격·큰 주름을 섞은 16개 영상,
가변 간격 profile, 평면·경계·희소 주름·일반/평활 잡음 38개 음성 영상,
마스크 밖 무늬의 resize 유입·결정성·입력 보존이 포함된다.

가변 간격의 최초 양성 fixture가 선언된 주파수 범위를 벗어난 문제가 있었다.
그 fixture를 거절 대조로 보존하고 범위 안의 양성 fixture를 추가했다.
이 과정에서 알고리즘이나 실험 상수를 완화하지 않았다.

```powershell
# ai/scripts 에서 실행
python -m unittest -v test_photo_visibility_local_audit_v1 test_photo_visibility_peak_train_probe_v4
```

합성 대조 통과는 자연 피부의 비지문 질감 구별을 보장하지 않는다. 약한 세부
신호와 혼합 질감을 구별할 별도 음성 사례 및 독립 촬영 그룹이 남은 검증 조건이다.
범용 사진 품질 원인을 확정하는 분류기, 자동 손끝 검출을 포함한 end-to-end
성능, 보호 성능 및 새 경로의 Linux 동등성은 이번에 검증하지 않았다.

현재 가능한 원본 검토·원인 측정·새 관측 실험·비교·회귀 점검은 완료했다.
개인 원본, 캐시, 표시 이미지, 상세 진단 JSON과 HTML 보고서는 저장소 밖에 보관한다.
