# 경계 외관 V20 후보와 Windows NBIS 후속 검증

## 결론

NBIS의 이전 미완료 검사를 같은 106 ROI·212영상·318쌍으로 완료했다.
V20 경계색 보정은 실험으로 보존하고 기본 V19를 교체하지 않았다.
자동 가시성·검출·보호 성능을 새로 승인한 작업은 아니다.

## Windows 실행 오류

이전 두 NBIS 작업은 서로 다른 단계에서 프로세스 시작이 `WinError 5`로
실패했다. 같은 실행 파일과 입력의 실패했던 매칭 명령은 이번에 20회 모두
같은 출력으로 성공했다. 읽은 Defender·CodeIntegrity 로그에는 해당 실행
파일의 차단 기록이 없었다. 이것만으로 운영체제 원인을 확정할 수는 없다.

Windows 어댑터에 명시적인 `max_launch_retries=0..2` 선택 인자를 추가했다.
기본값은 계속 0이다. 2를 선택하더라도 프로세스 생성 전의 `WinError 5`만
0.5초·1초 뒤에 재시도하며, 예산은 개별 명령이 아닌 작업 전체가 공유한다.
실행 파일 해시를 다시 확인하고 추출 결과가 이미 있으면 중단한다.
시작된 명령의 종료 실패·시간 초과·파이프 IO·잘못된 출력은 재시도하지 않는다.
모든 시도는 감사 기록에 남고, 실패를 점수 0이나 비일치로 바꾸지 않는다.
실행 파일·권한·보안 설정은 변경하지 않았다. 공통/Linux API도 그대로다.

전체 재실행은 약 58.9초에 끝났으며 **실제로 사용한 재시도는 0회**였다.
제한된 재시도는 합성 오류 시험에서 검증했지만 실제 오류를 그 기능으로
복구했다고 주장하지 않는다. 운영체제 근본 원인은 미확정이고 재발 가능성이 남는다.

| NBIS 범위 | 원본 자기 비교 중앙값 | 원본→반환 계산 가능 | 원본→반환 중앙값 / 최대 |
|---|---:|---:|---:|
| 전체 bbox | 805 | 51/53 | 10 / 128 |
| 내부 정사각형 | 499 | 47/53 | 5 / 18 |

원본 자기 비교의 계산 가능은 각각 53/53·48/53이다. 원본→반환의 나머지
2쌍·6쌍은 특징점 부족이며 보호 성공이 아니다. 기존 500 DPI 가정,
512px·CLAHE 전처리와 양쪽 특징점 10개 기준을 유지했다. 전체 bbox에는
마스크 밖이 들어가고 내부 정사각형은 손끝 일부만 본다. 독립 촬영 지문과의
식별 불가능성이나 일반 보호 성공률을 증명한 결과가 아니다.

## 외관의 원인과 V20 후보

기존 경계 재구성은 원본의 구간별 RGB 통계를 사용하지만, V19는 각 보정을
최대 16단계로 제한한다. 큰 피부·배경 색 차이가 있는 합성 재현에서는 이
제한 때문에 정답 평균 경계색까지 복원할 수 없음을 확인했다.

`photo_contour_color_v20.py`는 원본 픽셀을 혼합하는 대신, 같은 경계 통계의
관측 범위 안에서 보정 곡선을 보간한다. 기존 최대 192개 노드·최소 24픽셀
표본·3개 관측 깊이·PCHIP과 RGB8 경계색 검사를 유지한다. 새 측정 지문 간격,
원본 고주파 잔차, 원본 알파, 기증 지문은 넣지 않았다. 경계 통계가 원본에
의존한다는 사실은 그대로이며 이를 생체 정보 제거 증명으로 해석하지 않는다.

후보를 고정한 뒤 기존 개발 **23장·보임 44영역**의 실제 저장 V19 반환에
적용했다. GT7과 독립 holdout은 이번 외관 개발에서 사용하지 않았다.
19영역은 평균 경계색 검사에서 보정이 채택됐고 25영역은 V19로 유지됐다.
이는 보호 적용 19/44라는 뜻이 아니다. 44영역은 이미 V19가 적용된 상태다.
원본·정답 마스크, 허용 영역 밖·미처리 영역 RGB 및 경계 밴드보다 깊은
합성 RGB는 그대로다. PNG 저장·재읽기와 파일 해시를 확인했다.

잔존 질감 진단의 경고는 기존 3개에서 3개로 유지됐고 새 경고 영역은 없었다.
경고 부재·증가 없음으로 보호 승인을 내리지 않았다. 변경된 19영역을 비교
이미지 5개 모음에서 확인하고, 별도로 두 손끝의 원본·마스크·반환 외곽을
확대했다. 일부 밝은 테두리의 색 차이는 줄지만, 각짐·진한 경계 띠·관절의
단차와 매끈한 질감이 남는다. **뚜렷하고 일관된 자연스러움 개선은 미달**이다.

외곽 확대에서 수동 마스크의 직선 구간이 실제 손끝 곡선과 어긋나는 사례를
확인했다. 마스크 끝까지 피부 질감을 재구성하면 그 다각형이 눈에 보이는
외곽으로 드러난다. 색 오차 개선만으로 이 기하 문제를 해결할 수 없다.
수동 정답을 변경하거나 원본 경계를 그대로 섞어 문제를 감추지 않았다.

## 검증·다음 경계

Windows 시작 복구·실패 보존 9개, V20 경계색 4개, 기존 V19 회귀 9개,
총 **22개 테스트 통과**. 실제 NBIS 전체 실행과 실제 개발 사진 반환은 별도로
확인했다. Linux 동등성·Android·새 독립 사진·실시간 성능은 이번 검증 범위 밖이다.

다음 외관 작업은 보호를 허용하는 마스크와 실제 피부 실루엣을 구분하는
경계 표현이다. 기존 정답을 보존하고 후보 경계는 별도로 생성·검증해야 하며,
마스크 축소로 지문을 남기거나 원본 픽셀 혼합으로 자연스러움을 얻는 방식은
피한다. V20은 연구 후보로만 남고 실행기의 기본 알고리즘은 유지한다.
