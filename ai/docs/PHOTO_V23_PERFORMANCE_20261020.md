# 자동 V23 CPU 처리 최적화

손끝 검출·가시성 판정·V23 합성의 수학과 임계값을 유지하면서 실행 비용을 줄였다.
이전 기준은 `8d5226f`다. 이전 알고리즘 파일과 기존 결과는 삭제하지 않았다.

## 변경

- V23의 독립적인 경계 패치 적합을 최대 4개 프로세스로 계산한다. 노드 결과는
  기존 순서로 수집하고, 기존 `fit_patch`와 최적화 허용오차를 그대로 사용한다.
  풀은 자동 요청 안에서 필요할 때 생성하여 여러 손가락에 재사용하고 종료한다.
  수동 검토·기존 렌더 경로는 기본적으로 직렬 실행한다.
- V19 내부에서 이미 계산한 피부 색면과 경계 보정을 같은 렌더 호출에서 재사용한다.
  재사용 배열은 합계 64 MiB 이내로 제한하며, 초과하는 영역은 기존처럼 재계산한다.
  요청 간 원본이나 계산 결과를 보관하지 않는다.
- 자동 후보 단계는 후속 단계가 사용하는 마스크와 추론·출처 자료만 저장한다.
  곧 버릴 중간 검은 가림 RGB 및 비교 미리보기 생성을 생략한다. 이 중간 결과의
  상태는 `candidates_only_no_protection`이며 보호 완료로 표시하지 않는다.
  기존 검은 가림 실행기와 수동 검토 실행기의 출력은 유지한다.

원본·모델·코드 해시, 입력 계약, 결과 PNG 및 마스크 검증은 생략하지 않았다.
새 관측 임계값, 축소 해상도, 모델 교체, 지문 표현 단순화를 도입하지 않았다.
기존 frozen V4는 변경하지 않았다.

## 실제 전체 경로 측정

동일한 기존 개발 사진 1장(3024 × 4032 RGB), 동일한 모델과 시드로 각 2회
실행했다. 기준 소스는 파일 바이트를 보존한 별도 복사본에서 실행했다.
매번 실제 COLFISPOOF·V6·MediaPipe 검출과 렌더링을 수행했으며, 검출 결과를
재사용하지 않았다. 아래 측정은 cProfile을 끈 값이다.

| 범위 | 기존 | 최적화 후 |
| --- | ---: | ---: |
| 전체 AI 파이프라인 1회차 | 86.81초 | 75.70초 |
| 전체 AI 파이프라인 2회차 | 94.14초 | 82.01초 |
| 전체 AI 파이프라인 평균 | 90.47초 | 78.85초 |
| import를 포함한 평균 | 94.90초 | 82.88초 |

이 사진의 AI 처리 평균은 약 12.8% 감소했다. 두 차례 모두 반환 RGB,
적용 마스크, 거절 마스크 해시가 기준과 정확히 같고 후보 1개/적용 1개였다.
이는 Windows CPU 환경의 작은 반복 측정이며 전체 사진·다른 PC의 지연 보장은 아니다.
사진·가중치·해시와 상세 측정 자료는 공개 저장소 밖의 비공개 출력에 보관한다.

최초 cProfile 측정의 약 110초는 프로파일러 비용이 포함되어 위 표와 직접
비교하지 않는다. 별도 96개 패치 계산 시험에서는 직렬 9.07초, 4프로세스
3.09초였으며 모든 모델 파라미터가 정확히 같았다. 스레드 실행은 더 느려 채택하지 않았다.

## 회귀 검증

- AI 관련 41개 통과. 실제 적합 파라미터·최종 RGB·메타데이터의 직렬/병렬 일치,
  지원되지 않는 경계 노드, 워커 오류 후 정리, 제한된 캐시의 재계산,
  여러 컴포넌트의 대응, 원본 및 마스크 밖 보존을 포함한다.
- 서버·실행기 관련 108개 통과. 입력/출력 계약, 실제 테스트용 자식 프로세스,
  timeout·연결 해제·정리 및 재실행 검증을 포함한다.
  기존 Starlette의 httpx 관련 deprecation warning 1개는 남아 있다.
- 별도 기존 개발 사진 3장에 대해서는 이전 검출 출력만 재사용해 이후 경계·관측·합성을
  다시 수행했다. 후보 12개/적용 11개/경계 불확실 거절 1개이며, 3장 모두 이전의
  같은 시드 결과와 반환 RGB·적용 마스크·거절 사유가 정확히 같다.
  이 검사는 새 모델 추론 성능이나 독립 정확도 평가가 아니다.
- Android 에뮬레이터의 실제 Repository→HTTP→모델 처리→MediaStore 저장 및
  재읽기 1회 통과. 후보 1개/적용 1개이며 저장 바이트 검증까지 약 96.77초였다.
  이전 실행 약 120.91초는 별도 시점·임의 시드였으므로 엄밀한 속도 비교는
  위의 고정 입력·시드 2회 측정을 사용한다. 실물 휴대폰은 이번에 검사하지 않았다.

## 한계

최적화 후에도 이 사진은 AI 처리에 약 76~82초가 필요하다. 검출·경계 준비가
약 50~56초, 그 안의 COLFISPOOF 외부 실행이 약 21~24초를 차지했다.
네트워크 왕복·Android 응답 검증·저장은 위 AI 시간과 별도다.
실시간 처리라고 표현하지 않는다.

출력이 같은지 확인하는 성능 회귀 시험을 새 독립 촬영 평가나 보호 효과 검증으로
계산하지 않는다. 검출 누락, 미보정 가시성 정책, 자연스러움과 보호 효과의 독립
검증은 기존의 미완료 조건으로 남아 있다.

기존 PC 실행기와 APK를 그대로 사용할 수 있다. 이번 변경은 서버가 요청마다
실행하는 AI 소스에 적용되어 있다. 기존 서버의 환경변수를 변경하는 작업은 아니다.
