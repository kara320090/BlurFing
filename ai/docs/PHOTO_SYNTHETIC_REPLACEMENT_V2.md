# 합성 교체 V2 — 저주파 피부 명암과 독립 무늬

V1은 영역당 RGB 중앙값 하나로 채워 피부가 평평하고 동심원이 두드러졌다. V2는 동일한 지정 영역 안에서 넓은 구역의 피부색 중앙값을 최대 3차 다항식으로 재구성하고, 별도 난수로 만든 가는 아치·편심 루프·왜곡된 소용돌이 무늬를 더한다. 피부 명암과 입체감을 개선하는 선택 경로다.

## 원본 정보 사용 범위

- 마스크 좌표로만 주축과 폭을 계산한다. 원본 지문 간격·방향·특징점으로 합성 무늬를 정하지 않는다.
- 색상 구역은 투영 좌표상 최소 약 64픽셀 폭, 최대 8×10개다. 각 구역의 RGB 중앙값만 사용하며, 구역이 부족하면 차수를 낮추거나 단일 중앙값으로 돌아간다.
- 최대 3차 색상 함수는 원본의 완만한 공간적 명암을 유지한다. **V1과 달리 원본의 공간적 정보를 전혀 사용하지 않는 방식은 아니다.** 원본 픽셀이나 고주파 잔차를 합성 결과에 직접 섞지는 않는다.
- 무늬의 간격은 마스크 폭에 따른 생성 파라미터다. 측정된 생체 지문 간격이 아니며, 실제 지문 형태·인식기 유효성을 보증하지 않는다.
- 경계에서는 생성한 무늬의 대비만 낮춘다. 원본으로 되돌리는 alpha/feather는 사용하지 않고 지정 영역의 모든 픽셀을 교체한다.
- 구역 내부 원본 픽셀을 임의로 뒤섞어도 같은 seed의 결과가 완전히 같다. 이는 그 구역 내부의 지문선 위치를 그대로 복사하지 않는다는 데이터 흐름 검사이며, 생체정보 유출이 없다는 일반적 증명은 아니다.

## 연결 및 사용

```text
python ai/scripts/replace_photo_synthetic_v1.py --input ORIGINAL --protection-run VERIFIED_NATIVE_RUN --output FRESH_OUTPUT --renderer v2
```

기본 API/CLI는 V1을 유지한다. `--renderer v2`로 명시적으로 선택하며 원본·마스크·연결 영역·기존 반환 결과의 검증 계약을 그대로 사용한다. 정상 품질 거절 후 가려진 영역을 교체하며 기존에 승인된 native 변환 픽셀은 보존한다. 실행기에서 선택되는 최신 실험 버전은 후속 버전 문서를 참고한다.

기존 `natural_auto_04`, `boundaryblend_02`, 검출·pitch·feature gate는 변경하지 않았다. 이번 비교는 기존 검증 결과와 마스크를 재사용했다. 독립적인 검출 성능 재평가나 새 실행기의 전체 detector→native→합성 체인 재실행으로 보고하지 않는다.

## 검증

155개 단위·계약·회귀 테스트가 통과했다. 알려진 합성 명암 복원, 구역 내부 픽셀 순열 불변성, 난수 재현, 부분 영역과 구멍·빈 마스크, 자원 제한, V1 기본값 픽셀 동등성과 V2 파일 연동을 검사했다. 실제 CLI 1회와 PowerShell 구문 검사를 완료했다.

기존 6장·16개 지정 영역을 같은 seed로 재처리했다. 실제 저장 PNG 재읽기, 영역 밖 RGB·원본 파일 보존, 6장 모두의 구역 내부 픽셀 순열 불변성 검사를 통과했다. 확대 확인에서는 V1보다 명암이 자연스러워졌지만 과도하게 매끈한 피부와 관절 경계 이음새가 남았다. 정답 경계·독립 촬영 자료 평가는 아니다.

## 매칭 비교 원칙

16개 기존 지정 영역 모두에서 바깥 사각형과 완전히 내부에 들어가는 최대 정사각형을 정했다. 결과 점수를 보기 전에 좌표를 고정하고 원본, V1, V2, 검은 가림을 비교했다. 실제 PNG의 같은 좌표를 방향 보정 후 종횡비 유지 512픽셀로 정규화했다. 500 DPI는 개발 평가 가정이며 실제 사진의 물리 DPI를 알아낸 것이 아니다.

NBIS·SourceAFIS 점수, 원본 자기 매칭, 양쪽 특징점 개수를 함께 기록한다. 원본 또는 교체본의 특징점 부족·추출 실패·점수 0을 보호 성공으로 집계하지 않는다. 원본 자기 매칭은 별도 촬영본에 대한 본인 인식률도 아니다. 이 결과에 맞춰 renderer·seed·gate를 조정하지 않는다.

2026-10-17 실제 실행: 두 엔진 모두 128개 ROI 이미지와 128개 비교를 오류 없이 처리했다. 이 전처리 없는 회색조 프로토콜에서는 원본 32개 ROI 전부 특징점이 10개 미만이었다. 따라서 V1/V2의 보호 성능 우열은 판단할 수 없다. 추출 실패나 점수 0을 성공으로 집계하지 않았다. 이 한계와 별개로 합성 V3에서 지문선 질감을 개선한다.
