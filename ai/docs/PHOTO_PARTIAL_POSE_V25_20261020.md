# 자동 V23의 손가락별 자세 처리와 실패 수정

실제 실패 사진을 모델부터 재실행하여 두 가지 중단 원인을 확인했다. V6 가중치와 V23 질감 생성기를 재학습한 작업은 아니며 자동 사진 경로의 후보·소유 영역·경계 연결을 수정했다.

## 재현한 원인

- V자 개발 사진 A: 접힌 손가락의 자세 중간점이 BODY 밖에 있어 `pose_axis_midpoint_outside_BODY`로 요청 전체가 중단됐다. 보이는 검지·중지의 검출 근거도 함께 버려졌다.
- V자 개발 사진 B와 미관측 대조 사진: 실패한 자세 후보 `pose-…`를 V24의 다른 추정기 ID로 조회하여 `local_axis_owner_binding`으로 중단됐다.
- 사람이 지문이 보인다고 판정한 A/B의 두 영역은 현재 자동 raw-ridge 관측기로 이미 반복 증거를 찾을 수 있었다. 과거 관측기의 누락 통계를 현재 관측기의 실패 수치로 재사용하거나 관측 기준을 낮춰 이 오류를 해결하지 않았다.

## 변경한 동작

자동 `synthetic_v23`만 `photo_partial_pose_v25.py`의 별도 자세 정책을 선택한다. 기존 사람 검토 UI와 명시적 V12/V13/V14·기존 자세 경로는 기본 선택을 유지한다.

1. 기존 worker/model/source/방향/해상도 결합을 검사한다. 다른 원본, 손상된 기록, 미고정 모델은 계속 오류다.
2. 각 손가락을 따로 검사한다. 유한한 IP/DIP→TIP 축, 프레임 안의 끝점, BODY 안의 TIP·중간점, 별도 COLFISPOOF의 semantic TIP 픽셀 근거가 필요하다. 접힘·가림·근거 없음은 손가락별 사유로 남기고 다른 유효한 손가락을 중단시키지 않는다.
3. 선택되지 않은 손가락의 유한한 축도 공간을 예약한다. 유효한 한 손가락이 손 전체를 소유하여 다른 V6 후보를 지우지 않도록 한다. 예약은 처리 권한이 아니다.
4. 선택된 손가락의 기존 외곽/주름 경계를 계산한다. 미선택 영역의 기존 모델 후보는 검토 대상으로 유지한다. 원본 좌표의 소유 라벨을 해시로 묶어 전달하며 서로 닿은 손가락·미확인 후보도 독립된 처리 단위로 나눈다.
5. 기존 원본 지문 반복 증거와 V23 렌더러 검사를 통과한 단위만 합성한다. 주름·가시성·렌더링 조건은 그대로이고 미확인 영역은 적용 권한을 얻지 않는다.
6. V24는 자세 소유 ID를 다른 추정기 ID로 변환하지 않는다. 복구하지 못한 자세 경계는 미적용 사유로 남기며 이웃한 정상 후보를 처리할 수 있다.

API 엔진명은 `synthetic_v23`, endpoint는 `/v2/photo/protect`다. V25는 이번 기하 정책의 버전이며 새 학습 모델을 뜻하지 않는다. Android의 원본/결과 결합, 실제 A/R 마스크, PNG 재읽기 계약을 유지한다.

## 해석과 한계

- 두 손끝이 처리됐다는 것과 손끝 전체의 원래 지문 정보가 사라졌다는 것은 별개다. `complete_photo_protection_verified`, `privacy_validated`, `production_approved`는 계속 false다.
- semantic TIP·자세·주름·반복 무늬 모두 오탐·누락할 수 있다. TIP 근거가 없거나 손이 여러 개 관측된 입력은 기존 모델 후보와 미확인 처리를 유지한다.
- 사람 마스크와 실제 적용 범위를 별도로 대조한다. 이미 사용한 개발 사진을 독립 평가로 부르지 않고 불확실 영역을 보이는 지문으로 강제 집계하지 않는다.
- 소스·모델·원본 해시는 private 결과에 기록한다. 사진·지문·실험 응답·가중치는 공개 저장소에 추가하지 않는다.
- 새 V자 사진은 사용자가 다음 메시지에 제공하기로 했다. 수신 후 첫 실행으로 검증하며 현재 새 촬영 일반화 완료로 표시하지 않는다.
