# 합성 교체 V5 — 지문 무늬 변화와 큰 주름

V4의 균일한 합성 지문선과 큰 피부 주름 소실을 개선하는 별도 선택 버전이다. 기존 V1 기본값, V2/V3/V4 경로, frozen 보호 알고리즘과 검출·pitch·feature gate는 그대로다.

## 지문 무늬

원본과 무관한 난수로 완만한 좌표 변형, 굵기 변화, 공간별 대비를 생성한다. 좌표 변형의 변위 gradient Frobenius norm을 0.28 이하로 제한하여 좌표장이 접히지 않게 한다. 기존의 굴곡·분기 구조와 미세 피부 요철은 유지하되 전 영역이 똑같은 대비를 갖지 않도록 한다. 합성 pitch는 기하와 난수에서 정한 디자인 값이며 실제 지문 간격 측정값이 아니다. 기존 텍스처나 타인의 지문을 복사하지 않는다.

## 큰 주름

V4의 넓은 색상 구역만으로는 좁은 관절 주름이 사라진다. 추가로 최대 12×48개 구역(원본 투영 좌표 기준 폭 48px, 길이 16px 이상)의 RGB 중앙값을 구한다. 구역당 최소 24픽셀의 지지가 필요하다. V4 명암장과의 중앙값 차이에서 길고 넓게 이어지는 어두운 골을 찾아, 영역당 최대 3개의 이차 곡선·폭·깊이로 요약한다. 이 곡선으로 골과 약한 밝은 가장자리를 다시 그리고 골 안에서는 생성한 지문선 대비를 낮춘다.

원본 고주파 잔차나 원본 픽셀을 합성 결과에 섞지 않는다. 후보 근거가 부족하거나 너무 작은 영역에는 큰 주름을 추가하지 않는다. 파라미터로 만든 주름이므로 피부 주름의 정확한 복제·해부학적 검출을 의미하지 않는다. 조명 그림자를 주름 후보로 오인할 가능성, 비스듬하거나 경계에서 잘린 주름의 누락, 작은 주름 소실이 남는다.

V4보다 원본의 큰 주름 위치·명암 정보를 더 사용한다. V5 순열 검사는 **V4 색상·경계 분할과 새 macro 구역의 교집합** 안에서 픽셀을 섞는 조건이다. V4의 더 큰 구역 순열 불변성을 주장하지 않는다. 원본 지문선 위치를 직접 복사하지 않는다는 데이터 흐름 검증이며 일반적인 생체정보 제거 증명이 아니다.

## 유지한 계약

- 원본 파일·마스크·기존 처리 판정의 해시 결합과 fresh output 요구를 유지한다.
- 허용 범위 전체를 생성 RGB로 교체하고 범위 밖 RGB·이미 승인된 native 픽셀을 보존한다.
- RGB ICC·EXIF 방향·PNG 재읽기 계약과 명시적 interpolation을 유지한다.
- 영역 4 MiPixels, bbox 8 MiPixels, 영역 수 256개 및 기존 전역 할당 제한을 유지한다. 지문 합성 격자는 512×512로 제한한다.
- 작은 영역의 질감 생성 불가는 별도 기록하며 원래 native 거절을 native 성공으로 바꾸지 않는다.

```text
python ai/scripts/replace_photo_synthetic_v1.py --input ORIGINAL --protection-run VERIFIED_NATIVE_RUN --output FRESH_OUTPUT --renderer v5
```

## 개발 검증

2026-10-17 관련 단위·계약·회귀 검사 **77개 통과**. 새 7개 검사를 포함하며 과거 테스트 수를 누적한 숫자가 아니다. 정답을 아는 곡선 주름 합성 자료에서 색상 재구성 RMSE가 **3.0903→2.2970**으로 줄었다. 가는 주기 무늬·평탄한 피부를 큰 주름으로 만들지 않는 검사, 좌표장 제한, 생성 지문선의 연속성, 난수 재현성, 새 순열 계약, 평행 이동, 영역 밖·승인 픽셀 보존, EXIF·ICC·PNG, 자원 제한을 확인했다.

같은 개발 사진 6장·16개 허용 영역과 기존 seed로 재처리했다. 총 4,703,163화소를 교체했으며 미처리 후보와 질감 생성 불가 영역은 0개였다. 8개 영역에서 총 10개의 큰 주름 후보를 재구성했다. 이는 인간 정답으로 확인한 10개 주름이라는 뜻이 아니다. 모든 사진의 원본 해시·영역 밖 RGB·PNG 재읽기·새 순열 검사가 통과했다. 기존 마스크·검출·native 결과를 재사용한 비교이며 독립 검출 성능 평가가 아니다.

16개 확대 비교에서 무늬의 규칙성과 대비가 줄고 일부 큰 주름 명암이 돌아왔다. 완전한 사진 수준의 자연스러움, 모든 주름의 보존, 독립 촬영에서의 보호 성능은 아직 검증되지 않았다. 사용자가 검토할 비교는 원본/V4/V5 순서이며 이전 결과는 보존한다.

## 실제 매칭 관찰

V4와 같은 32개 ROI·동일 CLAHE 전처리·동일 기존 seed로 원본/V4/V5/검은 가림을 평가했다. 점수에 맞춰 파라미터나 seed를 재선택하지 않았다. 양쪽 특징점 10개 이상과 정상 점수 반환이라는 개발용 조건을 적용했다.

| 엔진·ROI | V4 유효/16 | V4 점수 중앙값 | V5 유효/16 | V5 점수 중앙값 |
| --- | ---: | ---: | ---: | ---: |
| NBIS 전체 bbox | 13 | 0 | 12 | 0 |
| NBIS 내부 사각형 | 1 | 3 | 1 | 0 |
| SourceAFIS 전체 bbox | 2 | 0.93 | 0 | 자료 부족 |
| SourceAFIS 내부 사각형 | 2 | 0 | 0 | 자료 부족 |

양 버전 모두 유효한 NBIS 전체 bbox 12쌍에서 3개 감소·8개 동일·1개 증가했다. SourceAFIS는 V5가 모두 유효성 조건을 충족하지 못하므로 성능 비교 결론을 내릴 수 없다. 원본부터 특징점이 부족한 영역이 많고 전체 bbox에는 변경되지 않은 외부 문맥이 포함된다. 원본 self는 독립 촬영 참조가 아니다. 낮은 점수·추출 실패·자료 부족을 보호 성공으로 집계하지 않는다.

## 실행기 확인

기존 합성 전용 Windows 실행기를 V5로 연결했다. 실제 JPEG 한 장을 파일 경로 인자로 전달해 검출→경계 보정→native 판정→V5 합성→PNG 저장까지 재실행했다. 1개 영역 620,040화소와 큰 주름 후보 1개가 처리됐으며 기존 비교의 허용 마스크와 같았다. 원본 파일 해시, 마스크 밖 RGB, 저장된 EXIF·ICC, 실행 소스 무결성을 확인했다. 기존 native 결과의 거절 상태는 보존했다. 파일 선택 UI는 재시험하지 않았다.
