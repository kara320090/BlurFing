# 가시성 누락 원인 감사와 고정 비교 실험

## 범위와 자료

사용자가 완료한 30장·67개 영역의 가시성 정답을 검증했다. 보임 53개,
관찰되지 않음 6개, 불확실 8개다. 원본/마스크 파일 60개, 원본 RGB 연결,
대표 사각형과 성분 그룹, 기존 관측 입력 102개를 확인했다. 개인 자료와
상세 결과는 비공개 outputs에 보관한다. AI 초안과 사람 정답을 합치지 않았다.

이는 이미 소비한 개발 23장과 과거 GT7 7장이다. 새 독립 holdout이 아니다.
음성 6개는 두 사진, 한 촬영 그룹에 집중돼 있다. 사람에게 AI 초안 접근이
가능했으므로 블라인드 독립 주석이나 사람 간 일치도 검증으로 해석하지 않는다.

## 원인 감사

`photo_visibility_gate_audit_v1.py`는 기존 관측기의 창별 수치와 판정을
그대로 재현하고, 실패 조건과 각 조건 하나를 제거한 반사실적 결과를 기록한다.
이는 조건 완화에 대한 승인이나 새 적용 규칙이 아니다.

- 기존 반복 신호는 보임 53개 중 24개에서 관측됐고 29개에서는 실패했다.
- 29개 모두에서 주파수 집중도 조건만 제외하면 관측 기준에 도달했다.
  밝기 대비 조건만 제외한 경우는 9개, 방향 조건만 제외한 경우는 0개다.
  서로 다른 창의 조합일 수 있어 원인 수를 단순 합산할 수 없다.
- 평균만 뺀 32×32 창의 FFT에는 조명 기울기와 큰 주름의 저주파 에너지가
  남는다. 그 에너지가 집중도 분모를 차지하면 함께 보이는 약한 반복 무늬도
  거절된다. 합성 선형 조명에서 이 경로를 재현했다. 실제 29개 모두가 선형
  조명 때문이라는 뜻은 아니며 아래의 단독 보정 실험 개선은 3개였다.
- 사용 대역은 약 3.3~15.4 working pixel 주기다. 사진 가시성 전반에 대해
  교정된 범위가 아니다. 고정 밝기 대비 8도 가시성의 보편적 기준이 아니다.
- 별도 간격 관측기는 최소 6개의 패치를 요구한다. 놓친 29개 중 14개는
  모든 평가 해상도에서 마스크 내 후보 중심이 6개 미만이었다. 방향 검사를
  거치면 26개가 6개 미만이다. 이것은 후속 profile 검사 전의 상한이다.
  특히 후보 중심이 없는 경우의 `no_periodicity`는 주기 부재를 증명하지 않는다.

## 고정된 비교 결과

| 사람 판정 | 수 | 기존 | 선형 조명 성분 제거만 추가 | 별도 주파수 실험 |
|---|---:|---:|---:|---:|
| 보임 | 53 | 24 | 27 | 24 |
| 관찰되지 않음 | 6 | 0 | 0 | 0 |
| 불확실 | 8 | 0 | 0 | 0 |

각 수는 반복 신호가 관측된 영역 수이며 보호 성공률이나 검증된 분류 정확도가
아니다. 작은 음성 집합에서 0/6이라는 관찰은 일반 오탐률 0을 의미하지 않는다.

선형 조명 제거 비교는 FFT 앞에서 평면을 뺀 뒤 기존 밝기 대비·방향·주파수
수치 조건을 그대로 사용했다. 3개를 추가 관측하고 기존 관측을 잃지 않았다.
개발 23장에서 보임 44개에 대한 17→19, 소비된 GT7에서는 7/9→8/9다.
27/53(50.9%)에 그쳐 기본 보호 적용 기준으로 승격하지 않는다.

`photo_visibility_spectral_probe_v1.py`는 절대 밝기 대신 대역 에너지·방향·
반경 집중도와 잡음 대비 신호를 확인하는 별도 실험이다. 상수는 기존 대역과
highres 기본값, 합성 대조 시험을 바탕으로 실제 후보 평가 전에 고정했다.
원본/마스크만 받고 정답 라벨·대표 사각형·파일명은 받지 않는다. 출력은
항상 미교정 진단이며 `automatic_visibility=uncertain`, `used_by_protection=false`다.
신호를 만들기 위한 원본 선명화·가짜 주기·학습은 하지 않는다.

주파수 실험은 5개를 추가 관측하지만 기존 5개를 놓쳐 24/53으로 동일했다.
개발 23장에서는 17/44→16/44로 감소해 교체 후보로 채택하지 않았다.
GT7 결과를 보고 상수를 다시 조정하지 않았다. 서로 다른 실험의 좋은 결과만
합쳐 개선률로 보고하지 않는다.

## 변경과 다음 단계

기존 frozen V4, V19, scanner, 관측/간격 조건과 실행기 보호 동작은 변경하지
않았다. 개선 가능한 원인을 드러내는 감사 도구와 비교 실험만 추가했다.
다음에는 좁은 주파수/고정 창의 한계와 큰 주름의 영향을 개발 자료에서 분리하고,
지문 가시성과 변환용 품질 측정을 분리한 판정기를 검토한다. 음성이 한 촬영
그룹에만 있어 현재 자료만으로 촬영 그룹 독립 학습·오탐 검증을 완성할 수 없다.

검증: 합성 저대비/회전/조명/잡음/평면/단일 주름/마스크 외 무늬 대조,
기존 수치 재현, 작은 ROI 샘플 부족, 주석·좌표·기존 관측 회귀 등 53개 통과.
30장·67개 실제 개발 영역에서 고정 비교를 실행했고 원본과 사람 주석은 보존했다.
대표 개선·퇴행·미관측 사례의 원본 패치도 시각 확인했다.

```powershell
python -m unittest -v test_photo_visibility_gate_audit_v1 test_photo_visibility_spectral_probe_v1 test_photo_visibility_v1 test_photo_pad_annotation_v1 test_ridge_axial_orientation test_photo_candidate_ridge_diagnostic_v1
```

`ai/scripts`에서 실행한다. 새 함수는 진단 전용이며 운영 보호 경로로 import하지 않는다.
