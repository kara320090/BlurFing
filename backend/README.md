# BlurFing Backend

주담당: 한윤섭

## 백엔드에서 할 일

Android 앱에서 사진을 받으면 손가락 영역에 블러를 적용하고, 처리 결과를 앱에 돌려주는 서버를 만듭니다.

현재 백엔드 코드는 아직 없으며 아래 순서대로 구현할 예정입니다.

1. 서버 기본 구조 만들기
2. 사진을 받는 `POST /v1/protect` API 만들기
3. 전달받은 손가락 영역에 블러 적용하기
4. 처리된 이미지를 앱에 반환하기
5. 잘못된 요청, 파일 크기 초과, 서버 오류 처리하기
6. Android 앱과 실제 통신 테스트하기
