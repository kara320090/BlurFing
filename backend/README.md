# BlurFing Backend

주담당: 한윤섭

## 백엔드에서 할 일

Android 앱에서 사진과 영역을 받아 AI 담당자의 보호 처리 모듈에 전달하고, 결과를 앱에 돌려주는 서버를 만듭니다.

현재는 요청 검증과 처리 모듈 연결 지점, 결과 검증·응답 형식까지 구현했습니다. AI 모듈은 아직 연결되지 않았으며, 연결 전에는 `503 PROCESSOR_UNAVAILABLE`을 반환합니다. 자동 영역 추출도 아직 없습니다.

1. 서버 기본 구조 만들기 (완료)
2. 사진을 받는 `POST /v1/protect` API와 요청 검증 만들기 (완료)
3. AI 담당자의 보호 처리 모듈 연결하기
4. 처리 결과를 검증해 앱에 반환하기 (연결 인터페이스 완료)
5. 잘못된 요청, 파일 크기 초과, 서버 오류 처리하기
6. Android 앱과 실제 통신 테스트하기

## AI 모듈 연결 지점

`app.state.protection_processor`에 함수를 등록합니다. 함수는 `(image_bytes, method, strength, regions)`를 받고, 입력 이미지와 같은 크기의 완성된 PNG 바이트를 반환해야 합니다. `regions`는 0~1 상대 좌표의 목록입니다. 실제 블러 방식과 강도 해석은 AI 담당자가 구현합니다.
