# 2026-10-21 이봉헌: 사용자 선호 V27 재질 복원

사용자가 원본/수정 전/수정 후 비교에서 가운데 수정 전이 더 자연스럽다고 평가했다.
해당 화면은 V27과 V28의 비교였다. 자동 처리의 생성 재질을 V27로 되돌렸다.
V28의 밝고 연속적인 선을 더 자연스럽다고 단정하지 않는다.

## 변경

- `render_selected_regions`의 예방적 합성 재질을 `photo_generated_detail_v27`로 복원했다.
- V27 재질, 강도, 기존 후속 경계 결합을 그대로 사용한다. 새 강도 조정이나 특정 사진 예외를 추가하지 않는다.
- 상주 모델, 원본 격자의 손 ROI, OpenCV 무손실 입출력, 요청별 새 추론과 전송 검증은 유지한다.
- V28은 직접 비교할 수 있도록 독립 모듈과 검사를 보존하지만 자동 재질로 선택하지 않는다.
- 기존 결과 파일을 재사용하거나 덮어쓰지 않는다. 실제 자동 요청은 새 무작위 합성 시드를 사용한다.
  선호한 이전 PNG와 모든 픽셀이 같은 복원으로 설명하지 않는다.

## 실제 확인

Windows i9-13980HX·RTX 4060 Laptop GPU의 현재 서버와 실제 모델로 제공 사진을 2회 처리했다.
3,000×4,000 RGB PNG를 실제 HTTP에 보내 응답 검증·PNG 저장/재읽기까지 측정했다.

| 실행 | 서버 | HTTP 수신 | 검증·PNG 저장/재읽기 포함 | 적용/미적용 |
|---|---:|---:|---:|---:|
| 1회 | 46.92초 | 47.16초 | **49.87초** | 2/1 |
| 2회 | 45.67초 | 45.91초 | **48.61초** | 2/1 |

최초 서버 준비 45.72초는 별도다. 사진 선택·최초 PNG 정규화, 학교 Ubuntu·실물 Android 시간은 포함하지 않는다.
적용 밖 원본 RGB가 같고, 직전 빠른 V28과 적용 마스크가 같은지 별도로 확인했다.
제공 사진의 개발 재실행이며 일반 사진의 1분 처리·보호 효과·객관적 자연스러움 점수로 확대하지 않는다.
다른 인수 사진에서 남은 60초 초과는 이번 변경으로 해결했다고 주장하지 않는다.

같은 원본 좌표의 원본/직전 빠른 V28/복원 V27 비교와 전체 PNG를 비공개 바탕화면 결과 폴더에 보관한다.
생성 시드가 다른 비교라는 점을 표시한다.

## 검사

V27 직접 렌더러와 실제 선택 경로의 고정 시드 RGB 일치, 선택되지 않은 영역과 원본 불변을 검사한다.
자동 예방적 합성의 보고서가 V27 정책을 식별하고 원본 지문 복원·지문선 관측을 주장하지 않는지 검사한다.
- V27 및 선택 경로의 실제 RGB 일치: **4개 통과**.
- 검토 영역·미적용/실패·원본 보존·EXIF·일괄 처리 계약: **15개 통과**.
- 자동 V23의 예방적 적용·경고·전송 결합·strict 경로: **7개 통과**.
- 실제 HTTP 2회와 PNG 저장/재읽기 검증을 통과했다. 두 번 모두 같은 사진의 개발 재실행이다.
- Android·센서 코드는 바꾸지 않았고 해당 실물 검사는 수행하지 않았다.
- 작업 전 미커밋 상태였던 data 5개 파일은 SHA256으로 보존을 확인했다.
