# 센서 전후 유사도 100점 표시 — 2026-10-23

담당: 이봉헌, Windows 표시·내보내기. 버전 0.3.1. 사용자가 0.9·298처럼 범위가 다른 원시 점수를 처리 전후 100점 척도로 표시하도록 요청했다.

## 변경

- `100 × s / (s + 40)` 고정 곡선으로 표시용 유사도 지수를 추가했다. 0.9→2.2, 40→50.0, 298→88.2다. 40은 표시 곡선 기준일 뿐 인증 판정을 적용한 것이 아니다. 독립 자료에서 보정한 확률·인식률·보호 성공률이 아니다.
- 큰 숫자에는 100점 환산 지수, 상세에는 원시 점수·엔진·DPI·특징점·환산식을 표시한다. 처리 전·후 한 쌍의 유사도이며 두 영상의 개별 품질 점수나 원본을 100으로 놓는 자기매칭 비율이 아니다.
- 원시 점수는 잘라내거나 변경하지 않는다. JSON의 기존 `similarity_score`를 유지하고 `similarity_index_100`, method/reference/formula/unit을 추가했다. hstack에도 같은 환산과 원시 점수를 표시한다. 미측정·측정 불가에는 0점 대신 미측정을 유지한다.
- 서버 API·매칭 엔진·AI 영상·SDK 취득 경로는 수정하지 않았다. 기존 서버·개인 설정을 사용한다. 합성 화면 예시는 실측과 구분한다.
