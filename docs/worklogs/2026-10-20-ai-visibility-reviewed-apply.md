# 가시성 후보 비교와 사람 검토형 적용 검증

자동 가시성 관측을 개선하되 성능을 과장하지 않고, 기존 사람 검토를 실제
전체 손끝 합성에 연결하는 작업이다. 사용자 지시에 따라 원본·기존 버전을
보존하고, 결과 검토에서 발견한 문제를 추가 수정했다.

## 변경

- V11: 같은 연속 원본 봉우리의 대응 및 공동 구간 상관.
- V12: 공동 구간의 국소 원본 기울기 방향.
- V13: 방향 통계의 일정 조명 기울기 보정. 원본 봉우리는 보정하지 않음.
- 기존 사람 검토의 좌표·해시·revision을 확인한 V19 전체 손끝 적용 CLI와
  Windows PowerShell 실행기. 자동 진단 신호는 적용 권한이 아님.
- 검토 프로젝트 재사용, 대각선 한 픽셀의 같은 손끝 생성 색 보완,
  합쳐진 손끝의 원자적 적용·복귀, 실행 중 자료 변경 시 완료 거절.
- V19 기존 면적 제한을 넘는 영역의 별도 축소 합성·생성 전용 확대 어댑터.
  안전 제한과 기존 렌더러 수학은 변경하지 않음. 최종 원본 마스크는 불변.

## 관측 결과

기존 30장·67영역에서 사람 보임 53개 중 신호 관측은 V5 43, V9 47,
V11 47, V12 36, V13 37이다. 음성 6개의 관측은 각각 1/0/0/0/0,
불확실 8개는 0/1/0/0/0이다. 새 후보 모두 기존 보임 손실이 있어 채택하지
않았다. 기본값·승인 기준을 바꾸거나 유리한 후보들을 합치지 않았다.

66영역은 전체 해상도를 계산하고, 큰 역사 자료 한 영역은 고정 코드의 첫
해상도에서 양성 증거를 확인해 OR 판정을 확정했다. 후보별 67영역 판정과
99해상도 계산이며, 3해상도는 미실행이다. 음성 결과에는 이 생략을 사용하지
않았다. 초기 계획·중단·실행 변경 기록을 비공개 위치에 보존했다.

## 발견·수정한 오류

1. 8방향 연결 한 픽셀을 렌더러의 4방향 검사에서 미해결로 보아 정상 손끝
   전체가 복귀했다. 인접한 같은 손끝의 생성 픽셀만으로 한 픽셀을 보완한다.
2. 여러 조각을 사람이 합친 그룹을 component별로 처리하면 일부 적용이
   허용됐다. 합성 재현 후 그룹 단위 전체 적용·전체 복귀로 고쳤다.
3. 이미 처리한 자료의 검토 내용이 배치 후반에 바뀌어도 완료될 수 있었다.
   완료 직전 로스터·검토 revision·모든 선택 원본과 마스크를 재검사한다.
4. 실제 배치가 24/30장에서 4 MiPixel 영역 제한으로 중단됐다. 제한은 유지하고
   별도 면적 어댑터를 추가했다. 축소·확대 모두 허용 마스크의 값만 사용하고
   원본 RGB를 합성 결과에 다시 섞지 않는다. 작업 해상도를 명시한다.

두 계약 오류는 수정 전 합성 테스트에서 실패함을 확인했다. 추가 테스트의
임시 상위 폴더 누락은 테스트 fixture를 고쳐 재실행했다. 실패 기록을 숨기거나
미완료 배치를 완료로 바꾸지 않았다.

## 검증 및 한계

관측 22개, 검토형 적용 14개, 큰 영역 3개, AREA support 4개, V19 9개,
잔존 진단 2개, 서로 다른 테스트 **54개를 통과**했다. 기존 V4·V19·스캐너 소스와
사람 라벨을 유지했다. 개인 사진·마스크·개별 감사 결과는 공개 커밋에서 제외한다.

실제 Windows PowerShell 실행기에서 30/30장을 완료했다. 사람 보임 53/53
그룹의 전체 마스크를 처리했고, 나머지 14그룹과 마스크 밖 RGB는 원본과 같다.
한 픽셀 보완은 총 2픽셀, 큰 영역 어댑터는 1영역에 사용했다. 원본·마스크
60개, 검토 상태와 실행 코드의 무결성을 확인했다. 기존 중단 결과는 보존했다.

67개 비교를 모음 이미지로 육안 검토하고, 큰 영역·잔존 경고를 별도 확대했다.
일부 외곽의 각짐, 관절 경계 단차, 매끈하고 규칙적인 질감은 남는다. 새 무늬의
적용과 충분한 자연스러움을 구분한다. 모든 픽셀의 1:1 육안 검사는 아니다.
잔존 진단 1,172개 창 중 3개 경고는 경계 영향이 주요 원인으로 보였지만 원래
경고를 삭제하지 않았다. 이 보조 진단으로 보호 성능을 승인하지 않는다.

SourceAFIS 106 ROI·212영상·318쌍 검사를 완료했다. 원본→반환 전체 bbox의
계산 가능 44/53쌍, 중앙값 0.992·최대 65.197, 내부 정사각형의 계산 가능
34/53쌍, 중앙값 0.869·최대 18.093이다. 특징점 부족은 성공으로 세지 않았다.
NBIS는 두 실행에서 서로 다른 단계의 Windows 프로세스 시작이 `WinError 5`로
실패했다. 파일 무결성·사용자 파일 권한은 정상이나 원인은 미확정이다. 보안
설정이나 실행 파일을 바꾸지 않았다. NBIS 결과는 미완료로 보고한다.

완전 자동 분류·독립 매칭·잔존 지문 없음·엄격한 자연스러움·제품 보호 승인은
완료된 항목이 아니다. 사람 검토형 적용 결과를 자동 검출 정확도로 보고하지
않는다. 새 촬영 그룹과 충분한 음성·불확실 자료가 없는 한 자동 승인 근거는
확보되지 않으며, 기존 30장 반복 조정으로 대체하지 않는다.
