# 2026-10-20 V22 경계 음영과 피부 이음새

V21에서 이전 생성 영상의 경계 음영이 질감으로 재유입되는 경로를 합성
사례로 확인했다. 내부 생성 질감 범위로 제한하는 선택 모드와 별도 저차
피부색/넓은 주름 연결 모듈을 추가했다. 사람 검토 실행·배치 CLI에
`material_v22` 선택을 연결했고 기본 V19와 기존 V21 동작을 유지했다.

개발 23장·44영역의 저장 결과를 다시 만들고 모두 시각 검토했다. 일부
경계 개선은 있으나 전체 차이는 작고 관절 모서리·이음새는 남는다. 기본
승격 없이 별도 실험 버전으로 보존한다. 원본/GT, 사람 검토, 보호 마스크,
보류 영역, 마스크 밖 RGB 및 보정 깊이보다 안쪽의 생성 RGB를 보존했다.

47개 테스트 통과. 실제 V22 CLI RGB는 개발 재생과 일치했고, V21 재실행도
이전 V21 RGB와 일치했다. 원본/GT 60개 및 이전 V19 30개·V20 23개·V21
23개 반환 해시를 확인했다. 잔존 질감 경고는 2→1개이며 보호 증명이 아니다.
새 matcher·독립 사진·Linux/Android 검증은 미실시다.

공개 코드·합성 테스트·익명 요약 문서만 커밋한다. 개인 사진·상세 진단·
비교 페이지·모델은 비공개로 보존한다. 시작 시 원격을 확인했으며 기존
main과 origin/main의 분기 이력을 보존했다. merge·push는 수행하지 않았다.
