# AI V23 교차 경계 외관 보정

## 변경

피부·배경·관절 주름이 만나는 모서리에 V21/V22의 접선 평균만으로는
설명하기 어려운 돌출이 남았다. 별도 V23 모듈에 RGB 셀 평균 기반의
2차원 경계·피부 곡면·넓은 주름 모델을 구현했다. 생성 질감만 결합하고,
기존 적용 마스크와 보류 상태는 보존한다.

검토 기반 단일/배치 CLI에 `--appearance junction_v23` 선택을 추가했다.
기본 V19 및 기존 옵션은 유지했다. 기존 잔존 질감 진단에 새 경고가
생기면 해당 성분의 V22 결과를 유지한다. 이전 버전·실험 출력은 보존했다.

## 검증과 결과

- 관련 테스트 55개 통과. 새 합성 기하/계수 회귀·경고 복귀 검사 8개 포함.
- 개발 23장·44영역 재생: 외관 보정 30영역, V22 유지 14영역.
- 44영역 확대 비교 및 실제 저장 PNG의 교차 경계 확인.
- 일부 모서리 돌출 감소. 큰 주름 연결·인공적인 매끈함은 남음.
- 최종 잔존 질감 경고 1→1, 새 경고 영역 없음. 보호 증명은 아님.
- 평균색 비교 629개 국소 패치 중 146개 악화, 최대 RMSE 증가 약 2.08.
- 실제 V23 CLI와 재생 RGB 일치, V22 CLI와 이전 RGB 일치.
- 원본/GT 60개·V19 반환 30개·V20/V21/V22 반환 각 23개 해시 보존.
- 사람 검토·적용 마스크·마스크 밖/보류/깊은 내부 RGB 보존.

독립 촬영 검증, 이번 버전 matcher, Linux/Android 검증은 미실시다.
기본값 승격이나 보호 성능 승인은 하지 않았다. GitHub 업로드는 준비만
하며 이 작업에서 push/merge하지 않는다. 개인 사진·GT·모델·비공개 결과는
커밋 대상에서 제외한다.
