# 2026-10-20 V21 외관 실루엣 보정

보호 허용 마스크와 실제 피부 외곽을 별도 표현하는 V21 후보를 구현하고
기존 사람 검토 실행/배치 CLI에 명시적 선택 옵션으로 연결했다. 기본
V19, frozen V4, 검출/가시성/피치/특징점 기준은 그대로다.

기존 개발 23장·44영역에 적용해 43영역 경계 보정을 채택했다. 44영역은
이미 V19로 합성된 영역이며 보호 성공률이 아니다. 44개 비교를 시각 검토했고
흰 테두리 감소를 확인했으나 진한 띠·관절 이음새·매끈함은 남는다.
전체 평균 색 오차가 좋아져도 일부 국소 표본 오차는 증가해 기본 승격은 하지 않았다.

최종 테스트 40개 통과. 실제 현재 사진의 CLI 생성/저장 RGB가 같은 seed의
비교 실험과 정확히 일치했다. 원본·사람 GT·검토 상태·이전 V19/V20 출력,
마스크 밖과 보류 영역 RGB 및 깊은 내부 생성 RGB를 보존했다.
새 matcher/독립 사진/Linux/Android 검증은 수행하지 않았다.

공개 코드·테스트·문서만 커밋한다. 사진·개별 진단·비교 페이지는 비공개
작업 공간에 보존하고 업로드하지 않았다. Git fetch 결과 원격 변경은
Android 쪽이며 이력이 갈라져 fast-forward가 불가능했다. reset·merge·push는
수행하지 않았고 기존 커밋과 원격 변경을 보존했다.
