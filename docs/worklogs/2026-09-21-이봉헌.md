도구 활용: Codex가 코드 수정·자동 테스트·Git 작업을 수행했다. 사용자의 실제 기기 조작이나 수동 검수를 수행한 것으로 기록하지 않는다.

## 팀원 작업 검토

작업 시작 기준: `75830fd`. 한윤섭의 백엔드 `GET /` 구현과 문서 변경을 확인했다. `POST /v1/protect`는 아직 없어 앱에서 성공적인 보호 응답을 받을 수 없는 상태다. 백엔드 구현의 기여는 기존 커밋 작성자에게 있으며 이번 작업에서 백엔드 코드는 변경하지 않았다.

기존 Android 코드에서는 Gradle Wrapper JAR 누락으로 빌드가 시작되지 않았고, 사진 선택 화면이 현재 ViewModel에 없는 `ImageLoaded` 상태를 참조했다. 실제 서버 응답도 로컬 프리뷰로 대체되고 통신 실패 시 사진 선택 화면으로 돌아가는 연동 문제가 있었다.

## 실행한 검증

환경: Windows, JDK 21.0.4, Gradle 8.9, Android SDK 35, AGP 8.7.0.

작업 위치: `android/`. 명령: `./gradlew.bat testDebugUnitTest assembleDebug --max-workers=4 --console=plain`.

최종 결과: **BUILD SUCCESSFUL**, 테스트 **36개 / 실패 0 / 오류 0 / 건너뜀 0**.

| 테스트 클래스 | 개수 |
|---|---:|
| ApiProtectionIntegrationTest | 8 |
| BackendAddressTest | 3 |
| BlurFingViewModelIntegrationTest | 4 |
| ProtectedImageDecoderTest | 4 |
| CoordinateTransformerTest | 4 |
| NormalizedRegionTest | 7 |
| EvaluationMetricsTest | 2 |
| ProtectionRepositoryTest | 4 |

기존 17개에 19개를 추가했다. API 시험은 MockWebServer의 합성 응답을 사용했고, 비트맵 시험은 Robolectric Native Graphics로 실행했다. 합성 사진 입력 → 실제 HTTP 요청 → 서버의 합성 PNG 응답 → 앱 비교 상태까지 확인했다.

첫 실행에서 시간 초과 분류와 테스트 메서드 반환형 오류를 발견해 수정했다. 기본 Robolectric 그래픽 모드에서 MIME 검증이 재현되지 않아 이미지 테스트를 Native Graphics로 전환했다. 실패를 숨기지 않고 수정 후 전체 테스트를 다시 통과시켰다.

로컬 검증 산출물: `android/app/build/reports/tests/testDebugUnitTest/index.html`, `android/app/build/test-results/testDebugUnitTest/`, `android/app/build/outputs/apk/debug/app-debug.apk`. APK와 생성 보고서는 Git에 올리지 않는다.
