# 2026-10-21 이봉헌: V27 외관 유지 사진 처리 추가 최적화

사용자가 가능한 반복 비용을 줄여 처리 시간을 더 짧게 해 달라고 요청했다.
선호 V27 재질을 유지하고 현재 실행을 계측한 뒤 모델/프로세스 준비·파일 읽기·영역 계산·PNG 인코딩·중간 전송을 개선했다.
특정 사진의 예외, 추론 생략, 해상도 축소, 검출/거절 임계값 변경은 추가하지 않았다.

## 결과

- 실제 준비된 Windows 서버→HTTP→독립 응답 검증·PNG 저장/재읽기: 제공 사진 **37.26초·37.76초**.
- 같은 서버의 인수 사진 `TRN-022`: **52.55초**. 이번 두 입력의 세 요청은 모두 60초 이내다.
- 최초 서버 준비 **43.69초는 별도**다. 학교 Ubuntu·실물 Android의 측정은 아니다.
- 같은 시드의 직접 실행 두 번째 요청은 **45.14초→30.60초**였다. HTTP 시간과 구분한다.
- 고정 시드 두 번 모두 변경 전과 반환 RGB·후보/적용 마스크·전체/ROI 손 관측이 정확히 같았다.
- 실제 HTTP 세 번 모두 두 영역 합성·한 후보 미적용이고 적용 밖 원본 RGB가 같았다.
  후보 수는 손가락 수가 아니며 일부 미적용/누락 가능성을 보호 성공으로 바꾸지 않는다.

구조·메모리 상한·측정 조건은 [V31 상세 기록](../../ai/docs/PHOTO_RESIDENT_FAST_V31_20261021.md)을 따른다.

## 구현과 검사

모델을 새로 구성하던 V6 경로와 요청마다 시작하던 손 검출기를 재사용한다.
실제 사진/ROI 관측은 매번 실행하고 가중치 파일과 메모리 파라미터를 확인한다.
손 관측 IPC는 내부 ID를 결합하고 잘못된 ID·미소비 결과·기한 초과 때 worker를 종료한다.
병렬 준비 중 한 자원만 실패해도 다른 준비 자원과 fit 풀을 정리한다.

중간 자동 처리의 배열 전달은 최종 응답을 원본 좌표에서 검증하는 데 사용한다.
독립 파일 출력 경로도 유지하며 합성 자료로 두 경로의 RGB/마스크 일치를 검사한다.
거친 영역과 인코딩은 요청 안에서만 재사용하고 파일은 최종 재해시한다.

- 실행·IO·거친 영역·자동 경로·경계 fit 회귀 pytest **45개 통과**.
- 전체 소스 집합·추가/삭제/변조·재파스 검사 unittest **16개 통과**.
- export/전송·소스/모델/의미 마스크 변조 계약 unittest **16개 통과**.
- 실제 AI Python에서 상주 모델의 파일/메모리 변조 거절·RNG·범위 분리 **2개 통과**.
- 초기 배열 전달 검사에서 PHOTO 라우터를 고정하지 않은 합성 입력이 불확실 경로로 빠졌다.
  합성 fixture의 라우팅 조건을 명시하고 실제 처리 경로를 검사하도록 수정한 뒤 통과했다.
- Torch 의존 모델 검사는 실제 AI 환경에서 수행한다. Torch 없는 CI의 합성/프로세스 검사와 구분한다.

원본·가중치·비공개 설정은 공개 Git에 넣지 않는다. 기존 미커밋 data 5개 파일을 보존한다.
학교 Ubuntu·실물 Android·센서·일반 사진 보호 효과와 속도는 이번 변경의 완료 항목으로 세지 않는다.
