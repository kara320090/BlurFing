## 검증 범위와 남은 사항

- 기기 자동 테스트는 사진 선택·카메라 결과 경계에 합성 데이터를 주입한다. 별도로 에뮬레이터의 Camera2 촬영도 직접 확인했지만 실제 휴대폰의 카메라 앱·갤러리 선택기·실물 센서 시험으로 대체하지 않는다.
- 작업 복원 단위 테스트는 새 SavedStateHandle·ViewModel로 수정 좌표를 읽는다. 기기에서는 Activity 재생성과 백그라운드 프로세스 종료 후 기존 작업 복귀를 확인했다. ADB로 새 MainActivity를 하나 더 띄운 화면은 빈 입력 화면이었고, 기존 작업으로 돌아가 복원을 확인했다. 캐시 삭제·최근 작업 제거·강제 중지 후 새 작업 시작까지 복원을 보장하지 않는다.
- 로컬 팀 백엔드 기본 구성은 AI 미연결로 503을 반환한다. 성공 경로에는 격리된 단색 출력 함수를 사용했으며 보호 알고리즘이나 지문 매칭 성능으로 보고하지 않는다.
- 평가 표시 코드와 합성 데이터 검증은 완료했지만 실제 측정값은 생성하지 않았다. 센서·AI·백엔드 담당이 실제 자료와 연결 정보를 제공해야 한다.
- 실제 휴대폰, Android 8·9 시스템 저장 권한 창, 팀의 독립 배포 서버, 실모델·실센서 검증은 별도로 남아 있다.

## 기여 및 인계

이봉헌 담당인 Android 화면·상태·입출력·서버 통합을 구현하고 검증했다. 한윤섭의 백엔드와 필수 입력 오류 응답 변경은 수정하지 않고 연결 검증했다. 데이터 추출·AI·센서 모듈 구현을 대신 완료한 것으로 기록하지 않는다. Git 게시 시점과 이 문서의 실제 작업·검증 시점은 별개로 유지한다.
