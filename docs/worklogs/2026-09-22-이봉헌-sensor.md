# 2026-09-22 이봉헌 — BioMini Slim 2 설치·취득 도구 사전 준비

관련 요구사항: BF-08, BF-11, BF-12. 사용자 요청: 구매 예정인 약 14만 원 센서의 SDK 다운로드·설치 경로 확인과 미리 사용할 프로그램 제작.

## 역할과 변경

최승빈이 센서 모듈·참조 영상 취득·측정 업무를 계속 담당한다. 이번에는 이봉헌의 시스템 통합 작업으로 Windows 수집 화면, 공식 예제에 기반한 SDK 어댑터, 파일 출력·출처 기록·오류 경계를 준비했다. 최승빈의 실제 센서 개발·검증 실적으로 기록하지 않는다. Codex가 사용자 요청에 따라 코드 작성·검증·설치·Git 작업을 수행했다.

- C# WinForms 수집 도구: SDK DLL 선택, 장치 수 조회, 한 장 취득, 취소, 시간 제한, 미리보기, BMP/PNG/JSON 저장.
- SDK와 합성 모드 분리. 합성 테스트는 300×400 회색조 그라데이션·체커보드이며 지문이 아니다.
- 실제 취득 시도 전 기존 영상을 제거해 실패 후 오래된 결과가 남지 않게 했다.
- SDK가 멈추거나 충돌해도 UI와 분리되도록 네이티브 호출을 자식 프로세스로 구성했다.
- 원본 BMP 바이트를 보존하고 출처·익명 ID·UTC 시각·크기·SHA-256을 기록한다. 임의의 품질 점수·일치 확률은 생성하지 않는다.
- 실제 지문과 SDK 바이너리를 공개 Git에서 제외한다. 기본 결과 폴더는 저장소 밖의 사용자 로컬 앱 데이터다.

## SDK와 드라이버 확인

[제조사 SDK 페이지](https://www.xperix.com/products/developer/sdks)에는 SDK가 구매 대상으로 안내돼 있다. 공개 설치 파일은 찾지 못했고 구매처 포함 여부도 확인되지 않았으므로 SDK 설치 완료로 기록하지 않는다. 공식 예제에서 확인한 6개 네이티브 함수만 어댑터에서 사용한다. SDK 수령 후 헤더·버전·라이선스를 다시 확인해야 한다.

[공식 드라이버](https://tech.xperix.com/en/support/solutions/articles/69000857511--device-driver-biomini-windows)를 내려받아 이 작업 PC에 설치했다. 설치 완료 화면, 설치 폴더, Windows 드라이버 저장소의 Xperix `sfr.inf` / `oem152.inf`, 버전 3.0.3.0을 확인했다. EXE 설치 파일 버전은 2.2.1.2다. 설치된 카탈로그 서명은 Valid이며 Windows 등록 서명자는 Microsoft Windows Hardware Compatibility Publisher다. 설치 EXE 자체는 서명되지 않은 것으로 확인했다. 출처·해시는 [sensor 안내](../../sensor/README.md)에 기록했다.

## 실행한 검증

| 검증 | 결과 |
|---|---|
| `dotnet run --project sensor/BlurFing.SensorCapture.Checks -c Release` | 16/16 통과. 합성 BMP 8비트/크기/출처, 잘못된 입력, 원본 보존, PNG 전체 픽셀, 해시, 중복 저장, 파일 경로, DLL 오류, 자식 프로세스 취소·시간 초과·오류 전달 및 임시 폴더 정리 확인 |
| Windows x64 자체 포함 배포 | 빌드 성공. DLL·프로세스 경로 경고 수정 후 경고 없이 배포 |
| Windows x86 자체 포함 배포 | 빌드 성공 |
| x64 실제 UI 실행 | SDK 미선택 시 장치 조회·취득 비활성, 합성 패턴 미리보기, 합성 명시, BMP/PNG/JSON 저장 및 완료 안내 확인 |
| 드라이버 설치 | 완료 화면과 Windows 드라이버 저장소 등록 확인. 센서 인식 확인은 아님 |

검사에 사용한 영상은 모두 합성 자료이며 실제 지문 수집·외부 전송은 수행하지 않았다. 이번 변경은 센서 도구와 관련 안내에 한정되어 Android·백엔드 테스트를 다시 실행하지 않았다.

## 아직 검증하지 않은 부분

실제 제조사 SDK의 DLL 로딩·ABI 호환성, USB 센서 인식, 원본 지문 취득, 실장비 취소·재연결, 품질·매칭 측정은 SDK와 센서가 없어 검증하지 않았다. 이 프로그램이 곧바로 장비와 호환된다고 확정하지 않는다. 수령 후 제조사 샘플의 BMP 취득부터 확인하고 어댑터와 공동 시험한다.
