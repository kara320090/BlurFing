# 2026-10-19 지문 가시성 검토 도구와 외부 품질 진단

기존 손끝 마스크와 지문선 가시성 정답을 분리하는 로컬 도구를 구현했다.
30장·67개 연결 성분을 검토 제안으로 준비했다. 원본·마스크는 보존하며
사람의 명시적 검토 전에는 정답으로 집계하지 않는다. 기존 학습 23장과
소비된 GT7 7장의 역할, 촬영 그룹, 해시를 유지했다.

원본 ridge 관측과 저자 제공 MCLFIQ 모델(NFIQ 2.2.0)을 실제 실행했다.
67개 중 24개에서 원본 반복 신호, 5개에서 주기 정규화 및 MCLFIQ 점수를
얻었다. 사람 가시성 정답은 아직 없으므로 정확도는 산출하지 않았다.
MCLFIQ 전처리는 별도 실험 어댑터이며 논문과의 동등성은 검증되지 않았다.
측정 불가를 음성이나 보호 성공으로 바꾸지 않는다.

새 도구 및 기존 마스크 주석 도구의 30개 테스트가 통과했다. EXIF 1~8,
대표 영역의 마스크 포함, 임시/사람 정답 구분, revision·프로세스 충돌,
원본/마스크 변경 감지, 좌표 변환, 메모리 제한, 모델 바인딩, 종료 코드 0의
특징 추출 오류를 확인했다. 합성 브라우저 자료에서 저장과 내보내기도 확인했다.
실제 자료의 사람 검토는 대행하지 않았다.

기존 V19와 보호 임계값은 변경하지 않았다. 코드·테스트·익명 요약만 공개
대상이다. 원본 사진·정답·모델·개별 진단은 비공개 작업 폴더에 유지한다.
원격 main의 Android 변경 3개를 확인했으나 AI와 겹치지 않으며 현재 이력은
분기되어 있다. 이번 작업은 로컬 커밋까지만 준비하고 push하지 않는다.
