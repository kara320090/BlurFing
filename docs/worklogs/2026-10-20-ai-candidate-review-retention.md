# 2026-10-20 검토용 후보 소실 수정

사용자가 새 사진에서 손끝 후보가 나오지 않는다고 보고했다. 실제 기록에서 V6와 보완 단계는 후보를 생성했지만, 주름 경계 보정이 기준점을 확인하지 못한 손가락을 보호용 허용 마스크에서 제외했다. 새 실행기가 이를 검토용 후보로 그대로 사용한 것이 후보 0개 표시의 직접 원인이었다.

검토용 후보와 보호 허용 마스크를 구분했다. `unanchored_candidate_excluded`로 기록된 소속 영역 안의 기존 후보만 다시 표시한다. 다른 사유로 제거된 잡음은 복원하지 않는다. 후보 0개와 경계 불확실 후보에 대해 서로 다른 안내를 표시한다. 복구된 후보는 여전히 불확실이며 사용자 확인 없이 V23 적용을 승인하지 않는다.

실행기 테스트 12개 통과. 실제 신경망 재실행에서 문제 사례 후보 1개 복구 확인. 최종 소속 제한과 경계 처리의 저장 출력 재생 3건에서 문제 사례 복구 및 다른 두 사례 픽셀 동일성 확인. 기존 검토 기록과 입력 파일, 모델, frozen 알고리즘, 검출·보호 임계값은 수정하지 않았다.

후보 하단의 사선 경계는 여전히 불완전하다. Android 사진 입력만으로 자동 보호가 완료되는 제품 수준에 도달했다고 판단하지 않는다. 다음 우선순위는 검출 범위와 가시성 판단, 불확실 처리, V23 Android/backend 통합 및 독립 평가다.
