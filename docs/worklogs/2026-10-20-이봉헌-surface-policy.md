# 2026-10-20 흐린 손끝의 합성 정책 변경

사용자가 ‘정책 바꿔’라고 명시하여 자동 V23의 기본 선택을 원본 지문선 필수 관측에서 모델·자세 근거가 있는 손끝 표면의 예방적 합성으로 변경했다. 기능 커밋은 `c0f35eb`이며 [V26 선택 정책](../../ai/docs/PHOTO_SURFACE_POLICY_V26_20261020.md)을 따른다. 같은 렌더러를 사용하므로 엔진은 계속 `synthetic_v23`이다.

## 구현과 실제 실행

- 원본 관측 결과를 그대로 남기고, 관측이 불확실해도 원본 검출·자세·경계에 결합된 후보만 합성할 수 있게 했다. 기존 strict 선택은 CLI 옵션으로 보존했다.
- 실제 적용 사유·응답 경고·서버 검증·Android 디코딩과 설명을 함께 바꿨다. 생성 실패를 성공으로 세지 않으며 적용 마스크 밖 원본 화소는 유지한다.
- 사용자가 제공한 전체 V자 사진에서 검지·중지 각각 합성 적용, 나머지 경계 불확실 후보 2개 미적용으로 `partial_success`를 반환했다. 적용 영역 26,244픽셀, 실제 변경 26,221픽셀이다.
- 저장 PNG/응답 RGB·서버 계약·적용 밖 원본 화소 보존을 재검사했고 원본 해상도의 양쪽 손끝 결과도 확인했다. 원본 관측 창 26·22개에서의 불확실 판정은 유지한다.
- 실제 지문 복원·독립 시험·전체 보호 성공으로 보고하지 않는다. 이미 개발에 사용한 사진의 재실행이며 임의 시드 선택이나 수동 마스크를 사용하지 않았다. 155.080초의 서버 처리 시간은 120초 목표 미달이다.

## 회귀와 배포

기존 개발 자료도 실제 모델부터 다시 실행했다. V자 B는 후보 5·적용 2·거절 3, 성공 대조는 1·1·0을 유지했고 같은 고정 시드의 반환 RGB·후보/적용 마스크가 이전 strict 결과와 정확히 같다. 각각 약 156.92초·154.74초의 단발 진단이며 일부 회귀와 겹친 시간이다.

기존 ‘지문선 미관측’ 대조는 정책 변경에 따라 후보 5·적용 4·거절 1로 달라졌다(약 159.54초). 네 영역은 원본 관측이 계속 불확실하지만 모델·자세·경계 근거로 예방 합성됐다. 이를 원본 지문 검출 성공 4개나 독립 가시성 정확도 개선으로 집계하지 않는다. 다섯 번째 미확인 경계는 계속 원본이다. 3개 모두 wire 계약·PNG/응답 RGB 동일성·적용 밖 원본 보존을 별도로 확인했다.

- 자동 기하·새 선택 정책·실제 합성·전송 합성 검사: **35개 통과**. 원본 관측을 조작하지 않고 평탄한 입력의 허용 영역만 합성, 부분 권한·경계 밖 권한 거절, 새 사유/경고 누락·다른 엔진 혼용 거절과 기존 strict 결과 동등성을 검사했다.
- 기존 AI·export·transport·자세·검토 UI/적용·주름/외곽: **115개 통과**.
- 서버·시연 도구: **140개 통과**. 기존 httpx/Starlette deprecation warning 1개가 있다.
- Android 단위: **217개 통과·선택 시험 1개 건너뜀**, lint 통과. 실제 PNG/마스크·새 사유·경고·영역 수와 사용자 설명을 Robolectric에서 검사했다.
- 위 통과는 합계 **507개**다. 실제 모델 실행 4개는 이 합성/단위 검사 수에 섞지 않는다.
- 서버 실행 도구의 모델·환경 preflight를 다시 통과했다. 실행 예시의 인수는 실제 CLI의 `--config`, `--service photo`를 확인했다.
- 기존 `data/` 미커밋 5개 파일의 해시는 그대로다. 비공개 원본·결과·가중치·실험 응답을 공개 Git에 추가하지 않는다.

새 APK는 새 사유/경고를 해석하는 앱으로 빌드한다. 이 변경 후 실물 Android·학교 Ubuntu·센서 연결은 아직 검증하지 않았고, 구버전 서버 프로세스를 재사용하는 것만으로 업그레이드되지 않는다. 사용자 요청대로 기능과 검증·인계를 두 커밋으로 나눈다.
