# 경계 외관 후보와 NBIS 검사 완료

- 이전 실패 명령의 읽기 전용 20회 실행이 동일 출력으로 성공했다. Windows
  실행 거부는 간헐적으로 관측됐으나 운영체제 원인은 확정하지 못했다.
- Windows 전용 선택 인자로 작업 전체 최대 2회의 생성 전 재시도를 구현했다.
  기본값은 0, 시작된 명령·시간 초과·IO 오류는 재시도하지 않는다. 실행 파일과
  보안 설정은 변경하지 않았다. 모든 시도와 오류를 기록한다.
- 이전 미완료 NBIS 212영상·318쌍을 같은 조건으로 완료했다. 약 58.9초,
  실제 재시도 0회다. 실환경 오류를 재시도 기능으로 복구했다고 보고하지 않는다.
- 원본→실제 반환 NBIS 점수는 전체 bbox 중앙 10·최대 128(계산 가능 51/53),
  내부 정사각형 중앙 5·최대 18(47/53)이다. 특징점 부족과 낮은 점수는 보호
  성공 증명이 아니다. 과거 SourceAFIS 결과와 실패 감사 기록은 보존했다.
- V19의 고정 16단계 경계 보정 제한을 합성 재현으로 분석하고, 관측된 평균
  경계색 범위로 보정하는 V20 실험을 추가했다. 기본 V19·frozen V4·scanner는 유지했다.
- 기존 개발 23장·44개 보임 영역에서 19개는 경계색 보정, 25개는 V19 유지.
  원본·마스크·허용 범위 밖·깊은 합성 RGB 및 PNG 재읽기를 검증했다.
  잔존 경고 3개는 그대로이며 새 경고 영역은 없었다. GT7·holdout은 사용하지 않았다.
- 변경된 19영역과 두 외곽 확대를 육안 검토했다. 색 차이 감소는 일부이나
  각짐·경계 띠·매끈함이 남아 후보를 기본값으로 승격하지 않았다. 수동 마스크의
  직선 경계와 실제 피부 곡선의 차이가 외곽에 드러나는 사례를 확인했다.
- Windows 9개·경계색 4개·기존 V19 9개, 총 22개 테스트 통과. 일반 보호 성능,
  자동 판정, 독립 사진, Linux/Android 동등성은 이번에 승인하지 않았다.

공개 변경은 코드·합성 시험·익명 요약뿐이며 개인 사진과 개별 감사 기록은 제외한다.
