# 자동 V23 Android 연동 — 2026-10-20

## 구현한 범위

사진 선택/촬영 결과 → sRGB·EXIF 정규화 → V2 서버 → 후보 검출·경계 보정
→ 원본 지문선 관측 → V23 합성 → 원본 좌표 마스크/픽셀 검증 → 비교·PNG 저장을 연결했다.
이전에는 수동 검토된 영역을 받던 V23 렌더러를 자동 관측 경로에서도 호출한다.
자동 관측은 새로운 미보정 정책이며 사람의 정답으로 기록하지 않는다.

주먹을 쥔 엄지에서 손 전체의 PCA 축을 손가락 축으로 쓰던 문제가 확인됐다.
별도 V24 경로에서 후보와 같은 소유 영역의 근위부 방향을 사용하고,
기존 조건으로 관절 주름이 관측될 때만 실패한 경계를 보완했다.
이전 버전·frozen V4·가시성/지문 간격/feature threshold는 보존했다.

앱 첫 화면에서 자동 V23 진입점을 우선 표시하며, 사진 선택 후 요청이 자동으로 시작된다.
이전 작업 복원은 재업로드하지 않는다. 거절/후보 없음/불명확한 입력은 미적용으로 표시한다.
V23은 스마트폰 내 추론이 아니라 PC/서버 추론이다.

## 실행한 검증

- AI 관련 단위/회귀: 90개 통과.
- 백엔드 전체: 105개 통과. schema 추가 경고 검증 포함.
- Android 단위: 212개 통과, 선택적 1개 skip, 실패 없음.
- debug/계측 APK 빌드 및 lintDebug 통과. lint는 오류 0개·경고 12개다.
- 결과 비교·저장/공유·사진 교체·종료 UI: 에뮬레이터 11개 통과.
- 앱 첫 화면의 자동 진입점이 V23을 선택하는 실제 Activity 전환: 1개 통과.
- 실제 모델 HTTP: 실제 사진 1장, 후보 1/적용 1, 약 136초.
- 실제 Android Repository→HTTP→모델→MediaStore 저장 및 재읽기: 1회 통과,
  약 121초. V23 자동 시작을 사용했고 Mock 결과가 아니다.
- 모호한 합성 입력의 실제 HTTP: 200/rejected, 후보/변경 0, 원본 RGB 동일.
- 기존 3장 모델 출력 재사용: 후보 6개에 적용, 엄지의 경계 실패를 보완했고
  나머지 2장의 동일 seed 결과는 수정 전후 일치.
- 기존 6장 모델 출력 재사용: 후보 17개 중 16개 적용. 작은 후보 1개는 경계 근거가
  부족해 미적용. 원본/반환 비교 및 확대를 시각 검토했다.

마지막 두 검사는 모델 재추론/독립 촬영 평가가 아니다. 후보 개수도 손가락 수나
보호 성공률로 환산하지 않는다. 최초 Android 실행의 PATH 따옴표 문제와
추가 엔진에 대한 fixture/schema 누락을 고쳐 재검증했다.

## 보존·통합 및 남은 조건

원격 팀원 변경을 merge commit `8216fef`로 보존한 후 구현했다.
공개 변경은 코드·합성 시험·문서만 포함한다. 개인 이미지/GT/가중치/실험 출력은
저장소 밖에 보관했다. push는 하지 않았다.

현재 구현은 자동 연동 개발판이며 전체 지문 보호와 production 승인은 false다.
추가 자료 없이 기존 사진을 반복 튜닝해 이를 통과로 바꾸지 않는다.
