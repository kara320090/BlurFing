# V23 PC 실행기 재실행 수정

이전 검증에서 켜 둔 loopback 서버가 8001 포트를 점유하고 있어 재실행 시
Uvicorn의 Windows 10048 오류가 발생했다. 로컬 PowerShell wrapper가 자식 실행기의
실패 코드를 전달하지 않아 CMD의 오류 시 pause도 실행되지 않는 현상을 재현했다.

- 서버 실행기에 명시적 `-ReuseRunning` 추가: 같은 backend의 Uvicorn 프로세스와
  V23-only `/ready` 응답을 확인한 경우에만 기존 서버 설정을 재사용한다.
- 다른 프로그램의 포트나 준비되지 않은 서버는 안내 후 실패한다. 임의 종료하지 않는다.
- 로컬 배포 wrapper는 실패 코드를 전달하고, CMD는 종료 전에 상태를 보여 주고 기다린다.
- 서버 콘솔과 Android 사진 입력 화면을 구분해 실행 안내를 보완했다.

검증: Windows pytest 3개 통과(실제 임시 서버 시작/재사용/충돌, 다른 프로세스 보존,
native 실패 코드 7 전달). 로컬 wrapper의 실제 포트 충돌은 nonzero로 반환됐고,
다른 작업 디렉터리에서 실행한 배포 CMD는 기존 서버 재사용·pause·정상 종료까지 확인했다.
현재 8001 서버의 `/ready`는 200/ready다. 이 변경에서는 AI 재추론이나 보호 성능을
다시 평가하지 않았다.
