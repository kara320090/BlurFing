# 2026-10-20 새 V자 사진 첫 실행과 연결 수정

사용자가 새로 제공한 V자 사진을 먼저 `5c552c4`에서 수정 없이 실행했다. 인수 목록·추가 목록·고정 사용 자료 레지스트리의 파일/RGB 해시와 일치하지 않았다. 이는 확인 가능한 중복이 없다는 뜻이며 독립 모집단 평가나 촬영 이력 전체의 보증은 아니다. 원본 파일을 보존하고 전체 해상도에서 방향·sRGB만 정규화했다. 원본·입력 해시·결과 이미지는 비공개로 보관한다.

## 보존한 첫 실행

- 전체 입력: 세로 4,000 × 가로 3,000 RGB. 사람 마스크·수동 잘라낸 입력·지정 시드 없이 실제 모델을 실행했다.
- 결과: `rejected`, 후보 component 2·적용 0·거절 2, 서버 처리 109.939초, 직접 호출 전체 약 119.67초. 이 후보 2개를 해부학적 두 손가락 검출 성공으로 세지 않는다.
- COLFISPOOF BODY와 관측 자세는 있었지만 semantic TIP은 0픽셀이었다. V25가 semantic TIP만 허용해 유효한 손가락을 하나도 선택하지 못했다. 기존 추정기의 경계 보완도 실패했다.
- 두 후보 모두 `REJECT_BOUNDARY_UNCERTAIN`이었다. 이때는 raw-ridge 검사를 실행하지 못했으므로 첫 실패를 지문선 흐림에 의한 거절로 기록하지 않는다.
- 원본 해상도 손끝 확대에서는 초점 흐림이 관찰된다. 기하 연결 오류와 별도 문제이며 합성 지문을 넣어도 원래 지문 복원이 되지는 않는다.
- transport 검증·응답 PNG/디스크 재읽기·RGB 보존을 확인했다. 첫 반환은 전체가 입력 RGB와 같다.

## 추가 수정

기능 수정은 `83c5a77`이며 자동 경로의 기하 정책을 `model_supported_partial_pose_v25_2_experimental`로 식별한다. 기존 semantic TIP 근거 외에, **실제 원본 좌표 V6 예측의 같은 4연결 성분이 관측 TIP와 TIP–DIP 중간점을 모두 지지할 때** 손가락별 경계 계산을 허용한다. 하나의 점만 맞거나 서로 분리된 점은 충분하지 않다.

V6의 실제 prediction PNG를 모델·원본·manifest·해상도·PNG 해시에 결합하여 다시 읽는다. 자세 합집합이나 둥글게 확장한 후보 마스크가 자신의 경계를 스스로 승인하는 순환 근거로 사용되지 않도록 한다. RGB BODY 보정 후에는 해당 BODY 안의 근거만 사용하고 전후 근거 해시를 별도로 기록한다. 다른 손가락의 소유 공간과 미확인 후보는 유지한다.

이 변경은 경계를 계산할 기회를 복구한다. 기존 주름/외곽·원본 지문선 반복 관측·합성 검사와 전체 보호 미검증 표시는 그대로다. V6 가중치·레지스트리·학습 계약·입력 화소·관측 임계값을 변경하지 않았다.

새 사진은 첫 실행 후 원인 분석에 사용했으므로 **수정 후 재실행은 개발 재실행**으로 기록한다. 첫 실패를 지우거나 수정 후 결과를 새로운 독립 시험으로 바꾸지 않는다. 고정 모델 레지스트리는 수정하지 않고 별도의 비공개 사용 이력을 남긴다.

## 수정 후 실행과 회귀

수정 후 같은 전체 사진을 실제 모델부터 다시 실행했다. 수동 마스크·잘라낸 모델 입력·지정 시드는 사용하지 않았다.

- 검지·중지를 각각 선택했고 RGB 외곽 보정과 주름 경계 계산을 거쳤다. 각 손끝 후보는 원본 좌표 13,450·12,794픽셀이다. 이는 사람 정답 경계로 검증한 해부학적 정확도 수치가 아니다.
- 두 손끝의 raw-ridge 검사에서 각각 26·22개 창을 확인했으나 반복 지문선 증거를 확정하지 못했다. `REJECT_VISIBILITY_UNCERTAIN`이며 지문 부재 판정은 아니다.
- 미선택 영역의 나머지 모델 후보 2개는 `REJECT_BOUNDARY_UNCERTAIN`으로 유지했다. 최종 후보 component 4·적용 0·거절 4다. 후보 수를 손가락 수로 환산하지 않는다.
- 서버 처리 102.572초, 반환 `rejected`. 첫 실행과 수정 후 모두 transport 검증·저장 PNG 재읽기·응답 RGB 동일성·입력 전체 RGB 보존을 확인했다. **이 사진에서 실제 후처리·합성이 성공했다고 보고하지 않는다.**
- 두 손끝이 더 크게 촬영되고 초점이 맞아 원본에서 지문선을 관찰할 수 있는 새 사진으로 추가 첫 실행이 필요하다. 보이지 않는 원래 지문을 학습 자료에서 채우거나 생성해 복원했다고 표시하지 않는다.

단발 Windows CPU 실행이며 실물 Android·학교 Ubuntu 통합이나 3회 연속 120초 기준 달성이 아니다. 첫 실행 검증용 보조 스크립트에서 응답 시간·영역 필드명을 잘못 읽은 오류가 있었으나 모델 실행 결과는 보존됐고, 실제 `processing_ms`·`region_display_bounds` 필드로 수정해 저장 결과를 다시 검증했다.
