# 2026-10-20 새 사진 V23 실행기

기존 실행기는 미리 검토된 roster의 사진 ID만 선택할 수 있어 임의의 새 사진 테스트에 부적합했다. 독립적인 로컬 웹 실행기를 추가하여 새 사진 업로드, 기존 모델 후보 검출, 수동 경계 편집, 명시적 가시성 확인, V23 적용, 결과 비교 및 다운로드를 연결했다.

실제 개발 사진 점검에서 일반 JPG가 MPO로 열리는 사례를 발견했다. 복합 JPEG의 기본 사진을 명시적으로 선택하고 보조 프레임을 사용하지 않는 계약을 추가했다. 원본 바이트와 기존 GT는 보존한다.

새 경로의 11개 테스트와 관련 기존 회귀 38개가 통과했다. 브라우저의 실제 파일 선택·다각형 편집·V23 렌더·다운로드를 합성 fixture로 검증했고 다운로드와 저장 PNG 해시가 일치했다. 기존 개발 사진으로 실제 자동 후보 생성도 확인했지만 새로운 인간 검토나 독립 성능 결과를 만들지는 않았다.

검출/보호 수학, 모델 가중치, threshold, 기존 launcher는 변경하지 않았다. 사진/진단/가중치/로컬 실행 경로는 공개 소스에 포함하지 않는다. GitHub push는 하지 않았다.

사용자의 Android 자동 연동 질문에 대해 코드를 확인했다. Android 및 backend V2는 아직 V12/V13/V14 엔진 계약이므로, 이번 V23의 Android 자동 적용 완료로 보고할 수 없다. V23 서버 계약과 앱 연결 및 실기기 종단 검증이 후속 과제다.
