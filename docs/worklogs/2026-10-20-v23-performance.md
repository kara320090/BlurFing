# 자동 V23 처리 시간 최적화

검출·가시성·보호 수학과 임계값을 유지하면서 경계 적합을 요청별 최대 4개
프로세스로 계산하고, 피부 색면의 중복 계산 및 자동 후보 단계의 불필요한
중간 RGB/미리보기 생성을 줄였다. 입력·모델·코드 및 최종 결과 검증은 유지했다.

동일 개발 사진과 고정 시드로 실제 모델 경로를 각 2회 실행했다.
AI 전체 평균 90.47초→78.85초(약 12.8% 감소)이며 반환 RGB와 두 마스크가
정확히 같았다. 추가 3장의 이전 검출 출력을 사용한 재실행도 반환 RGB,
마스크와 판정이 같았다. 독립 정확도나 보호 효과를 새로 검증한 것은 아니다.

- AI 관련 41개 통과.
- backend/실행기 108개 통과, 기존 deprecation warning 1개.
- Android 에뮬레이터 실제 서버 처리→저장→재읽기 1개 통과, 약 96.77초.

실물 휴대폰 검증은 사용자 선택에 따라 진행하지 않았다.
원본/GT/가중치/비공개 진단은 공개 저장소 밖에 보존했다.
모델 검출과 경계 준비에 여전히 시간이 많이 걸리며 실시간 처리 완료로 보고하지 않는다.
이전 버전과 결과는 보존했고 GitHub push는 수행하지 않는다.
