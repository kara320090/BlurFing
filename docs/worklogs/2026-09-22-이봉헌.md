# 2026-09-22 이봉헌 — 백엔드 준비 상태 안내 및 복구 검증

관련 요구사항: BF-07, BF-12. 주담당: 이봉헌(Android 앱 및 시스템 통합).

## 팀원 변경 검토·병합

한윤섭의 요청 검증 추가 커밋 [1c349c3](https://github.com/kara320090/BlurFing/commit/1c349c3)을 검토했다. 서버는 유효한 보호 요청에 HTTP 501 / PROCESSING_NOT_IMPLEMENTED, 미지원 이미지 형식에 HTTP 415를 반환한다. 이미지 처리·반환은 아직 구현되지 않았다.

원격에서 기존 커밋 이력이 변경된 상태여서 양쪽 이력을 보존하는 merge를 수행했다(`1be88d0`). 충돌한 backend/main.py와 requirements.txt는 확인한 팀원의 최신 구현을 유지했다. 병합 결과의 backend 파일은 원격 `1c349c3`과 동일하며 백엔드 구현을 본인 개발 기여로 기록하지 않는다.

## 앱에서 수정한 부분

기존 앱은 두 응답을 숫자만 포함된 일반 서버 오류로 안내했다. HTTP 501은 이미지 보호 기능 미준비 및 로컬 Mock 전환 안내로, HTTP 415는 PNG/JPEG 형식 안내로 구분했다. 원본 서버 오류 본문은 화면에 노출하지 않는다.

새 통합 테스트는 합성 HTTP 응답 501·415 각각에 대해 다음 흐름을 확인한다.

- 처리 성공 화면으로 이동하지 않고 사진·수정 영역을 유지한다.
- 처리본과 성공 응답을 만들지 않고 원인에 맞는 안내를 표시한다.
- 사용자가 Mock으로 전환하면 같은 사진·영역으로 비교 화면까지 진행한다.
- Mock 전환 시 서버로 사진을 다시 전송하지 않는다.

기존 사진·영역 유지 기능을 활용한 회귀 검증이며, 자동 전환이나 새 이미지 보호 알고리즘을 구현한 것은 아니다. 빌드 중 생기는 .kotlin/ 캐시는 Git 제외 항목에 추가했다.

## 실행한 검증

| 검증 | 결과 |
|---|---|
| 수정 전 새 통합 테스트만 실행 | 일반 오류 안내로 인해 실패 재현 |
| Android 전체 테스트·debug APK 빌드 | 37개 통과, 실패·오류·건너뜀 0개, BUILD SUCCESSFUL |
| 팀 백엔드 기존 pytest | 5개 통과. TestClient 관련 의존성 deprecation 경고 2개 |
| backend와 원격 구현 비교 | 변경 없음 |

Android 명령: `./gradlew.bat testDebugUnitTest assembleDebug --max-workers=4 --console=plain` (`android/`에서 실행). JDK 21, Gradle 8.9, SDK 35를 사용했다.

백엔드는 저장소 밖의 별도 Python 가상환경에 `backend/requirements-dev.txt`를 설치하고 `backend/`에서 `python -m pytest -q`를 실행했다. 테스트는 합성 자료만 사용했다.

실제 스마트폰·에뮬레이터 화면 조작, 앱과 팀 서버 사이의 실시간 통신, 지문 보호 성능·센서 실측은 이번 검증에 포함하지 않았다. 앱 통합 시험은 MockWebServer와 Robolectric, 백엔드 시험은 FastAPI TestClient로 각각 수행했다.

도구 활용: Codex가 사용자 요청에 따라 코드 수정·자동 검증·Git 작업을 수행했다. 실제 기기 수동 확인을 완료한 것으로 기록하지 않는다.
