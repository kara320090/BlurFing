# 설정 유지와 편집 작업 복원

보호 방식·강도·서버 사용 여부·주소를 앱 전용 설정에 보관한다. 설정 화면 왕복 및 앱 재실행 후 유지되며, 사진 업로드는 사용자가 `서버로 전송 및 처리`를 눌러야 실행한다. 서버 주소 입력만으로 통신하지 않는다.

Android가 작업의 저장 상태를 복원할 때, 정규화된 원본의 임시 사본과 최신 수정 영역을 편집 화면으로 복원한다. Bundle에는 사진 바이트 대신 임의 파일 식별자와 좌표만 들어간다. 처리 요청·저장·저장 권한 요청은 재실행하지 않는다. 처리본은 다시 처리해야 한다는 안내를 표시한다.

임시 원본은 앱 내부 `cacheDir/editing-drafts/`에 보관하며 갤러리·외부 앱에 공개하지 않는다. 사진 변경·처음으로 돌아가기로 현재 사본을 지우며, 24시간을 지난 사본은 복원하지 않고 다음 앱 실행 시 오래된 임시 파일을 정리한다. 파일 누락·손상·만료 시 사진 재선택을 안내한다. 원본 파일은 수정하지 않는다. 캐시이므로 OS가 언제든 지울 수 있으며, 앱 강제 종료·최근 앱에서 작업 제거 후 새로 시작하는 경우까지 복원을 보장하지 않는다.

`DraftSessionTest`는 저장 상태를 새 객체로 복제하여 픽셀·수정 좌표 복원, 저장·전송 미재실행, 누락·만료·경로 이탈 거부, 원본 보존 및 설정 복구를 검사한다. 실제 시스템 프로세스 회수 검증과 단위 검증 결과는 최종 작업 기록에서 구분한다.

2026-09-29 확인: 에뮬레이터에서 앱을 홈으로 보낸 후 `am kill`로 백그라운드 프로세스를 종료하고 기존 작업에 복귀했을 때 복원 안내·사진·영역이 나타났다. 이전 처리나 저장은 재실행되지 않았다. 새 작업을 시작하는 경우와 기존 작업을 복원하는 경우를 구분한다.
