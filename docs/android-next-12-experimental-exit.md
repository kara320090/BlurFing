# 12. 사진 AI 실험의 미저장 결과와 종료 확인

관련 요구사항: BF-04, BF-05, BF-06, BF-12. Android·시스템 통합 담당: 이봉헌.

사진 AI V2에서 변경된 결과를 저장하지 않고 시스템 뒤로가기 또는 `일반 화면으로 돌아가기`를 누르면 먼저 확인한다. `계속 보기`는 현재 결과를 유지하고, `저장하지 않고 종료`는 실험 화면을 닫는다. 원본 파일과 이미 저장한 복사본을 삭제하지 않는다.

처리·입력 정규화·저장·외부 저장 위치 선택 대기는 진행 중인 작업으로 구분한다. 이때는 `취소 후 종료`를 확인한다. 확인 중 처리가 끝나 변경된 결과가 생기면 미저장 안내로 전환하고, 거절·실패 등으로 보존할 결과가 없으면 확인창을 닫는다. Activity 재생성에서는 확인 대기를 복원하며, 프로세스 종료 후 사진이나 AI 결과를 복원한 것으로 간주하지 않는다.

저장 완료는 공급자에서 다시 읽은 PNG의 길이·SHA256이 응답과 일치한 뒤에만 현재 요청에 기록한다. 저장창 취소·실패·다른 요청의 늦은 응답은 미저장 결과를 저장 완료로 바꾸지 않는다. 새 사진·엔진·실행에서는 이전 요청의 저장 완료 상태를 재사용하지 않는다. 이미 저장한 동일 결과를 다시 저장하다 취소하더라도 최초 검증된 사본의 완료 상태는 유지한다.

현재 화면에서 저장한 사실만 메모리에 보관한다. 갤러리에서 이후 파일이 삭제·변경되었는지를 감시하지 않으며, AI 보호 효과를 검증하는 기능도 아니다. 기존 V1 화면과 AI 엔진·API 계약은 유지한다.
