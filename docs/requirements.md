## 초기 수용 기준
- 자동 탐지의 손끝 후보는 지문이 보이는 패드 영역인지 확인한다. 손톱·손등·불명확한 영역을 무조건 지문으로 취급하지 않는다.
- 영역 좌표, 이미지 회전, 처리 상태, 오류 종류를 공통 계약으로 정의한다.
- 성능 목표치는 입력 크기·시험 기기·원본 기준 성능을 확인한 후 확정한다.
- 개인정보는 로컬·비공개 실험 경로에서 관리하며 공개 저장소에는 합성 예제만 둔다.
