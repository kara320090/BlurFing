# 09. 앱에서 측정한 처리 시간

성공한 요청마다 단조 시계 `elapsedRealtime`으로 사진 인코딩, 요청/대기, 결과 디코딩, 전체 경과 시간을 측정한다. 비교 화면에서 서버 보고 시간과 따로 표시하며, Mock이 보고한 시간은 Mock 지연으로 명시한다. AI 연산 시간이나 지문 보호 성능으로 해석하지 않는다.

결과와 함께 실제 요청의 방식·강도·서버 사용 여부를 보존한다. 재처리 시작과 영역 수정 시 이전 측정 기록을 제거한다. 단위 검증은 고정 시계로 시간 차이를 확인하고 역전 시계를 거부하며, 실제 앱 흐름에서 결과와 측정값의 연결 및 수정 후 무효화를 확인한다.
