# 10. 사진을 제외한 진단 기록 내보내기

비교 화면의 `진단 기록 저장 (사진 제외)` 버튼에서 사용자가 선택한 위치로 JSON 파일을 저장한다. 버튼을 누른 시점의 결과를 고정하고 저장 위치 선택 중 취소하면 쓰지 않는다. 서버 전송은 없다.

허용 필드: 앱 버전, 실제 내보낸 시각, 사진 크기, 영역 개수, 요청 방식·강도·서버 사용 여부, Mock/real, 선택한 출력 형식, 앱 측정 시간, 서버 또는 Mock이 보고한 시간. 사진 바이트, 원본 URI, 파일명, 좌표, 서버 주소, 요청·자료·참조 ID, 평가 점수 및 서버 자유문은 제외한다.

합성 자료 테스트는 비공개 문자열을 URI·주소·식별자·평가 자료 등에 넣어도 JSON에 남지 않는지, Mock 시간이 서버 시간으로 표기되지 않는지, 미완료 결과 및 영역 편집 화면에서 이전 보고서가 생성되지 않는지 확인한다. 실제 센서나 보호 성능 검증을 대신하지 않는다.
