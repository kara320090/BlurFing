# 6. 서버 오류 계약과 재시도 안내

HTTP 409(요청 처리 중), 429(요청 과다), 502(연결 오류), 504(처리 시간 초과)를 구체적으로 안내한다. 응답의 request_id가 일치할 때만 형식이 제한된 오류 코드를 보존한다. 원격 메시지·경로·임의 필드는 화면에 표시하지 않는다.

오류 본문은 64KiB까지 읽으며 형식이 깨져도 HTTP 상태 기반 안내를 유지한다. 입력 오류의 retryable 값을 원격 응답이 true로 바꿀 수 없다. 사진 재전송은 사용자의 새 요청으로만 실행하고 자동 재시도하지 않는다. 성공 응답 파싱 오류도 원문 대신 안전한 안내로 바꾼다.
