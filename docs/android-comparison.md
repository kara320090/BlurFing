# 전후 비교와 평가 결과 표시

비교 화면에서 원본·처리본 전환 또는 나란히 비교를 선택한다. `영역 N`을 누르면 처리 영역 주변을 확대하며, 추가 배율 1~4배는 두 이미지에 동일하게 적용된다. `전체`를 누르면 원래 구도로 돌아간다. 확대는 화면 표시만 바꾸며 저장 사본의 해상도를 변경하지 않는다. 작은 화면에서는 아래 평가·저장 영역으로 스크롤할 수 있다.

서버 처리 결과 자체와 실제 지문 평가를 구분한다. `evaluation`이 없으면 **미측정**이다. Mock 처리 또는 Mock 측정은 수치로 표시하지 않는다. 현재 백엔드는 이 평가 데이터를 생성하지 않으므로 실제 측정값 표시는 센서·AI·백엔드 담당 연동 이후 확인해야 한다.

앱은 다음 선택적 응답 확장을 읽을 준비가 되어 있다. 기존 응답은 변경 없이 사용한다. 값은 제조사 SDK나 매칭 엔진의 실제 측정 결과로 채워야 한다.

| evaluation 필드 | 표시 조건 |
|---|---|
| request_id | 현재 보호 응답의 request_id와 같음 |
| sample_id / reference_id | 비식별 실험 자료 식별자 |
| engine / engine_version | 엔진과 버전 |
| original_score / protected_score | 둘 다 유한한 실측 숫자 |
| score_unit / conditions | 점수 단위와 압축·해상도·임계값 등 측정 조건 |
| measured_at | 시간대가 포함된 ISO 8601 측정 시각 |
| is_mock | false |
| is_valid_original | true 또는 false로 명시 |

메타데이터가 빠지거나 요청이 다르면 수치를 표시하지 않는다. 이 검사는 데이터의 연결·완전성을 확인하며 측정 사실 자체를 인증하지는 않는다. 점수는 단위를 유지하여 그대로 표시하고 일치 확률·보호 성공률로 변환하지 않는다. 원본 기준이 유효하지 않으면 점수와 함께 성공 집계 제외 안내를 표시한다. 테스트의 합성 수치는 측정 실적으로 사용하지 않는다.

검증: `ComparisonPresentationTest`는 범위·확대 계산과 미측정·Mock·부분 값·요청 불일치·엔진/조건 누락 등을 검사한다. `ComparisonDeviceTest`는 실제 Android 화면에서 나란히 비교·영역 선택·배율 변경·미측정 표시·저장 버튼을 확인한다.
