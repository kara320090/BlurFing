## 알고리즘 평가
원본과 처리본은 독립된 동일 손가락 참조에 같은 엔진·설정을 적용한다. 원본 매칭 가능성을 먼저 확인하고 기본 블러와 후보 방법을 동일 품질 조건에서 비교한다. JPEG 압축·축소는 양쪽에 같은 조건을 적용한다. 데이터는 사람 단위로 분리하며 세부 실험 설계와 해석은 유재윤이 담당한다.

## 기록할 항목
실제 수행 시각, 요구사항 ID, 담당자, 코드 버전, 환경, 절차, 기대 결과, 실제 결과, 관련 커밋 SHA·Issue(사용한 경우 PR), 실패 원인과 후속 조치를 남긴다. 실제 개인정보가 없는 로그·화면만 공개한다. 확인하지 못한 기기 시험이나 성능은 미실행으로 표기한다.

이봉헌의 기술 기여는 앱 구현, 규격 공동 설계, 연동 코드, 좌표·상태 오류 해결, 통합 검증 및 재현 가능한 실행 버전으로 설명한다. 회의 진행과 일정 관리는 별도로 기록한다.
