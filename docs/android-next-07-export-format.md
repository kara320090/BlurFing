# 7. PNG·JPEG 보호 사본 저장

비교 화면에서 PNG 또는 JPEG를 선택한다. PNG가 기본이며 JPEG 품질은 80~100으로 선택·저장한다. MediaStore의 MIME·확장자·실제 인코딩을 동일하게 사용한다. 출력은 픽셀에서 새로 인코딩해 원본 EXIF를 복사하지 않는다.

저장/권한 확인 중에는 설정 변경을 막고 요청 시작 당시의 설정으로 저장한다. 같은 초에 반복 저장해도 파일명이 겹치지 않도록 임의 접미사를 붙인다. JPEG 재압축 뒤의 보호 효과는 별도 평가 대상이며 앱이 자동으로 성공을 선언하지 않는다.
