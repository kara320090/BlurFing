# 11. 시스템 뒤로가기와 처리 취소 확인

휴대폰의 시스템 뒤로가기를 앱 화면의 뒤로가기와 같은 흐름으로 연결한다.

- 보호 설정 또는 비교 화면: 같은 사진과 수정 영역을 유지한 채 영역 편집으로 돌아간다. 진행 중인 사본 저장·공유와 저장 권한 대기는 기존 화면 이동 규칙에 따라 무효화한다.
- 영역 편집 화면: 첫 화면으로 돌아가며 편집 복원용 임시 사본과 영역 이력을 지운다. 원본 사진과 이미 저장한 사본은 삭제하지 않는다.
- 보호 처리 중: 즉시 화면을 닫지 않고 `계속 처리` / `처리 취소`를 확인한다. 확인창을 닫거나 시스템 뒤로가기를 한 번 더 누르면 처리를 계속한다. 취소하면 사진과 영역을 유지한 설정 화면에서 다시 시작할 수 있다.
- 취소 확인 중 처리가 먼저 끝나면 확인창을 닫고 정상 비교 결과를 표시한다. 화면 재생성 중에도 확인창 선택 대기를 복원한다.
- 첫 화면에서는 운영체제의 기본 뒤로가기를 사용한다. 외부 사진 선택기·공유·문서 저장 창의 뒤로가기는 해당 창이 처리한다.

앱의 요청 취소는 응답을 더 이상 적용하지 않는 동작이다. 서버에서 이미 완료한 작업이나 갤러리의 완성 파일을 되돌린다는 의미가 아니다. 합성 자료를 이용해 탐색과 취소를 검증하며 실제 AI·센서 보호 성능과 구분한다.
