# Android 구현 마무리 — 2026-10-20

이봉헌 담당 앱 구현의 인수 기준이다. 실제 학교 서버 연결은 사용자 요청에 따라 10월 21일에 확인한다. 이 문서의 구현 완료는 AI의 일반 보호 성능 승인이나 실물 휴대폰 전체 검증을 뜻하지 않는다.

## 이번 변경

| 사용자 흐름 | 구현 내용 |
|---|---|
| 서버·엔진 설정 | V2 전용 주소·엔진을 저장한다. V1의 Mock/임시 터널 설정을 가져오지 않는다. 배포 빌드의 초기 V2 주소는 비워 두고 HTTPS 주소를 직접 입력한다. |
| 연결 확인 | 사진 없이 `GET /ready`로 V2 계약과 구성된 엔진을 확인한다. 선택 엔진이 없으면 전송을 막고, 주소를 바꾸면 이전 확인을 지운다. 준비 응답은 실제 추론 성공의 증거가 아니다. |
| 실패·취소 | 404/405 주소·버전, 401/403 접근 권한, 413 크기, 415/422 형식, 409 중복, 429 사용 중, 503 엔진 미준비, 504 시간 초과를 구분한다. 오류 본문·서버 내부 경로를 표시하지 않는다. 자동 엔진 변경·재업로드는 하지 않는다. |
| 촬영 | 기존 전체 해상도 카메라 계약·촬영 URI 복원을 재사용한다. 촬영 취소는 현재 결과를 유지하며 성공 입력·거절된 교체의 앱 소유 임시 파일을 정리한다. 사진 선택기·촬영에는 전체 사진함 읽기 권한을 요청하지 않는다. |
| 비교 | 원본과 처리본을 나란히 또는 한 장씩 본다. 후보 선택과 1–4배 확대는 양쪽의 같은 원본 좌표에 적용한다. RGB 행을 순서대로 읽고 선택 영역만 최대 1024픽셀 미리보기로 유지하므로 전체 크기의 Bitmap을 추가하지 않는다. 마스크는 검증된 원본 좌표를 사용하며 저장 파일을 바꾸지 않는다. |
| 공유 | 변경된 결과만 명시적 확인 후 PNG로 공유한다. 재압축 없이 반환 PNG를 복사하고 재읽기 해시를 확인한다. FileProvider로 사본 한 개에 읽기 권한만 전달한다. 원본·마스크·서버 경로는 공유 첨부에 넣지 않는다. 공유창을 연 것을 저장 완료로 처리하지 않는다. |
| 재생성·복원 | 설정과 private cache의 원본·검증 응답을 복원한다. SavedState에는 UUID·해시·시각·저장 요청 ID만 넣는다. 복원 시 PNG·마스크·픽셀 보존 계약을 다시 검증한다. 오래되거나 손상된 사본은 거절한다. 중단된 네트워크·저장·공유·저장창 ticket은 재실행하지 않는다. |

원본·결과 복원 사본은 앱의 private cache에 있으며 최대 24시간의 복원 유효 기간을 갖는다. 다음 실행에서 만료된 임시 사본을 정리하고 명시적으로 실험 화면을 닫거나 사진을 교체하면 해당 작업 사본을 지운다. Android가 cache를 회수하거나 저장 공간·메모리가 부족하면 복원이 불가능할 수 있다. 이때 경고하며 사용자가 저장한 파일과 원본은 유지한다. 공유한 임시 PNG는 수신 앱의 읽기를 위해 유지하고 이후 공유 시 24시간 지난 실험 사본을 정리한다.

사진·결과 복원은 Android가 작업의 SavedState를 되살리는 화면·프로세스 재생성에 적용한다. 강제 중지·작업 제거 후 새 실행에서의 사진 복원은 보장하지 않는다. 설정 저장과 중단 작업의 자동 재실행 금지는 새 실행에도 적용한다.

## 기존 앱에서 유지되는 범위

V1의 갤러리·카메라 입력, 영역 추가/이동/삭제, 편집 복원, 보호 방법·강도, 진행·취소·재시도, 서버 응답 검증, PNG/JPEG 저장, 공유, 비교 확대, 진단 내보내기는 유지한다. V2는 자동 영역 실험과 무손실 PNG 저장·공유를 사용한다. V1의 수동 영역·강도 설정을 다른 계약의 V2 요청에 섞지 않는다.

## 검증 증거

최종 실행 수치와 빌드·에뮬레이터 결과는 [당일 작업 기록](worklogs/2026-10-20-이봉헌-android-completion.md)에 기록한다. 합성 입력·제어된 HTTP 응답으로 앱의 화면·통신·픽셀 검증·파일 수명을 검사한다. 실제 AI 보호 성능이나 센서 점수로 집계하지 않는다.

전체 단위 209개 중 208개 통과·선택 1개 건너뜀, 고유 에뮬레이터 검사 22개(회귀 21 + V2 카메라 전달 URI 1) 통과, debug·계측·unsigned release 빌드 성공, lint 오류 0을 확인했다.

## 외부 확인이 남은 항목

1. 학교 Ubuntu에 V2를 구성하고 휴대폰에서 접근 가능한 최종 HTTPS 주소와 지원 엔진 확인. 사용자가 다음 날로 지정한 작업이다.
2. 실제 휴대폰의 카메라 앱·사진 선택기·문서 저장 제공자·공유 수신 앱 및 저메모리 상황 확인. 에뮬레이터 결과를 전체 기기 호환성으로 확대하지 않는다.
3. 실제 모델·독립 정답 자료·센서 측정에 기반한 탐지·보호 성능 평가. 미검출·거절된 지문이 원본으로 남을 수 있다는 안내를 유지한다.
4. Play 배포가 필요하면 소유자의 배포 서명·콘솔 절차를 별도로 진행한다. debug APK 설치와 unsigned release 빌드를 Play 출시로 표시하지 않는다.

## 재현

JDK 21과 Android SDK 경로를 설정하고 `android/`에서 실행한다.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug :app:assembleRelease --no-daemon --max-workers=2
```

`ExperimentalPhotoReadinessTest`는 실제 loopback TCP·응답 제한·취소·계약을, `ExperimentalPhotoCompletionTest`는 설정·private snapshot·재검증·촬영 사본 정리·정확한 PNG 공유·영역 확대를 검사한다. `ExperimentalCompletionDeviceTest`는 실제 V2 Activity와 제어된 TCP 응답·화면 재생성·공유 확인 취소를 연결한다. 비공개 사진·모델 파일은 APK나 공개 Git에 포함하지 않는다.
