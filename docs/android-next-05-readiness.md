# 5. 사진 전송 전 서버 준비 상태 확인

설정 화면에서 GET /ready를 직접 확인한다. 준비됨/모듈 미연결/미지원/통신 오류를 구분한다. 상태 확인은 사진·좌표·사진 식별자를 보내지 않는다. 5초 제한과 본문 크기 제한을 적용하고 주소를 바꾸면 이전 응답을 폐기한다.

준비됨은 모듈 연결 여부만 뜻한다. 실제 보호 성능이나 사진 처리 성공을 보장하지 않는다. 오래된 서버의 404는 미지원으로 안내하며 보호 요청 자체를 자동으로 차단하지 않는다. 자동 재요청이나 사진 전송은 하지 않는다.

## 상태 전환 회귀 검증

`BackendReadinessLifecycleTest`는 주소 변경 후 도착한 이전 응답을 폐기하는지, 두 요청의 완료 순서가 바뀌어도 최신 요청의 상태를 유지하는지 확인한다. Mock 모드 전환과 사진 작업 초기화 시 진행 중인 확인을 취소하는지도 검증한다. Mock 모드에서는 새 상태 확인 요청을 보내지 않는다.

지연 응답은 합성 검사 함수와 코루틴 테스트 스케줄러로 재현한다. 실제 네트워크 속도에 의존하지 않으며 실제 서버·실물 기기·AI 보호 성능 검증과는 구분한다.
