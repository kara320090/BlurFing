# 08. 처리 사본 공유

비교 화면에서 PNG/JPEG 설정대로 처리된 비트맵만 다시 인코딩해 Android 공유 창을 연다. 원본 URI와 EXIF를 전달하지 않는다. Mock은 공유 버튼과 창 제목에도 Mock 프리뷰로 표시한다.

전용 FileProvider는 `protected-shares/` 캐시 경로만 노출하며 수신 앱에 읽기 권한만 부여한다. 캐시 파일명은 임의 UUID이고, 다음 공유 준비 때 24시간 지난 전용 파일을 정리한다. 준비 실패 시 새 파일을 제거하고, 중복 요청 및 이전 사진의 늦은 완료를 무시한다.

합성 이미지 단위 검증: MIME와 JPEG 헤더, 소스 보존, 캐시 정리 범위, URI 실패 정리, 읽기 권한, 중복 요청 및 초기화 후 늦은 완료. 외부 앱에 실제 개인 사진을 공유하는 시험은 수행하지 않는다.
