# 구조 및 연동 경계

## 구성
Android 앱 → 백엔드 API → 영역 추출·보호 알고리즘의 흐름으로 연결한다. 센서 취득과 지문 매칭 평가는 연구용 도구로 분리하고, 실제 측정 결과만 백엔드를 거쳐 시연 화면에 전달한다.

| 경로 | 예정 내용 | 주담당 |
|---|---|---|
| android/ | Kotlin·Jetpack Compose 기반 앱 후보, 화면·상태·저장·통신 | 이봉헌 |
| backend/ | 공통 처리 API와 모듈 어댑터 | 한윤섭 |
| data/ | 자료 목록·허용 범위·주석·영역 추출 | 정회서 |
| ai/ | 블러 기준 및 보호 알고리즘 실험 | 유재윤 |
| sensor/ | 센서 영상 취득과 품질·오류 처리 | 최승빈 |
| evaluation/ | 측정 도구와 재현 절차 | 최승빈·유재윤 |
| contracts/ | 공통 입출력 초안과 합성 예제 | 관련 담당 공동, 이봉헌 통합 반영 |

## 앱 구조 초안
화면은 입력, 영역 확인, 처리 진행, 전후 비교·저장으로 구성한다. UI 상태와 API 통신을 분리하고 Repository 인터페이스로 Mock 구현과 실제 API 구현을 교체할 수 있게 한다. 플랫폼·SDK·라이브러리 버전은 설치 환경을 확인해 고정한다.

## 구현 순서
1. 외부 모듈이 없어도 합성 사진과 Mock 응답으로 앱 흐름을 구현한다.
2. 영역 좌표·방향·오류 계약을 검증하고 실제 백엔드 어댑터를 연결한다.
3. 정회서의 영역 추출, 유재윤의 보호 알고리즘, 최승빈의 측정 결과를 각 담당자와 연결한다.
4. 입력부터 저장까지 검증하고 실패 재현·수정 증거를 남긴다.

Mock 시연은 지문 검출이나 보호 성능을 입증하지 않는다. AI 결과가 없는 단계에서는 수치를 만들지 않고 '미측정'으로 표시한다. 앱의 요구사항이 바뀌면 API 초안과 검증 기준을 함께 갱신한다.
