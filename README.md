# BlurFing

SNS 사진 속 손가락 지문 노출을 줄이는 Android 보호 앱 프로젝트입니다.
사진 입력 → 손끝 영역 확인·수정 → 보호 처리 → 전후 비교 → 보호 사본 저장을 구현합니다.

## 현재 상태
2026-09-21 기준 Android 앱에는 사진 선택, 수동 영역 편집, Mock 프리뷰, 서버 처리 선택, 전후 비교와 사본 저장 코드가 있습니다. 서버 응답의 이미지·요청 ID를 확인하고 통신 실패 시 사진과 수정 영역을 유지합니다. 실행 방법과 검증 범위는 [Android 안내](android/README.md)를 확인하세요.

백엔드는 기본 확인용 `GET /`까지 구현되어 있으며 `POST /v1/protect`는 아직 없습니다. 자동 영역 추출·AI 보호 성능·센서 연동은 후속 개발 대상입니다. 기본 후보 영역은 개발용 예시이며 실제 탐지 결과가 아닙니다.

## 시작하기
1. [안티그래비티 실행 프롬프트](docs/antigravity-prompt.md)를 읽고 개발 에이전트에 전달합니다.
2. [요구사항](docs/requirements.md)과 [구조 및 경계](docs/architecture.md)를 확인합니다.
3. [우선 작업 목록](docs/backlog.md)에서 작업을 선택하고 main에서 구현합니다.
4. [협업 규칙](CONTRIBUTING.md)에 따라 변경과 실제 검증 결과를 기록합니다.
5. 팀장은 [main 작업 및 검토 절차](docs/main-workflow.md)에 따라 팀원 변경 검토와 앱·통합 개발을 병행합니다.

## 일정과 완료 기준
수업 7주차인 **2026-10-16까지 개발·검증·보고서·발표 자료를 완료**하고, 8주차에는 발표·시연·질의응답을 진행합니다. [주차별 계획](docs/project-plan.md)을 따릅니다.

원본부터 매칭이 불가능한 사진을 보호 성공으로 집계하지 않습니다. 지문 매칭 점수를 본인 일치 확률로 표시하지 않습니다. Mock 결과는 통신·화면 개발용이며 실제 보호 성능의 근거가 아닙니다.
