# BlurFing

SNS 사진 속 손가락 지문 노출을 줄이는 Android 보호 앱 프로젝트입니다.
사진 입력 → 손끝 영역 확인·수정 → 보호 처리 → 전후 비교 → 보호 사본 저장을 구현합니다.

## 현재 상태
2026-09-28 기준 Android 앱에는 사진 선택, 수동 영역 편집, Mock 프리뷰, 서버 처리 선택, 전후 비교와 사본 저장 코드가 있습니다. 서버 응답의 이미지·요청 ID를 확인하고 통신 실패 시 사진과 수정 영역을 유지합니다. 저장 중 중복 실행을 막고, 저장 실패 시 비교 화면에서 재시도할 수 있습니다. 사진을 바꾸거나 편집 화면으로 돌아간 뒤에는 이전 저장 결과가 화면을 되돌리지 않습니다. 실행 방법과 검증 범위는 [Android 안내](android/README.md)를 확인하세요.

사진 입력은 15MiB·2,000만 화소 이하를 검사한 뒤 원본 해상도를 유지해 읽습니다. 같은 파일 데이터에서 EXIF 방향을 적용하며, 읽기 오류에 내부 파일 경로를 노출하지 않습니다. 사본 저장은 갤러리 등록까지 성공해야 완료로 처리하고 실패 시 미완성 항목 정리를 시도합니다. [입출력 보완 기록](docs/worklogs/2026-09-27-이봉헌-입출력보완.md)

Android 8·9의 저장 권한 요청·허용 후 저장·거부 후 재시도를 연결했습니다. 사진 교체·화면 이동 후 도착한 이전 권한 응답은 무시하며 Android 10 이상에서는 앱 소유 사본 저장에 기존 저장 권한을 요청하지 않습니다. 전체 Android 테스트 76개와 debug APK 빌드를 통과했고 실제 시스템 권한 창·갤러리 동작은 기기 검증이 남아 있습니다. [9월 28일 작업 기록](docs/worklogs/2026-09-28-이봉헌.md)

2026-09-27 확인: 백엔드는 요청 이미지·영역 검증, AI 처리 모듈 연결 지점, 결과 PNG 검증·반환을 구현했습니다. AI 모듈은 아직 연결되지 않아 영역이 있는 보호 요청에는 HTTP 503 / `PROCESSOR_UNAVAILABLE`을 반환합니다. 자동 영역 추출·AI 보호 성능·실장비 센서 연동 검증도 남아 있습니다. 기본 후보 영역은 개발용 예시이며 실제 탐지 결과가 아닙니다.

[Windows 센서 수집 도구](sensor/README.md)는 BioMini Slim 2의 SDK 연결·단일 영상 취득·BMP/PNG 저장을 준비한 별도 프로그램입니다. 합성 영상 저장과 오류 처리를 검증했으며, 실제 SDK·센서 취득은 수령 후 검증해야 합니다.

2026-09-28 센서 인수인계: [조사·설치·담당 작업 정리](docs/sensor-handoff.md)와 [무료 FFV SDK용 저장 확장 소스](sensor/ffv-extension/README.md)를 공유합니다. FFV 공식 지원 목록에 BioMini Slim 2가 있어 드라이버·SDK·프로그램 구성이 맞으면 취득 동작을 기대할 근거가 있습니다. 실물 연결·취득·저장은 아직 확인하지 않았으며, 사진 파일의 보호 전후 비교는 별도 평가 엔진으로 연결합니다.

## 시작하기
1. [안티그래비티 실행 프롬프트](docs/antigravity-prompt.md)를 읽고 개발 에이전트에 전달합니다.
2. [요구사항](docs/requirements.md)과 [구조 및 경계](docs/architecture.md)를 확인합니다.
3. [우선 작업 목록](docs/backlog.md)에서 작업을 선택하고 main에서 구현합니다.
4. [협업 규칙](CONTRIBUTING.md)에 따라 변경과 실제 검증 결과를 기록합니다.
5. 팀장은 [main 작업 및 검토 절차](docs/main-workflow.md)에 따라 팀원 변경 검토와 앱·통합 개발을 병행합니다.
